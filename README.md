# 天空小球冒险 - Sky Ball Adventure

一个基于 Three.js 和 Cannon.js 的 3D 天空小球跨越险阻过关游戏。

## 游戏特色

- 🌟 **3D 天空环境**: 美丽的天空盒和云朵效果
- 🎮 **物理引擎**: 使用 Cannon.js 实现真实的物理效果
- 🏃 **多样化关卡**: 包含静态平台、移动平台、旋转障碍等
- 💎 **收集系统**: 收集金币获得分数
- 🎵 **音效系统**: 合成音效增强游戏体验
- ✨ **特效系统**: 粒子效果、轨迹效果、烟花效果
- 📱 **响应式设计**: 适配不同屏幕尺寸

## 游戏玩法

### 控制方式
- **移动**: WASD 键 或 方向键
- **跳跃**: 空格键

### 游戏目标
- 控制小球在天空中的平台间跳跃
- 避开旋转的红色障碍物
- 收集金色的收集品获得分数
- 到达绿色的终点平台完成关卡

### 游戏机制
- 生命值: 3 条生命
- 掉落惩罚: 掉出平台会失去一条生命
- 分数系统: 收集品 +100 分，完成关卡 +500 分
- 关卡进度: 完成关卡后自动进入下一关

## 技术实现

### 核心技术
- **Three.js**: 3D 渲染引擎
- **Cannon.js**: 物理引擎
- **Web Audio API**: 音效系统

### 文件结构
```
├── index.html          # 主页面
├── js/
│   ├── game.js        # 主游戏逻辑
│   ├── audio.js       # 音频管理
│   └── effects.js     # 特效系统
└── README.md          # 说明文档
```

### 主要功能模块

#### 1. 游戏核心 (game.js)
- 场景管理和渲染
- 物理世界设置
- 小球控制和移动
- 关卡生成和管理
- 碰撞检测
- 游戏状态管理

#### 2. 音频系统 (audio.js)
- 合成音效生成
- 音量控制
- 静音功能

#### 3. 特效系统 (effects.js)
- 粒子效果
- 小球轨迹
- 收集特效
- 关卡完成烟花

## 关卡设计

### 第一关
- 简单的跳跃平台
- 基础收集品
- 学习游戏机制

### 第二关
- 引入移动平台
- 旋转障碍物
- 增加难度

### 第三关
- 复杂的障碍组合
- 多个旋转障碍
- 更多收集品

### 随机关卡
- 程序生成的无限关卡
- 随机平台布局
- 动态难度调整

## 运行游戏

1. 将所有文件放在同一目录下
2. 使用本地服务器打开 `index.html`
3. 或者直接在现代浏览器中打开文件

### 本地服务器示例
```bash
# Python 3
python -m http.server 8000

# Node.js
npx serve .

# 或使用任何其他静态文件服务器
```

## 浏览器兼容性

- Chrome 60+
- Firefox 55+
- Safari 11+
- Edge 79+

需要支持 WebGL 和 Web Audio API 的现代浏览器。

## 开发说明

### 添加新关卡
在 `game.js` 中的 `createLevel()` 方法中添加新的关卡逻辑：

```javascript
case 4:
    this.createLevel4();
    break;
```

### 自定义音效
在 `audio.js` 中的 `createSynthSounds()` 方法中添加新音效：

```javascript
this.sounds.newSound = () => this.playTone(frequency, duration, waveType);
```

### 添加新特效
在 `effects.js` 中创建新的特效方法并在适当时机调用。
