# 《魔尊重生，开局负债500万》创作项目

一套完整的500万字都市修仙/重生逆袭/商战修仙双线网文创作系统。

## 项目概述

- **书名**: 魔尊重生，开局负债500万
- **类型**: 都市修仙 / 重生逆袭 / 商战修仙双线
- **总字数目标**: 500万字
- **主角**: 萧烬（前世修仙界魔尊，今世都市青年）
- **核心卖点**: 
  - 修仙+商战双线并重，前期商业戏份占60%
  - 五位风格迥异的女主，各有独立故事线
  - 节奏快速但张弛有度，爽点多样不重复

## 文件结构

### 核心文件

| 文件 | 说明 |
|-----|------|
| `大纲_优化版.md` | 核心大纲文件，包含分卷大纲和细纲 |
| `01_人物表_修订版.md` | 完整人物设定（主角、五女主、配角、反派等） |
| `02_时间线与伏笔回收表.md` | 章节类型、伏笔管理、时间节点 |
| `03_写作强制要求.md` | 写作规范、爽点设计、商战模板等 |

### 辅助工具

| 文件 | 说明 |
|-----|------|
| `章节深度优化.md` | 章节深度优化专家提示词 |
| `语言自然化.md` | 网文语言优化专家提示词 |
| `小说去AI痕迹完整提示词.md` | 去AI痕迹写作指南 |

## 文件关系

```
大纲_优化版.md (核心大纲)
    │
    ├── 01_人物表_修订版.md (人物设定)
    │
    ├── 02_时间线与伏笔回收表.md (时间线/伏笔)
```

## 使用方法

1. **规划阶段**: 查看 `大纲_优化版.md` 和 `02_时间线与伏笔回收表.md`
2. **写作阶段**: 参考 `03_写作强制要求.md` 执行写作标准
3. **优化阶段**: 使用 `语言自然化.md` 和 `小说去AI痕迹完整提示词.md` 优化文本
4. **检查阶段**: 使用 `章节深度优化.md` 进行章节质量检查

## 版本说明

- 本项目为500万字压缩优化版
- 前80万字商业占比60%，修仙占比40%
- 五女出场时间间隔50-80万字
