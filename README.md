# 🌟 天空小球冒险 - Sky Ball Adventure 🌟

一个激动人心的3D天空障碍跑酷游戏！控制小球穿越天空中的重重障碍，收集星星，到达终点！

## 🎮 游戏特色

- **3个独特关卡**: 每个关卡都有不同的挑战和障碍设计
- **多样化障碍**: 旋转障碍、尖刺球、激光束、消失平台、风力区域等
- **收集系统**: 收集金色星星获得高分
- **检查点系统**: 失败后从最近的检查点重新开始
- **生命系统**: 3条生命，合理规划路线
- **美丽的3D场景**: 天空环境、动态云朵、粒子效果

## 🚀 快速开始

### 方法1: 使用Python HTTP服务器
```bash
# Python 3
python3 -m http.server 8080

# Python 2
python -m SimpleHTTPServer 8080
```
然后打开浏览器访问: `http://localhost:8080`

### 方法2: 使用Node.js
```bash
# 如果已安装 http-server
npx http-server -p 8080

# 或使用npm脚本
npm start
```

### 方法3: 直接打开
某些浏览器允许直接打开 `index.html` 文件（可能需要调整浏览器安全设置）

## 🎯 游戏控制

| 按键 | 功能 |
|------|------|
| **W / ↑** | 向前移动 |
| **S / ↓** | 向后移动 |
| **A / ←** | 向左移动 |
| **D / →** | 向右移动 |
| **空格** | 跳跃 |
| **鼠标** | 控制视角 |

## 📖 游戏玩法

### 关卡介绍

#### 关卡 1 - 基础跳跃
- 学习基本控制
- 浮动平台挑战
- 旋转障碍躲避
- 移动平台跳跃

#### 关卡 2 - 旋转迷宫
- 环形平台阵列
- 螺旋上升路径
- 浮动与旋转平台组合
- 尖刺球障碍

#### 关卡 3 - 极限挑战
- 消失重现平台（注意闪烁警告）
- 激光束区域
- 风力影响区
- 倾斜平台
- 弹跳蘑菇

### 特殊元素

- **🟡 普通星星**: +10分
- **⭐ 特殊星星**: +50分
- **🚩 检查点**: 保存进度
- **🏁 终点旗帜**: 完成关卡
- **🍄 弹跳垫**: 超级跳跃
- **💨 风力区**: 影响移动方向

## 🏆 得分系统

- 收集普通星星: 10分
- 收集特殊星星: 50分
- 时间奖励: 越快完成得分越高
- 生命奖励: 保留的生命越多得分越高

## 💡 游戏技巧

1. **观察平台规律**: 移动平台和消失平台都有固定规律
2. **利用检查点**: 遇到检查点一定要触碰保存进度
3. **控制跳跃力度**: 不要在边缘跳跃，保持在平台中心
4. **注意障碍模式**: 旋转障碍和激光有固定的运动模式
5. **收集星星**: 尽量收集所有星星以获得高分
6. **利用弹跳垫**: 弹跳垫可以帮助你到达更高的地方
7. **小心风力区**: 风力会影响你的移动方向
