# 《魔尊重生,开局负债500万》小说创作规划

## 项目概述

本项目是一部都市修仙/重生逆袭/商战修仙双线的网络小说创作规划文档集。

**书名**: 魔尊重生,开局负债500万  
**类型**: 都市修仙 / 重生逆袭 / 商战修仙双线  
**总字数目标**: 500万字  
**主角**: 萧烬,前世修仙界魔尊,今世都市青年

## 核心卖点

- 修仙+商战双线并重,前期商业戏份占60%
- 五位风格迥异的女主,各有独立故事线
- 节奏快速但张弛有度,爽点多样不重复
- 商业帝国与修仙宗门同步建立
