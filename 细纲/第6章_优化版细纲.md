# 第6章：还清债务，打脸前女友（优化版细纲）

**类型**：高潮章节 | **建议字数**：3200-3800字

---

## 一、核心事件

萧烬带着4104万去还清500万债务，在豪华酒店偶遇林诗雨和王天豪。王天豪炫耀5万一桌，萧烬随手点50万一桌。林诗雨震惊后悔，想攀关系被冷漠拒绝。王天豪威胁，被酒店经理轰出去。本章核心是"打脸"，但要写出质感和层次，不能沦为单纯的发泄。

---

## 二、本章场景拆解与权重

| 场景 | 类型 | 权重 | 建议字数 | 说明 |
|------|------|------|---------|------|
| 还清债务 | 过渡场景 | 15% | 480-570字 | 简洁交代，为后续铺垫 |
| **酒店偶遇** | **核心场景** | **35%** | **1120-1330字** | 遭遇+王天豪炫耀+萧烬反击 |
| **林诗雨后悔+王天豪恼羞** | **核心场景** | **35%** | **1120-1330字** | 情绪递进，双线打脸 |
| 王天豪威胁+被轰 | 过渡场景 | 15% | 480-570字 | 收尾+埋伏笔 |

**本章核心是情绪递进，从偶遇→震惊→后悔→恼怒→被轰，一气呵成。**

## 三、场景一：还清债务（480-570字）

### 场景定位
开篇过渡，快速交代萧烬还债的事实，同时展现他的心态变化。

### 五层展开

#### 【第1层：事件】
萧烬去银行还清500万债务 → 拿到结清证明 → 内心感慨 → 决定去酒店吃饭

#### 【第2层：感官细节】

**视觉**

```
银行柜台前，萧烬看着电脑屏幕上那串归零的数字。
500万。
欠款余额：0.00元。
柜员小姐的眼神从一开始的敷衍变成了震惊——一次性还清500万的人可不多见。
```

**听觉**

```
柜员的声音都在发抖："先生，您这500万，真的要一次性还清吗？"
"嗯。"
键盘敲击声响起，确认按钮被按下。
"叮"——转账成功的提示音。
```

#### 【第3层：人物反应】

```
萧烬看着那张结清证明，嘴角微微上扬。
三天前，他还是一个负债500万的废物。
三天后，他口袋里还剩下三千多万。
世事无常。
但对他这种人来说，无常才是常态。
```

#### 【第4层：内心活动】

```
【深度思考】
前世，他富可敌国。
灵石堆成山，丹药成箱，法器随便用。
那时候，他对财富早已麻木。
但今天，看着这张结清证明，他忽然有种说不出的感觉。
不是开心。
是……解脱。
原身欠下的债，今天算是还清了。
接下来，该做自己想做的事了。
```

#### 【第5层：过渡】

```
走出银行，萧烬看了一眼时间。
中午了。
他想起林小满早上说过，中午要去医院实习，不能回来做饭。
那就……自己找个地方吃吧。
手机搜了一下附近的餐厅。
江南天下。
号称全市最高档的酒店，人均消费三千起步。
萧烬想了想，叫了一辆车。
【过渡——引出下一场景】
```

## 四、场景二：酒店偶遇（1120-1330字）【核心场景】

### 场景定位
本章第一个核心场景，要写出：
1. 江南天下酒店的高档环境
2. 偶遇的"巧合感"
3. 王天豪的炫耀（立靶子）
4. 萧烬的反击（打脸第一波）

### 五层展开

#### 【第1层：事件】
萧烬进入酒店 → 遇到前女友林诗雨和王天豪 → 王天豪炫耀 → 萧烬点50万宴席

#### 【第2层：感官细节】

**视觉（主导）**

```
1. 酒店大堂：
   - 挑高十几米的大堂，正中央是一座水晶喷泉
   - 地面是大理石，反光照人
   - 墙上挂着几幅名画，萧烬扫了一眼——真迹
   - 服务员统一穿着黑色西装，彬彬有礼

2. 人物：
   - 林诗雨穿着一条紫色连衣裙，挽着王天豪的手臂
   - 王天豪穿着定制西装，手腕上戴着一块百达翡丽
   - 两人正往餐厅走，身后跟着一个服务员
   
3. 表情变化：
   - 林诗雨看到萧烬的一瞬间，脸色微变
   - 王天豪先是愣了一下，然后露出玩味的笑容
```

**听觉**

```
1. 轻柔的背景音乐，大概是肖邦的夜曲
2. 杯盏碰撞的声音，低声细语的交谈声
3. 王天豪故意提高的声音："诗雨，你看，这不是你前男友吗？"
```

**嗅觉**

```
空气里弥漫着淡淡的香氛味，是酒店定制的。
还有王天豪身上古龙水的味道——萧烬皱了皱眉，太浓了，暴发户的选择。
```

#### 【第3层：对话设计】（动作三明治法）

**偶遇瞬间**

```
"诗雨，你看，这不是你前男友吗？"
王天豪的声音不大不小，恰好能让周围几桌的人听到。
林诗雨的脸色微变："天豪，别闹……"
"怕什么？"王天豪笑了笑，拉着林诗雨走向萧烬，"萧烬是吧？好久不见。"
萧烬看了他一眼。
目光平静，像是在看一个陌生人。
"……你好。"
王天豪等着萧烬的反应，但萧烬只说了两个字，然后转身准备走。
这反应让王天豪有点意外，也有点不爽。
```

**王天豪炫耀——立靶子**

```
"萧烬，既然遇到了，一起吃个饭呗？"
王天豪叫住他，声音里带着一丝居高临下的施舍感。
"今天我请客。江南天下的顶级宴席，5万一桌。"
他故意强调了"5万"两个字。
"你应该没吃过吧？来见识见识。"
周围有人开始窃窃私语。
有人认出了王天豪——建业集团少东家，这一片有名的富二代。
也有人在看萧烬——穿着普通，看起来不像有钱人。
林诗雨拉了拉王天豪的袖子："天豪……"
王天豪没理她，就这么盯着萧烬，嘴角带着玩味的笑。
他等着看萧烬窘迫的表情。
等着萧烬推脱、找借口、灰溜溜地离开。
等着曾经的"情敌"在自己面前抬不起头。
```

**萧烬的反击——第一波打脸**

```
萧烬没有窘迫。
他只是看了王天豪一眼，然后笑了。
"5万？"
他转头，对着一旁的服务员说：
"给我开一个包厢。"
服务员愣了一下："先生，请问您要什么档次的……"
"最贵的那种。"
"最……最贵的是50万一桌的定制宴席，需要……"
"开一桌。"
服务员懵了。
王天豪也懵了。
周围议论的声音戛然而止。
所有人都看着萧烬，眼神里带着难以置信。
50万一桌？
这个看起来普普通通的年轻人？
林诗雨瞪大了眼睛，嘴巴微张，想说什么却说不出来。
王天豪的笑容僵在脸上。
他炫耀5万，萧烬直接点50万。
十倍碾压。
```

#### 【第4层：内心活动】

**萧烬的内心**

```
【即时反应】
5万？
呵。
【快速判断】
这个王天豪，脑子里装的大概都是浆糊。
区区5万就想在他面前炫耀？
前世他随便炼一颗丹药，都比这个数高一百倍。
【深度思考】
不过……倒也不是为了和他比。
他萧烬做事，从来不需要向任何人证明什么。
只是有些人，非要自己把脸凑上来。
那就别怪他不客气。
```

#### 【第5层：闲笔】

```
【闲笔1】观察服务员反应（约30字）
服务员的态度立刻变了，从客气变成了恭敬。萧烬注意到他的手都在抖——大概从没遇到过这种客人。
```

## 五、场景三：林诗雨后悔+王天豪恼羞（1120-1330字）【核心场景】

### 场景定位
本章第二个核心场景，也是情绪最浓烈的部分。要写出：
1. 林诗雨的复杂情绪（不能脸谱化）
2. 她想攀关系被冷漠拒绝
3. 王天豪的恼羞成怒
4. 萧烬全程冷漠，魔尊的骄傲

### 五层展开

#### 【第1层：事件】
包厢门口 → 林诗雨上前搭话 → 萧烬冷漠拒绝 → 王天豪恼怒发难

#### 【第2层：人物心理】

**林诗雨的情绪变化**（不能脸谱化）

```
【第一阶段：震惊】
林诗雨看着萧烬的背影，大脑一片空白。
50万一桌。
萧烬……什么时候这么有钱了？
三天前，他还是那个欠债500万的废物。
三天后，他能在江南天下随手点50万的宴席。

【第二阶段：后悔】
她想起了很多事。
想起高中时萧烬偷偷给她买生日蛋糕，省吃俭用攒了一个月。
想起大学时萧烬为了给她买一条项链，在工地打了一个暑假的工。
想起分手那天，萧烬的眼神——不是愤怒，是失望。
如果……
她没有和他分手呢？

【第三阶段：想法改变】
她咬了咬嘴唇，做出了一个决定。
不能让萧烬就这么走了。
```

**王天豪的情绪变化**

```
【第一阶段：震惊】
50万？
这个废物哪来的50万？
他不是负债500万吗？

【第二阶段：不信】
一定是在装逼。
装完逼付不起钱，等下看他怎么下台。

【第三阶段：恼怒】
但服务员的态度……
不对，这不是装逼。
这小子是真有钱。
怎么可能？
一股无名火从心底窜起。
```

#### 【第3层：对话设计】

**林诗雨的试探**

```
萧烬刚走到包厢门口，身后传来林诗雨的声音。
"萧烬，等一下。"
她快步走上来，脸上带着一丝尴尬的笑。
"好久不见了，你……最近过得不错？"
萧烬停下脚步，转头看她。
目光平静，像是在看一个陌生人。
"还行。"
"我……"林诗雨犹豫了一下，"我们能聊聊吗？以前……我们的关系还是挺好的，对吧？"
她试探性地靠近了一步。
萧烬没有动。
"我知道分手的事，可能让你觉得……但其实我一直……"
"林小姐。"萧烬打断她。
林小姐。
不是诗雨，是林小姐。
林诗雨的笑容僵住了。
"我们没什么好聊的。"
萧烬转身，推开了包厢的门。
"如果你觉得我以前对你有什么感情，现在可以告诉你——"
他顿了顿。
"那是原来那个萧烬。"
"和我无关。"
包厢门关上。
林诗雨愣在原地，脸色惨白。
```

**王天豪的发难**

```
王天豪走上来，脸色铁青。
"萧烬，你什么意思？"
他一把推开包厢门，怒气冲冲地走进去。
"装什么大款？你以为点个50万的宴席就能在我面前炫耀？"
萧烬正坐在沙发上，看着菜单。
听到声音，他抬起头。
"哦，是你。"
"你——"
"王公子，我记得你刚才说5万一桌？"萧烬放下菜单，似笑非笑，"现在看来，好像不太够。"
王天豪的脸涨红了。
"你少在这装逼！你一个负债500万的废物，哪来的钱？"
"债已经还清了。"萧烬淡淡地说，"就在今天上午。"
王天豪愣住了。
"500万……你还清了？"
"顺便还剩了点零花钱。"萧烬笑了笑，"比如，点一桌50万的宴席。"
空气仿佛凝固了。
林诗雨在门口，脸色更加苍白。
三天。
仅仅三天。
他就从负债500万变成了能随手挥霍的富豪。
她……是不是做错了什么？
```

#### 【第4层：萧烬的内心】

```
【面对林诗雨时】
前女友？
萧烬对这个词没什么感觉。
那是原身的记忆，不是他的。
十万年魔尊，见过的美人不计其数，对情爱早已看淡。
更何况，是一个背叛过自己（原身）的女人。
他没有恨意，只是不在意。
就像看一只曾经咬过自己的蚂蚁。
蚂蚁以为自己很重要，其实根本无足轻重。

【面对王天豪时】
这种人，前世他见得太多了。
修仙界里，总有一些世家子弟，仗着家族的势力欺压他人。
结果呢？
在真正的强者面前，连蝼蚁都不如。
王天豪？
呵，他连给前世那些世家子弟提鞋都不配。
```

#### 【第5层：闲笔】

```
【闲笔2】林诗雨的首饰（约40字）
萧烬注意到林诗雨脖子上戴着一条项链。
不是他当年送的那条。
是一条钻石项链，看起来价值不菲。
他没说什么，只是收回了目光。

【闲笔3】王天豪的表（约30字）
百达翡丽，限量款，市价三百万左右。
萧烬扫了一眼就认出来了——原身的记忆里有。
不过……也就这点档次了。
```

## 六、场景四：王天豪威胁+被轰（480-570字）

### 场景定位
本章收尾，要完成：
1. 王天豪的威胁（反派立Flag）
2. 酒店经理登场，反转
3. 王天豪被轰
4. 埋下后续伏笔

### 五层展开

#### 【第1层：事件】
王天豪威胁 → 酒店经理登场 → 经理认出萧烬 → 王天豪被轰 → 埋伏笔

#### 【第2层：对话设计】

**王天豪的威胁**

```
王天豪深吸一口气，强压下怒火。
"萧烬，你以为有几个臭钱就能翻天了？"
他上前一步，盯着萧烬。
"你知道我是谁吗？建业集团，听说过吗？我爸的公司，市值上百亿。"
他冷笑一声。
"你现在跪下给我道歉，我还能让你好过一点。否则——"
"否则怎样？"
萧烬饶有兴趣地看着他。
"否则我让你在这个城市混不下去！"王天豪咬牙切齿。
萧烬笑了。
"有意思。"
他站起身，走到王天豪面前。
两人相距不到一米。
萧烬比王天豪高半个头，俯视着他。
"王公子，我送你一句话。"
他的声音很轻，但每个字都清清楚楚。
"在威胁别人之前，先掂量一下自己有几斤几两。"
王天豪的瞳孔猛然收缩。
他感觉到了一股压迫感——从萧烬身上散发出来的、让他喘不过气的压迫感。
就在这时——
```

**酒店经理登场——反转**

```
"萧先生！"
一个穿着西装的中年人快步走进来，满脸堆笑。
"萧先生，您来了怎么不提前通知一声？我好安排迎接啊！"
酒店经理李铭，亲自跑来迎接。
王天豪愣住了。
酒店经理？
萧烬？
李铭认识萧烬？
"李经理。"萧烬点点头，"随便来吃个饭。"
"哎呀，萧先生您太客气了！"李铭一边说，一边用眼角余光扫了一眼王天豪和林诗雨。
眼神里带着一丝厌恶。
"这两位是……"
"不认识。"萧烬说，"而且他们打扰到我吃饭了。"
李铭立刻会意。
他转过身，脸色一变。
"王公子，林小姐，请离开。"
王天豪的脸涨成了猪肝色。
"李铭，你什么意思？我可是建业集团的少东家！"
"我知道。"李铭淡淡地说，"但江南天下不欢迎打扰贵客的人。请。"
两个保安走上来，一左一右站在王天豪身边。
王天豪想说什么，但保安已经架住了他的胳膊。
"放开我！你们知道我是谁吗？"
没有人理他。
林诗雨跟在后面，脸色惨白，不敢说话。
```

#### 【第3层：章末钩子】

```
包厢门关上，安静下来。
萧烬坐回沙发，继续看菜单。
李铭在一旁小心翼翼地说："萧先生，王天豪这人……您要不要我查查他的底细？"
萧烬摇摇头。
"不用。"
他翻了一页菜单。
"一个跳梁小丑而已。"
但他心里清楚，今天这件事不会这么简单结束。
王天豪这种人，睚眦必报。
被当众打脸，他一定会找机会报复。
不过……
萧烬嘴角微微上扬。
他还真有点期待。
毕竟，杀鸡儆猴，需要一只足够愚蠢的鸡。
王天豪，很合适。

【章末悬念】
另一边，被轰出酒店的王天豪，眼睛里满是阴毒。
"萧烬……"
他咬牙切齿。
"你等着。"
他掏出手机，拨通了一个号码。
"喂，是我。帮我查一个人……萧烬。查清楚他的一切。"
"另外，联系一下那边的人。"
```

## 九、对话设计要点

### 萧烬的对话风格

```
1. 简短——能用一个字绝不用两个字
   ✓ "还行。"
   ✓ "不必了。"
   ✗ "我过得还可以，谢谢你的关心。"

2. 疏离——不带任何情绪
   ✓ "林小姐，我们没什么好聊的。"
   ✗ "诗雨，我不想再提以前的事了。"

3. 偶尔带点玩味——对跳梁小丑的俯视
   ✓ "有意思。"
   ✓ "王公子，我记得你刚才说5万一桌？"
```

### 王天豪的对话风格

```
1. 炫耀时——故意强调数字
   "5万一桌"、"市值上百亿"

2. 恼怒时——暴露底线
   "你以为有几个臭钱就能翻天了？"

3. 威胁时——搬出家族
   "你知道我是谁吗？建业集团！"
```

### 林诗雨的对话风格

```
1. 试探——犹豫、不确定
   "我们能聊聊吗？以前……我们的关系还是挺好的，对吧？"

2. 被拒绝后——沉默
   她不敢再说话了。
```

## 十一、禁忌清单

### 语言禁忌

| 禁用词 | 替换为 |
|-------|--------|
| 眸子 | 眼睛 |
| 心中暗道 | 心想 / 直接写想法 |
| 唇角勾起 | 笑了 / 嘴角上扬 |
| 不由得 | 删除 |
| 沉吟 | 想了想 |
| 赫然 | 竟然 |

### 内容禁忌

- ❌ 萧烬主动炫耀——他是被动反击，不是主动装逼
- ❌ 林诗雨太贱——她有自己的逻辑，不能是纯反派
- ❌ 王天豪太蠢——他有资本，不是纯小丑
- ❌ 打脸太过瘾——保持克制，不要变成发泄文
- ❌ 忘记内心活动——萧烬的魔尊心态要贯穿始终

## 十三、本章预期效果

**读者读完第6章，应该：**

1. **觉得爽**：50万打脸5万，林诗雨后悔，王天豪被轰
2. **认识到萧烬的性格**：冷漠、不在意、魔尊的骄傲

- 萧烬在主动装逼
- 打脸太过爽，变成发泄文
- 林诗雨是纯反派
- 王天豪是纯小丑
- 剧情太老套
