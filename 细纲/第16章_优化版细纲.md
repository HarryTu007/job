王天豪不死心，花重金请来一名化劲中期的古武高手来报复。萧烬正好陪林小满在商场购物，遭遇伏击。萧烬一招制敌，王天豪彻底崩溃。萧烬警告王建业：三天内卖掉建业集团，否则后果自负。

## 三、场景一：商场购物+温馨日常（800-1000字）

### 场景定位
承接第15章，萧烬陪林小满逛商场。目的是：
1. 展现两人感情升温
2. 林小满的天真可爱
3. 为后续伏击形成反差

### 五层展开

#### 【第1层：事件】
萧烬陪林小满逛商场 → 林小满试衣服 → 温馨互动 → 准备离开

```

2. 林小满的装扮：
   - 白色连衣裙，长发披肩
   - 脸上带着开心的笑容

3. 萧烬的状态：
   - 穿着简单的白T恤和牛仔裤

```
1. 背景音：

   - "萧烬哥哥，你看这个好不好看？"

**萧烬**
```
- 表情平静，但眼神温柔

【内心】萧烬看着她开心的样子，心里有些暖。他活了十万年，从未有人这样拉着他逛街。前世，他高高在上，所有人都敬畏他。但也因此，他从未体验过这种平凡的温馨。
【行动】他任由林小满拉着，跟了进去。

### 具体内容

```
【开场】
商场里人来人往。
萧烬跟在林小满身后，手里提着三个购物袋。
"萧烬哥哥，我们再去那边看看！"林小满拉着他的手臂，指着前面的一家服装店。
萧烬看了一眼她亮晶晶的眼睛，点了点头。
"好。"
他从来不知道，逛街这种事，能让一个人这么开心。
前世他是弑天魔尊，所到之处，万人敬畏。

这种感觉……很好。

【试衣服】
林小满在店里挑了一件淡蓝色的连衣裙，钻进试衣间。
萧烬站在外面等着。
店员看了他一眼，热情地问："先生，需要帮您拿点什么吗？"
"不用。"
萧烬的语气平淡，但店员没有觉得被冷落。
她偷偷打量着萧烬，心想：这个男的气质真好，长得也帅，这女孩真有福气。

【出来展示】
试衣间的帘子拉开。
林小满走出来，脸有点红。
"萧烬哥哥，好看吗？"
她低着头，手指绞着裙角，声音小小的。
萧烬看着她。
淡蓝色的连衣裙，衬得她皮肤更白了。
长发披肩，像瀑布一样。
眼睛亮亮的，带着一丝羞涩。
他忽然想起，前世他见过无数美人。
但没有一个，让他有这种感觉。
"好看。"他说。
林小满的眼睛一下子亮了起来，像星星一样。
"真的吗？"
"真的。"
林小满开心地转了一圈，裙摆扬起，像一朵盛开的花。
```

## 五、场景三：王天豪崩溃+霸气警告（1200-1500字）【核心场景】

### 场景定位
本章爽点集中爆发，要写出：
1. 王天豪的彻底崩溃
2. 萧烬的霸气警告
3. 收购建业集团的宣言
4. 震撼全场的效果

### 五层展开

#### 【第1层：事件】
王天豪崩溃 → 萧烬警告 → 宣布收购 → 放话离开

#### 【第2层：感官细节】

**视觉**
```
1. 王天豪的状态：
   - 脸色惨白，浑身发抖
   - 腿一软，跪在地上
   - 裤裆处有一片湿迹——吓尿了

2. 铁青云的状态：
   - 躺在地上，动弹不得
   - 脸上全是血，不知道是伤口还是喷出来的
   - 眼神空洞，像丢了魂

3. 萧烬的状态：
   - 站在原地，纹丝不动
   - 表情平静，像刚才什么都没发生
   - 眼神冷漠，像在看一群蚂蚁
```

**听觉**
```
1. 停车场很安静，只有汽车警报器还在响

3. 林小满的轻声惊呼
```

#### 【第3层：人物反应】

**王天豪**（情绪崩溃四层法）
```
【第1层：震惊】
铁青云被一招打飞的瞬间，王天豪整个人都傻了。
这不可能！
铁青云可是化劲中期的高手！

**小节B：萧烬霸气警告（约600字）**

```
【萧烬开口】
萧烬看着跪在地上的王天豪，眼神没有任何波动。
"起来。"
王天豪愣了一下，不敢动。
"起来。"萧烬又说了一遍。
王天豪这才颤颤巍巍地站起来，腿还在抖，裤裆处的湿迹特别明显。
"你……你要怎样？"他的声音沙哑。
萧烬没理他，而是转头看向林小满。
"吓到了？"
林小满摇摇头，眼睛亮亮的。
"没有。萧烬哥哥好厉害。"
萧烬嘴角微扬，然后转回头看向王天豪。
"王天豪。"
他的声音很平静，但带着一种不容置疑的威严。
"我给过你机会。一次，两次，三次。"
王天豪的脸更白了。
"你一次次找人来报复我，我都没有追究。"
"我以为你会聪明点。"
"但你偏偏……"萧烬的眼神冷了下来，"要把你身边的人，也搭进来。"
他指了指躺在地上的铁青云。
"他今天能躺在这里，是因为我不想杀人。"
"下一次，就不是躺着了。"

【宣布收购】
王天豪浑身一哆嗦。
"萧……萧先生……我错了……我再也不敢了……"
萧烬打断了他。
"回去告诉你爹。"
他的声音很轻，但每一个字都像锤子一样砸在王天豪心上。
"三天时间。"
"要么，把建业集团卖给我。"
"要么——"
他顿了顿。
"灭门。"
王天豪整个人都懵了。
"什……什么？"
"我说，我要收购建业集团。"萧烬的语气平淡，像在说今天天气不错，"三天时间，你们考虑一下。"
"如果三天后，建业集团还姓王……"
他的眼神扫过王天豪，冰冷刺骨。
"王家，就不用存在了。"
王天豪的腿一软，差点又跪下去。
收购建业集团？
他们王家的产业，市值几十亿的建业集团？
这个人……疯了吗？
但看着萧烬的眼神，他忽然觉得——
这个人，说到做到。
```

## 十二、本章预期效果

**读者读完第16章，应该：**

1. **觉得爽**：王天豪彻底崩溃，萧烬霸气碾压
2. **期待收购**：三天后建业集团会怎样？
3. **感受甜蜜**：萧烬和林小满的互动很甜
4. **记住名场面**：一招秒杀、尿裤子、灭门警告
5. **好奇后续**：王建业会怎么反应？

**读者不应该觉得：**
- 战斗太长、太拖沓
- 王天豪太小丑化
- 林小满没有存在感
- 警告不够霸气
