# 第15章：苏震天古武者身份揭晓，拜访诊所（优化版细纲）

**类型**：铺垫章节 | **建议字数**：4000-5000字（以写透为准，不硬性限制）

---

## 一、核心事件

苏震天带着礼物来诊所拜访，展现古武者身份（暗劲巅峰），请求萧烬指点。萧烬点拨几句，苏震天当场突破到化劲初期。苏震天彻底服气，正式认可萧烬，并透露古武界的一些信息。本章核心是"苏震天臣服+古武界信息"。

---

## 三、场景一：苏震天拜访（800-1000字）

### 五层展开

#### 【第1层：事件】
苏震天带礼物来诊所 → 态度恭敬 → 林小满惊讶

#### 【第2层：苏震天登场】

```
上午十点。
天机诊所门口停了一辆黑色奔驰。
苏震天从车上下来，手里提着两盒礼品。
他穿着一身休闲装，和上次在茶馆的气势完全不同。
少了几分狠辣，多了几分和气。
"爸？"
林小满从诊所里出来，看到苏震天，愣住了。
"你怎么来了？"
苏震天笑了笑。
"来看看你，顺便拜访一下萧先生。"
林小满狐疑地看着他。
她爸可是地下势力的大佬，什么时候这么客气了？
"萧先生在吗？"苏震天问。
"在……在里面……"
苏震天点点头，提着礼品走进诊所。
林小满跟在后面，一脸茫然。
她总感觉，最近她爸对萧烬的态度变得很奇怪。
从之前的债主变成了……恭敬？
发生了什么？
```

#### 【第3层：进入诊所】

```
诊所里，萧烬正在给一个病人把脉。
看到苏震天进来，他抬了抬眼皮。
"苏叔叔。"
"萧先生。"苏震天把礼品放在桌上，"一点小意思，不成敬意。"
萧烬看了一眼那两个盒子。
茅台和野山参。
价值不菲。
"坐吧。等我看完这个病人。"
"不急不急。"苏震天找了个角落坐下，老老实实等着。
林小满在旁边看着，越来越觉得奇怪。
她什么时候见她爸这么乖过？
十分钟后。
病人离开，萧烬转向苏震天。
"苏叔叔今天来，应该不只是送礼吧？"
苏震天搓了搓手，有些不好意思。
"萧先生果然厉害，什么都瞒不过您。"
他深吸一口气。
"其实……我是来请教的。"
```

## 四、场景二：请求指点+点拨（1280-1520字）【核心场景】

### 五层展开

#### 【第1层：事件】
苏震天说明来意 → 展现古武者身份 → 萧烬点拨

#### 【第2层：苏震天的请求】

```
"请教？"萧烬挑眉。
苏震天站起身，走到萧烬面前。
"萧先生，不瞒您说，我是古武者。"
他运转体内的暗劲，手掌上泛起一层淡淡的光芒。
林小满惊呼一声。
"爸，你……"
她从来不知道，她爸还会这个。
苏震天笑了笑。
"小满，这是暗劲。是古武者的标志。"
他收回暗劲，看向萧烬。
"我练武三十年，十年前突破到暗劲巅峰。"
"但这十年来，一直卡在这个境界，无法寸进。"
他的语气带着一丝苦涩。
"找过很多高人指点，都没有用。"
"直到那天在茶馆，我见识到萧先生的实力……"
他深深鞠了一躬。
"萧先生，求您指点！"
```

#### 【第3层：萧烬的诊断】

```
萧烬看着他，沉默了几秒。
"把手伸出来。"
苏震天连忙伸出手。
萧烬的手指搭在他的脉搏上，精神力渗入他的身体。
他很快就发现了问题。
"你的瓶颈，不在修炼方法。"萧烬说，"而在心境。"
苏震天愣了一下。
"心境？"
"暗劲到化劲，不仅是力量的提升，更是心境的蜕变。"
萧烬收回手。
"你杀伐果断，心狠手辣，这在暗劲期是优势。"
"但到了化劲，你需要的不是狠，而是静。"
苏震天皱眉。
"静？"
"心如止水，才能感受到力量的真正流动。"萧烬说，"你心里杂念太多，执念太深，所以无法突破。"
苏震天沉默了。
杂念？执念？
他想起了很多事。
年轻时的恩怨，地下势力的争斗，家族的责任……
这些年，他确实一直绷着一根弦。
从来没有真正放松过。
```

#### 【第4层：萧烬的点拨】

```
"我教你一个方法。"
萧烬站起身。
"闭上眼睛，放空心神。"
苏震天照做。
"想象自己站在一片平静的湖面上。"
"湖水很清澈，能看到底。"
"你的心，就是那片湖水。"
萧烬的声音低沉平稳，带着一种说不出的力量。
"所有的杂念，都是落入湖中的石子。"
"它们会激起涟漪，但涟漪终会平息。"
"你要做的，不是压制杂念，而是任由它们来去。"
"来了，不追；去了，不留。"
苏震天认真地听着。
他按照萧烬说的，想象自己站在湖面上。
一开始，脑海里乱糟糟的。
各种念头不断冒出来。
但他没有强压，而是任由它们飘过。
渐渐的，那些念头越来越少。
心，慢慢静了下来。
```

## 五、场景三：当场突破（1000-1250字）【核心场景】

### 五层展开

#### 【第1层：突破瞬间】

```
五分钟后。
苏震天的身体忽然一震。
一股强大的气息从他体内爆发出来。
"轰——"
气浪四散，桌上的茶杯都被震得叮当作响。
林小满惊叫一声，往后退了几步。
"爸！"
苏震天睁开眼睛。
他的眼神和之前完全不同了。
之前是锐利、狠辣。
现在是平静、深邃。
像是一潭幽深的湖水。
"这……这是……"
他低头看了看自己的双手。
他能感觉到，体内的力量比之前强了不止一倍。
而且那股力量，不再像之前那样躁动。
而是平稳、沉静，完全在他的掌控之中。
"化劲……"
他的声音发颤。
"我突破了？！"
```

#### 【第2层：苏震天的震惊】

```
苏震天整个人都傻了。
化劲！
他卡了十年的瓶颈！
就这么……突破了？
萧烬只是说了几句话，他就突破了？
"这……这怎么可能……"
他看向萧烬，眼神里满是难以置信。
"萧先生，您……您到底是什么人？"
萧烬喝了口茶，表情淡然。
"只是指出了你的问题而已。能不能突破，看的是你自己。"
苏震天摇头。
"不，萧先生太谦虚了。"
他走到萧烬面前，再次深深鞠躬。
"如果没有您的点拨，我可能这辈子都突破不了。"
"这份恩情，苏某铭记于心！"
林小满在旁边看着，目瞪口呆。
她从没见过她爸这样。
天海市地下势力的扛把子，在一个年轻人面前，恭敬得像个学生。
萧烬哥哥……到底有多厉害？
```

#### 【第3层：正式认可】

```
"起来吧。"萧烬说。
苏震天直起身，眼眶有些红。
十年了。
他等这一刻，等了十年。
"萧先生，从今以后，您就是我苏震天的恩人。"
他看着萧烬，语气真诚。
"以后有什么需要苏某帮忙的，尽管开口。"
"只要我能做到的，绝不推辞。"
萧烬看了他一眼。
"有一件事。"
"萧先生请说！"
萧烬指了指旁边的林小满。
"她，我会好好对待。"
苏震天愣了一下，然后笑了。
笑得很开心。
"好！好！"
他拍了拍萧烬的肩膀。
"萧先生，不，萧兄弟！以后咱们就是一家人了！"
林小满的脸瞬间红透了。
"爸！你说什么呢！"
"哈哈哈！"苏震天大笑，"没说什么没说什么！"
气氛一下子轻松了很多。
```

## 六、场景四：古武界信息+收尾（600-750字）

### 五层展开

#### 【第1层：古武界信息】

```
笑过之后，苏震天坐下来，和萧烬聊起了正事。
"萧先生，您对古武界了解多少？"
萧烬摇头。
"不太了解。"
苏震天点点头。
"古武界，是一个隐藏在普通人世界背后的圈子。"
他慢慢说道。
"古武者通过修炼内力，可以做到普通人做不到的事。"
"暗劲期可以隔空击物，化劲期可以气罩全身……"
"更高的境界，听说能飞天遁地，甚至长生不老。"
萧烬听着，嘴角微微上扬。
古武界的所谓"高手"，在修仙者眼里，不过是入门级别。
但他没有说破。
"古武界有什么势力？"他问。
"主要有两个。"苏震天说，"一个是古武联盟，一个是天道门。"
"古武联盟是正道势力的联合体，天道门则是……比较神秘。"
他压低声音。
"有传言说，天道门背后有更强大的势力支撑。"
"更强大的势力？"
"是的。"苏震天说，"据说是……修仙者。"
```

#### 【第2层：章末伏笔】

```
萧烬的眼神微微一变。
修仙者。
看来，修仙界在凡俗世界的布局，比他想象的更深。
"下个月，古武联盟会在天海市举办一场古武大会。"苏震天说，"萧先生有兴趣吗？"
"古武大会？"
"是的。各方势力都会派人参加，是展示实力、结交人脉的好机会。"
苏震天看着萧烬。
"以萧先生的实力，去了绝对会一鸣惊人。"
萧烬想了想。
"到时候再说。"
他站起身，走到窗前。
窗外，阳光明媚。
修仙者……古武联盟……天道门……
这个世界，越来越有意思了。
他感觉，很快就会有大事发生。
而他，已经准备好了。
```
