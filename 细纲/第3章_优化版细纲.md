# 第3章：炼制美容丹，赚取第一桶金（优化版细纲）

**类型**：铺垫章节 | **建议字数**：4000-5000字（以写透为准，不硬性限制）

---

## 一、核心事件

萧烬利用《基础炼丹术》炼制美容丹，通过地下市场出售给贵妇李雅琴，赚取第一桶金45万。展现前世炼丹大师的实力，李雅琴惊叹丹药效果。

---

## 三、场景一：寻找材料（600-800字）

### 场景定位
承接第2章结尾，萧烬出门找材料。目的是：
1. 展现萧烬对灵草的辨识能力
2. 引出"地下市场"的概念
3. 快速推进，不要拖沓

### 中药店场景

**进店**：

```
萧烬在城西找到一家老字号中药店。
门面不大，但药香扑鼻，柜台后面的药柜密密麻麻，摆满了各种药材。
他推门进去，店里只有一个老人坐在柜台后面，戴着老花镜，正在看报纸。
"买什么药？"老人头也没抬。
萧烬没有回答，而是走到药柜前，开始扫视。
他的目光很快锁定了几样东西。
```

**萧烬的观察**（展现专业性）：

```
角落里有一株枯萎的草，被随意扔在一边，应该是准备丢掉的。
萧烬走过去，拿起来看了看。
茎是青色的，叶片边缘有锯齿，根部有一圈淡淡的光晕——这光晕普通人看不到，但在萧烬眼里清晰可见。
青灵草。
品相不好，但药性还在。
他又看向另一边。
一个小瓷瓶里装着几颗红色的果实，标签上写着"枸杞（陈年）"。
萧烬拿起来，凑近闻了闻。
不是枸杞。
是赤灵果。
这东西在修仙界是炼制筑基丹的辅材，价值连城。但在这里，被当成过期的枸杞，卖20块钱一瓶。
萧烬笑了笑。
捡到宝了。
```

**购买**：

```
"老板，这些多少钱？"
萧烬把那株枯草和那瓶"枸杞"放到柜台上。
老人抬起头，瞟了一眼："那草要扔的，不卖。枸杞过期了，你确定要？"
"确定。"
"那……10块钱吧。"
萧烬付了钱，把东西收好。
他又在店里转了一圈，又挑了几样看起来不起眼的药材——普通人眼里的废料，在他眼里都是宝贝。
一共花了不到50块钱。
出门的时候，萧烬看了一眼手里的东西。
足够炼制三颗美容丹了。
```

### 地下市场的引出

```
但还差一样东西。
炼丹炉。
普通的锅具也能凑合，但效率太低，而且很难控制火候。
他需要一个真正的炼丹炉，哪怕是最基础的那种。
萧烬在原身的记忆里搜索了一下，发现这个城市确实有一些"地下渠道"，专门卖一些见不得光的东西。
古董、赃物、甚至……
一些"来历不明"的古怪器具。
他决定去看看。
说不定能找到惊喜。
```

### 地下市场初探（简略）

```
地下市场在城南的一条老巷子里，入口是一家古董店。
萧烬走进去，报了一个暗号——这是原身在网上偶然看到的，没想到真的管用。
店主是个瘦削的中年人，上下打量了他一眼，带他走进后面的暗门。
暗门后是一个很大的地下空间，灯光昏暗，摆满了各种稀奇古怪的东西。
萧烬扫了一圈，在角落里发现了一个落灰的铜炉。
他走过去，拿起来看了看。
材质一般，但阵纹还算完整。
是一个初级炼丹炉——不知道是哪个野路子修士留下的，流落到了这里。
"这个多少钱？"
"三万。"店主狮子大开口。
萧烬没有还价："成交。"
他现在没钱，但他可以先赊账。
刚才进来的时候，他注意到店主的脸色发暗，肝火旺盛，多半有什么隐疾。
"老板，我看你气色不太好，是不是最近睡眠不好，脾气暴躁？"
店主愣了一下，警惕地看着他："你什么意思？"
"我是医生。"萧烬笑了笑，"这炉子我赊账，等我治好你的病，再付钱。怎么样？"
```

**关键点**：
- 快速推进，不要在寻找材料上花太多笔墨
- 展现萧烬的"眼力"——能认出别人不认识的灵草
- 引出地下市场，为后续剧情铺垫
- 赊账买炉子，展现萧烬的灵活和自信

## 四、场景二：炼丹过程（1600-2000字）【核心场景】

### 场景定位
这是本章第一个核心场景，要写出：
1. 炼丹的专业感（不是随便煮一煮）
2. 萧烬的大师风范（轻车熟路，游刃有余）
3. 一定的仪式感和视觉冲击力

### 场景拆分

**小节A：准备工作（约300字）**
**小节B：炼丹过程——起炉、投药、控火、凝丹（约1000字）**
**小节C：成丹——效果展示（约400字）**

---

### 小节A：准备工作（约300字）

**环境布置**：

```
回到出租屋，萧烬把东西摆好。
炼丹炉放在桌上，材料摆在一旁。
他打开窗户，让空气流通——炼丹会产生一些异味，不通风的话，整栋楼都能闻到。
然后，他从系统里调出那张【初级聚灵阵图纸】。
图纸很简单，只需要几块灵石作为节点，就能布置出一个小型聚灵阵。
但他没有灵石。
萧烬想了想，用那几颗赤灵果代替。
赤灵果虽然不是灵石，但含有微弱灵气，勉强能用。
他按照图纸的指示，把赤灵果摆在炼丹炉周围的几个关键位置。
然后，注入一丝灵气。
"嗡——"
空气中传来一阵轻微的震动。
聚灵阵……启动了。
```

**萧烬的状态**：

```
萧烬闭上眼睛，感受着周围的灵气变化。
聚灵阵的效果比他预想的要好。
方圆百米内的灵气正在缓缓汇聚，虽然速度很慢，但已经足够炼制美容丹了。
他睁开眼睛，看向炼丹炉。
眼神，逐渐变得专注。
十万年了。
他有多久没有炼过丹了？
```

### 小节B：炼丹过程（约1000字）

**这是本章最重要的部分，要有专业感和仪式感。**

**起炉（约200字）**：

```
萧烬伸出手，按在炼丹炉上。
一缕灵气从指尖涌入炉底。
炉子开始发热。
普通的火焰在凡俗界炼丹几乎不可能成功，温度不够，也不够纯净。但修士可以用灵气催动炉火——这是炼丹最基本的技巧。
萧烬的灵气很微弱，只有炼气期三层，但他的控制极其精准。
炉火从淡蓝色逐渐变成深蓝色，最后稳定在一种近乎透明的状态。
这是最适合炼制美容丹的温度。
不高不低，刚刚好。
萧烬前世炼过无数次丹，这些步骤早已刻入骨髓，根本不需要思考。
```

**投药（约300字）**：

```
第一味药材：青灵草。
萧烬把那株枯萎的草放入炉中。
草叶在高温下迅速卷曲，然后化成一团青色的雾气，在炉中缓缓旋转。
第二味药材：白芷。
这是中药店买的普通白芷，没有灵性，但萧烬用灵气淬炼了一下，激发出了其中微弱的药性。
白芷化成白色的雾气，与青色的雾气交融在一起。
第三味药材：蜂蜜。
没错，就是普通的蜂蜜。
美容丹的配方很简单，关键不在于材料有多珍贵，而在于炼丹师的手法和火候。
蜂蜜化开，金色的液体在炉中流转，把青色和白色的雾气包裹起来。
三种颜色交织在一起，像是一幅流动的画。
```

**控火（约300字）**——这是炼丹最难的部分：

```
萧烬的眉头微微皱起。
接下来才是最关键的步骤——控火。
美容丹虽然是最基础的丹药，但对火候的要求极高。
温度高一分，药性就会流失；低一分，药材就无法完全融合。
萧烬必须在一个极其狭窄的温度区间内，保持炉火的稳定。
他闭上眼睛，用神识感知炉内的变化。
温度在攀升……
还差一点……
再高一点点……
到了！
萧烬的眼睛猛然睁开，手指一动。
炉火瞬间稳定住，不高不低，刚好卡在临界点上。
如果有其他炼丹师在场，一定会惊掉下巴。
这种控火的精准度，别说炼气期，就是金丹期的炼丹师都做不到。
但对萧烬来说，这只是基本功。
他前世炼制过的丹药数以万计，其中不乏九品神丹。区区美容丹，简直是大材小用。
```

**凝丹（约200字）**：

```
炉内的三色雾气开始凝聚。
青、白、金三种颜色缓缓旋转，最终融为一体，化成一颗晶莹剔透的药丸。
丸身通透，隐隐有流光浮动。
这是丹药成形的标志。
萧烬收回灵气，炉火熄灭。
他伸手，从炉中取出那颗药丸。
药丸温热，散发着淡淡的清香。
萧烬看着手里的丹药，嘴角微微上扬。
成了。
而且……
他仔细端详了一下药丸表面的纹路。
丹纹清晰，药性饱满。
这颗美容丹的品质，比他预想的还要好。
"上品。"
萧烬轻声说道，语气里带着一丝满意。
他本来只是想炼一颗普通的美容丹，没想到一出手就是上品。
看来，虽然境界跌落了，但手艺还在。
```

### 小节C：成丹——效果展示（约400字）

**萧烬自己试药**（展现丹药效果）：

```
萧烬没有急着卖丹药，而是先拿了一面镜子。
他看着镜子里的自己。
原身长得不差，五官端正，皮肤白皙。但因为最近的遭遇，整个人憔悴了很多，眼下有明显的黑眼圈，皮肤也有些暗沉。
萧烬把那颗美容丹一分为二。
这颗是上品丹，药效很强，普通人用半颗就够了。
他把半颗丹药放进嘴里，咽下去。
丹药入腹，瞬间化成一股暖流，涌向全身。
他能感觉到，那股暖流正在修复他的皮肤——清除暗沉，淡化细纹，甚至连一些微小的瑕疵都在消失。
几分钟后，他再次看向镜子。
变化很明显。
黑眼圈淡了，皮肤亮了，整个人看起来年轻了好几岁。
而这，只是半颗丹药的效果。
萧烬满意地点了点头。
可以卖钱了。
```

**炼制更多丹药**：

```
接下来的两个小时，萧烬又炼制了两颗美容丹。
加上之前那颗（剩下半颗），一共是两颗半。
按照他的估算，一颗上品美容丹在这个世界至少能卖20万。
两颗半，就是50万。
足够还债了。
但他不打算一次性全卖掉。
先卖一颗试试水，看看市场反应。
剩下的，留着以后用。
```

```
【闲笔2】丹药的香味（约50字）

```

## 五、场景三：交易李雅琴（1400-1800字）【核心场景】

### 场景定位
这是本章第二个核心场景，要写出：
1. 李雅琴的形象（贵妇，有见识，不是纯冤大头）
2. 丹药效果的震撼
3. 商业谈判的过程（不是简单的"给钱拿货"）

### 场景拆分

**小节A：联系李雅琴（约200字）**
**小节B：见面——李雅琴的形象（约300字）**
**小节C：丹药效果展示——震撼（约500字）**
**小节D：商业谈判——加价+长期合作（约500字）**

---

### 小节A：联系李雅琴（约200字）

**引出李雅琴**：

```
萧烬在原身的记忆里找到了一个人——李雅琴。
李雅琴是本地有名的贵妇，经常出入各种高端美容院和私人会所。
原身以前在一家广告公司上班，有一次接过李雅琴公司的单子，加过微信。
萧烬翻出微信，给她发了一条消息：
【李女士，我这里有一款私人定制的美容产品，效果非常好。方便见一面吗？】
很快，李雅琴回了消息：
【你是？】
【萧烬，之前帮您公司做过广告。】
对方沉默了一会儿，然后回复：
【下午三点，XX咖啡厅。】
```

---

### 小节B：见面——李雅琴的形象（约300字）

**咖啡厅场景**：

```
下午三点，萧烬准时到达咖啡厅。
李雅琴已经在了。
她坐在角落的卡座里，穿着一身香奈儿套装，妆容精致，保养得很好。
四十岁出头的年纪，看起来像三十多。
萧烬走过去，坐下。
"萧先生？"李雅琴打量了他一眼，眼神里带着点惊讶，"你看起来……和我印象中不太一样。"
萧烬知道她在说什么。
原身以前见李雅琴的时候，唯唯诺诺的，一副打工人的样子。
但现在的他，气质完全不同。
"人总是会变的。"萧烬笑了笑，开门见山，"李女士，我这次来，是想给你介绍一款产品。"
```

**李雅琴的反应**（不是纯冤大头）：

```
李雅琴挑了挑眉："什么产品？"
"美容产品。"
"我每年在美容上的花费超过百万，"李雅琴端起咖啡，语气淡淡的，"什么产品我没见过？"
萧烬没有反驳，而是从口袋里拿出一个小瓷瓶，放在桌上。
"这个。"
李雅琴看了一眼那个瓶子，没有动。
"萧先生，我很忙。如果你是想推销什么三无产品，那我们就没什么好谈的了。"
萧烬笑了笑："李女士，你可以先试试效果。如果不满意，我分文不取。"
```

### 小节C：丹药效果展示——震撼（约500字）

**试用丹药**：

```
李雅琴看着萧烬，沉默了几秒。
她见过太多推销的人，但萧烬的自信让她有点好奇。
"好，我试试。"
她打开瓷瓶，倒出半颗药丸。
药丸晶莹剔透，散发着淡淡的清香。
李雅琴闻了闻，皱起眉头："这是什么？丹药？"
"可以这么理解。"
"我以为你要给我推销什么面膜或者精华，"李雅琴失笑，"吃的东西，我可不敢随便尝试。"
萧烬没有多说，只是看着她。
李雅琴犹豫了一下，最终还是把药丸放进了嘴里。
不是因为她信任萧烬，而是因为……她确实好奇。
这颗药丸的卖相太好了，不像是普通的东西。
```

**效果展现**：

```
丹药入口即化，一股暖流从胃部涌向全身。
李雅琴的表情变了。
她能感觉到，自己的皮肤正在发生变化。
不是那种缓慢的、需要坚持使用才能看到的变化，而是立竿见影的、肉眼可见的变化。
她急忙从包里掏出镜子。
镜子里的自己……
李雅琴愣住了。
脸上那几条细纹——她花了几十万都没能去掉的细纹——淡了。
不是完全消失，但明显淡了很多。
眼角的鱼尾纹，眉间的川字纹，嘴角的法令纹……全都淡了！
而且皮肤亮了，气色好了，整个人看起来年轻了至少五岁！
"这……这不可能……"
李雅琴的声音在发抖。
她做了二十年的美容，从来没见过这么神奇的东西！
```

**萧烬的解释**（点到为止）：

```
萧烬看着她的反应，不紧不慢地说："这只是半颗的效果。整颗的话，至少能年轻十岁。"
李雅琴猛地抬头看向他，眼神里全是震惊。
"这到底是什么东西？"
"我说了，丹药。"萧烬笑了笑，"至于具体是什么，你不需要知道。你只需要知道，它有效。"
李雅琴盯着他看了好几秒，忽然问："你……到底是什么人？"
萧烬没有回答。
```

### 小节D：商业谈判——加价+长期合作（约500字）

**开价**：

```
"这颗丹药，多少钱？"李雅琴直接问。
萧烬伸出两根手指："20万。"
李雅琴没有还价。
20万，对她来说不算什么。每年花在美容上的钱，都不止这个数。
但问题是——
"你还有多少？"
"目前只有这一颗。"萧烬说，"而且，我不打算大量生产。"
李雅琴皱眉："为什么？"
"材料难找，工艺复杂。"萧烬实话实说，"一个月最多炼制五颗。"
```

**李雅琴加价**：

```
李雅琴沉默了一会儿，忽然说："萧先生，我出50万一颗，一个月五颗，全部包了。"
萧烬挑了挑眉。
250万一个月，确实诱人。
但他摇了摇头："不行。"
"为什么？"
"我不做独家生意。"萧烬说，"你可以优先购买，但不能独占。"
李雅琴看着他，眼神复杂。
她做了这么多年生意，见过无数人。但萧烬这种人，她还是第一次见。
明明是在求财，却一点都不卑微。
甚至可以说，有点……高傲。
"好，"她最终点头，"那我出45万，买你这一颗，再加两颗的定金。一共135万，现在就可以转账。"
萧烬想了想，同意了。
"成交。"
```

**李雅琴的身份暗示**：

```
交易完成，李雅琴没有急着离开。
她看着萧烬，忽然说："萧先生，你这个东西……不是普通的药。"
萧烬没有否认。
"我认识一些人，"李雅琴压低声音，"他们可能会对你的东西感兴趣。如果你愿意，我可以帮你引荐。"
萧烬挑了挑眉："什么人？"
李雅琴笑了笑，没有直接回答："你应该知道，这个世界上有一些……普通人接触不到的圈子。"
她站起来，拿起包："等你的丹药炼好了，记得联系我。到时候，我带你去见见那些人。"
说完，她留下一张黑卡，转身离开了。
萧烬看着那张黑卡，陷入了沉思。
这个李雅琴……身份不简单啊。
【伏笔07：李雅琴的身份不简单】
【伏笔14：李雅琴答应介绍人脉】
```

## 八、人物塑造要点

### 萧烬

| 场景 | 表现 | 性格体现 |
|------|------|---------|
| 中药店 | 一眼认出灵草，买了"废料" | 眼力超群、深藏不露 |
| 地下市场 | 赊账买炉子，用医术做筹码 | 灵活、自信 |
| 炼丹 | 控火精准，一次成上品 | 大师风范 |
| 交易 | 不卑不亢，拒绝独占 | 有原则、有傲气 |

### 李雅琴（不要脸谱化）

| 阶段 | 表现 | 心理 |
|------|------|------|
| 刚见面 | 冷淡、不信任 | 见多了推销的人，不感兴趣 |
| 试用丹药 | 震惊、激动 | 从未见过这么神奇的东西 |
| 谈判 | 果断、加价 | 商人的敏锐，想抓住机会 |
| 离开时 | 暗示"圈子" | 她知道一些普通人不知道的事 |

**关键点**：
- 李雅琴是有见识的人，不是被骗的冤大头
- 她愿意出高价，是因为丹药效果真的震撼
- 她的"身份不简单"是后续剧情的重要伏笔

## 九、炼丹场景设计要点

### 炼丹的四个阶段

| 阶段 | 描写重点 | 萧烬的状态 |
|------|---------|----------|
| 起炉 | 灵气涌入、炉火变化 | 专注、平静 |
| 投药 | 药材变化、颜色交融 | 轻车熟路 |
| 控火 | 温度控制、精准度 | 眉头微皱、全神贯注 |
| 凝丹 | 成形、纹路、香味 | 满意、上品 |

### 炼丹的专业感

- 不要写成"把材料放进去，煮一煮就好了"
- 要有具体的步骤、温度变化、颜色变化
- 要体现萧烬的技术——控火精准，别人做不到
- 要有适当的专业术语，但不要堆砌

### 丹药效果的展示

- 不要只说"效果很好"，要有具体的变化
- 用镜子、用李雅琴的反应来展示
- 要有震撼感——"二十年美容，从未见过"

## 十三、本章预期效果

**读者读完第3章，应该：**

1. **觉得专业**：炼丹不是随便煮煮，是有技术含量的
2. **觉得爽**：赚了135万，第一桶金到手
3. **对李雅琴好奇**：她的"圈子"是什么？
4. **期待下一章**：苏震天要来了，还有王天豪的人
5. **开始怀疑**：这个世界真的只有普通人吗？

**读者不应该觉得：**
- 炼丹太水，没有技术含量
- 李雅琴是纯冤大头
- 赚钱太容易，没有难度
- 节奏太慢，看得无聊
