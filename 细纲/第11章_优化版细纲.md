# 第11章：李雅琴介绍人脉，首富千金求医（优化版细纲）

**类型**：铺垫章节 | **建议字数**：3200-3800字

---

## 一、核心事件

李雅琴兑现承诺，带萧烬参加上流社会聚会，介绍商界精英。市首富李建国的女儿李婉儿患有脑瘤，西医宣布只能活三个月，李建国恳求萧烬出手。萧烬同意，但提出条件。本章核心是"人脉拓展+新病人引入"，为后续商业布局和医道展示铺垫。

## 三、场景一：上流社会聚会（800-950字）

### 场景定位
李雅琴兑现承诺，带萧烬进入上流社会。目的是：
1. 展现萧烬在上流社会的从容
2. 贵妇们的态度变化
3. 引出李建国

### 五层展开

#### 【第1层：事件】
李雅琴带萧烬到江南俱乐部 → 介绍给贵妇圈 → 贵妇们从怀疑到争相预约 → 李建国出现

#### 【第2层：感官细节】

**视觉**

```
1. 江南俱乐部：
   - 坐落在市中心黄金地段，外观是民国风格的三层洋楼
   - 门口停着各种豪车，保时捷、宾利、劳斯莱斯
   - 大堂里摆着几盆名贵兰花，价值至少六位数

2. 聚会现场：
   - 二楼的私人会所，装修低调奢华
   - 水晶吊灯、真丝窗帘、红木家具
   - 十几位贵妇围坐在一起，珠光宝气

3. 贵妇们的穿着：
   - 每个人身上的首饰加起来都够买一套房
   - 但萧烬注意到，她们的皮肤状态参差不齐
   - 有几个用了太多医美，反而显得僵硬
```

**听觉**

```
1. 轻柔的古典音乐在背景里播放
2. 贵妇们的笑声，带着上流社会特有的矜持
3. 杯盏碰撞的声音
```

#### 【第3层：对话设计】

**李雅琴介绍**

```
"各位姐姐，这位就是治好我暗疾的萧神医。"
李雅琴挽着萧烬的手臂，语气里带着炫耀。
贵妇们的目光齐刷刷看过来。
一个穿着香奈儿套装的中年女人上下打量萧烬。
"这么年轻？雅琴，你没搞错吧？"
"就是，他看起来才二十出头，能有什么本事？"
李雅琴笑了笑。
"王姐，你的老寒腿，是不是一到阴天就疼？"
那女人愣了一下："你怎么知道？"
"萧先生一眼就看出来了。"李雅琴说，"他说，你这病根在腰椎，不在腿上。治错了地方。"
王姐的脸色变了。
她确实一直在治腿，但效果不好。
"这……"
萧烬站在那里，表情平静，一言不发。
他不需要解释什么。
实力，自己会说话。
```

**贵妇态度转变**

```
接下来的半小时，李雅琴又给萧烬介绍了几位贵妇。
萧烬只是看一眼，就能说出她们身上的毛病。
有的是妇科问题，有的是内分泌失调，有的是早期糖尿病……
每一个都说得准确无误。
贵妇们的态度彻底变了。
"萧先生，您什么时候有空？我想预约看诊……"
"萧先生，我那个……那个问题，能治吗？"
"萧先生……"
萧烬被围在中间，嘴角微微上扬。
人脉，就是这么建立的。
```

#### 【第4层：萧烬的内心】

```
【快速判断】
这些贵妇，身家都不简单。
她们背后是天海市最有权势的家族。
和她们搞好关系，对诊所的发展有很大帮助。
【深度思考】
不过，真正让萧烬感兴趣的，是李雅琴提到的另一个人。
李建国。
天海市首富，身家百亿。
据说他的女儿得了绝症，找遍了全国名医都治不好。
如果能治好……
萧烬的眼睛微微眯起。
那将是一笔巨大的人情。
```

#### 【第5层：闲笔】

```
【闲笔1】一位贵妇的反应（约40字）
有个贵妇想偷偷录音，被萧烬一个眼神吓得立刻收起手机。她不知道为什么，只觉得那一瞬间，脊背发凉。
```

## 四、场景二：李建国求医（1280-1520字）【核心场景】

### 场景定位
本章第一个核心场景，要写出：
1. 李建国的焦虑和恳求
2. 李婉儿病情的严重性
3. 萧烬的从容和条件

### 五层展开

#### 【第1层：事件】
李建国出现 → 说明女儿病情 → 恳求萧烬出手 → 萧烬提条件

#### 【第2层：李建国登场】

```
就在这时，门口传来一阵骚动。
一个五十多岁的男人快步走进来。
贵妇们立刻站起来。
"李总！"
"建国哥，你怎么来了？"
李建国——天海市首富，建国集团董事长。
但此刻，这个身家百亿的富豪，脸上却带着掩饰不住的憔悴。
他扫了一眼屋里的人，目光落在萧烬身上。
"萧先生？"
萧烬点头。
李建国快步走过来，一把握住萧烬的手。
"萧先生，求您救救我女儿！"
他的声音里带着哽咽。
贵妇们面面相觑。
李建国——天海市首富，在商场上呼风唤雨的人物。
此刻却像一个无助的父亲。
```

#### 【第3层：病情说明】

```
李建国带萧烬到角落的沙发坐下。
"萧先生，我女儿婉儿……得了脑瘤。"
他的声音很低，带着颤抖。
"三个月前发现的。看遍了全国最好的医院，做了各种检查。"
他从口袋里掏出一张CT片子。
"医生说……最多还能活三个月。"
萧烬接过片子，对着光看了一眼。
肿瘤位置很刁钻，正好压在脑干附近。
手术风险极大，化疗效果有限。
普通医学，确实很难治。
但对萧烬来说……
"什么时候发现的症状？"他问。
"半年前。"李建国说，"一开始只是头疼，后来越来越严重。上个月开始，视力也模糊了……"
他说着说着，眼眶红了。
"婉儿才25岁……她还那么年轻……"
```

#### 【第4层：萧烬的反应】

**诊断**

```
萧烬没有说话。
他看着那张CT片，眉头微微皱起。
不对。
这个肿瘤的形状……有些奇怪。
普通的脑瘤，生长方式是随机的。
但这个肿瘤，形状过于规整。
像是……被人故意放进去的。
萧烬的眼神变了。
"我需要亲自看看病人。"
"可以！可以！"李建国连忙点头，"我现在就带您去！"
```

**提条件**

```
"等等。"萧烬开口。
李建国愣住了。
"萧先生，您有什么条件尽管说！"
萧烬看着他。
"条件以后再说。先看病人。"
他顿了顿。
"不过我先说清楚，我不保证能治好。"
"我会尽力，但结果如何，要看过病人才知道。"
李建国连连点头。
"明白明白！只要萧先生愿意看，就是我李家的大恩人！"
他站起来，几乎是用跑的往外走。
"萧先生，我们现在就去！"
```

#### 【第5层：萧烬的内心】

```
【深度思考】
这个病，不简单。
从CT片子上看，那个肿瘤的形状太规整了。
像是某种……封印？
萧烬在前世见过类似的东西。
有些修仙者会在凡人体内种下"禁制"，用来控制或者惩罚。
如果李婉儿的肿瘤真的是禁制……
那她得罪的人，绝不简单。
不过，这也让萧烬更感兴趣了。
凡俗界，竟然还有修仙者的痕迹？
有意思。
```

## 五、场景三：初步诊断李婉儿（800-950字）【核心场景】

### 场景定位
本章第二个核心场景，要写出：
1. 李婉儿的状态
2. 萧烬的诊断
3. 发现异常——仙宗印记

### 五层展开

#### 【第1层：事件】
到达李家 → 见到李婉儿 → 萧烬诊断 → 发现印记

#### 【第2层：李婉儿登场】

```
李家别墅。
李建国带萧烬来到二楼的病房。
房间布置得很温馨，但空气里弥漫着一股消毒水的味道。
床上躺着一个年轻女孩。
李婉儿，25岁。
曾经应该是个很漂亮的女孩。
但现在，她脸色苍白，眼窝深陷，瘦得几乎皮包骨头。
头发因为化疗掉了大半，用一条丝巾包着。
她睁开眼睛，看到萧烬，眼神里带着一丝迷茫。
"爸……这是……"
"婉儿，这是萧神医。"李建国强撑着笑容，"他来给你看病。"
李婉儿轻轻点了点头。
她太虚弱了，连说话的力气都没有。
```

#### 【第3层：萧烬诊断】

```
萧烬走到床边，伸出手。
"把手给我。"
李婉儿伸出手。
手指瘦得像柴火棍。
萧烬的手指搭在她的脉搏上，闭上眼睛。
他的精神力悄悄渗入李婉儿的身体。
果然。
他感觉到了。
在李婉儿的脑部，有一团黑色的能量。
那不是普通的肿瘤。
那是一道禁制。
而且，是修仙界的禁制。
萧烬的眼神微微一变。
他继续探查，发现了更多的东西。
李婉儿的心脏位置，有一个淡淡的印记。
那个印记……很眼熟。
萧烬在前世见过。
那是仙宗的标记。
```

#### 【第4层：萧烬的发现】

```
【内心震惊】
仙宗印记？
萧烬强压下心中的惊讶。
仙宗，是前世修仙界的顶级势力之一。
他们怎么会在凡俗界留下印记？
而且还是在一个普通女孩身上？
除非……
萧烬看向李建国。
这个天海市首富，背景恐怕不简单。
他的女儿身上有仙宗印记，说明李家和修仙界有联系。
这件事，比他想象的要复杂得多。
【决定】
不过，这也不是坏事。
治好李婉儿，不仅能得到李建国的人情，还能借此了解更多关于修仙界的信息。
一举两得。
```

#### 【第5层：对话收尾】

```
萧烬松开手，站起身。
"怎么样？"李建国紧张地问，"萧先生，能治吗？"
萧烬看着他。
"能治。"
两个字，简单直接。
李建国的眼泪瞬间涌了出来。
"真的？真的能治？"
"但需要时间。"萧烬说，"我需要准备一些东西。明天，我再来。"
他顿了顿。
"还有，治疗期间，不要让其他人来打扰。"
李建国连连点头。
"明白明白！萧先生需要什么，尽管说！"
萧烬没有再说话。
他看了一眼躺在床上的李婉儿。
女孩的眼神里，有一丝微弱的希望。
那是活下去的渴望。
萧烬转身离开。
身后，传来李建国的声音：
"萧先生，谢谢您！谢谢您！"
```

## 六、场景四：伏笔+收尾（320-380字）

### 收尾设计

```
萧烬走出李家别墅。
夜风吹过，带来一丝凉意。
他站在门口，抬头看着天上的星星。
仙宗印记。
这东西出现在凡俗界，意味着什么？
萧烬的眼神变得深邃。
前世，他和仙宗有过几次交锋。
那是一个古老而强大的宗门，据说传承了数万年。
他们在凡俗界布局，必然有所图谋。
李婉儿体内的禁制，很可能就是某种阴谋的一部分。
"有意思……"
萧烬喃喃自语。
这一世，他本来只想低调发展，慢慢积累实力。
但看来，修仙界比他想象的更近。
手机响了。
是林小满的消息。
【萧烬哥哥，你什么时候回来？我给你留了饭。】
萧烬看着这条消息，嘴角微微上扬。
他回复：【一小时后到。】
然后，他叫了一辆车，消失在夜色中。
明天，还有很多事要做。
```
