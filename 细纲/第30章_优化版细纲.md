# 第30章：建业集团收购完成，商业帝国起步（优化版细纲）

**类型**：高潮章节（商业线） | **建议字数**：4000-5000字（以写透为准，不硬性限制）

---

## 一、核心事件

萧烬突破后处理商业事务。建业集团终于撑不住，王建业主动求和，同意以低价出售公司。萧烬霸气收购，王天豪彻底崩溃。收购完成后，萧烬宣布将天机诊所升级为"天机集团"，正式开启商业帝国之路。

---

| 场景 | 类型 | 权重 | 建议字数 | 说明 |

## 三、场景一：王建业父子求和（1000-1250字）

### 场景定位
王建业父子上门求和，打脸前奏。目的是：
1. 展现王家的落魄
2. 对比之前的嚣张
3. 为收购铺垫

### 五层展开

#### 【第1层：事件】
王建业父子来访 → 态度卑微 → 求萧烬收购 → 王天豪不甘

#### 【第2层：感官细节】

**视觉**
```
1. 王建业的形象：
   - 五十多岁，头发花白
   - 比之前憔悴了很多
   - 穿着虽然得体，但神态疲惫
   - 态度低三下四

2. 王天豪的形象：
   - 脸色铁青
   - 眼神里满是不甘和怨恨
   - 被父亲压着，不敢吭声

3. 场景对比：
   - 想起之前王天豪的嚣张
   - 现在父子俩像丧家之犬
```

**听觉**
```
1. 王建业恳求的声音
2. 王天豪压抑的咬牙声
3. 萧烬淡然的回应
```

#### 【第3层：人物反应】

**王建业**
```
- 态度：卑微，恳求
- "萧先生，求您放过我们……"
- 为了家族，放下所有尊严
```

**王天豪**
```
- 态度：不甘，但不敢反抗
- 被父亲警告：沉默
- 眼神里满是怨恨
```

**萧烬**
```
- 态度：淡然，居高临下
- 看着王家父子，没什么表情
- 心里：蝼蚁。
```

#### 【第4层：内心活动】

**萧烬的不屑**
```
萧烬看着跪在面前的王建业。
这就是之前那个不可一世的建业集团董事长？
现在看起来，就像一条丧家之犬。
商场如战场。
失败者，就要承受失败的代价。
王家之前仗着有点背景，对他趾高气扬。
现在背景没了，不也得乖乖来求他？
萧烬的嘴角微微上扬。
这就是实力的差距。
```

### 具体内容

```
【王家父子来访】
第二天上午。
萧烬正在诊所处理事务，张明远匆匆进来。
"先生，王建业和王天豪来了。"
"说是有重要的事求见您。"
萧烬挑了挑眉。
"让他们进来。"
片刻后，王建业和王天豪走了进来。
萧烬看着他们，嘴角微扬。
王建业比上次见面时憔悴了很多。
头发花白，神态疲惫。
曾经意气风发的建业集团董事长，现在看起来就像一个老人。
王天豪跟在他身后，脸色铁青。
看到萧烬时，眼神里满是怨恨。
但被父亲警告的眼神一扫，他不敢吭声。

【王建业求和】
"萧先生。"
王建业走到萧烬面前，深深鞠了一躬。
"这次来，是有事相求。"
萧烬靠在椅背上，淡淡道："说。"
王建业咬了咬牙，说出了那几个字。
"建业集团……愿意出售给您。"
全场安静。
林小满惊讶地看向萧烬。
张明远也愣了一下。
建业集团？王家的命根子？
王建业居然愿意卖？
萧烬的表情没有任何变化。
"价格呢？"
王建业艰难地说："40亿。"
他闭上眼睛，像是下了很大决心。
"40亿，整个建业集团都归您。"
"只求您……放过我们王家。"

【王天豪的不甘】
"爸！"
王天豪终于忍不住了。
"你怎么能向他低头！"
"建业集团是爷爷一手创办的！怎么能卖给这个……这个……"
他指着萧烬，气得说不出话。
王建业转身，狠狠打了他一巴掌。
"闭嘴！"
王天豪捂着脸，不敢置信地看着父亲。
王建业的眼神冰冷。
"你知道现在建业集团是什么情况吗？"
"银行抽贷，合作伙伴撤资，项目全部停工！"
"再不卖，建业集团就要破产了！"
"到时候，我们王家一无所有！"
王天豪的脸色变得苍白。
他不知道，情况已经糟糕到了这种地步。
"都是因为你！"王建业指着他，"都是因为你得罪了萧先生！"
"现在让我来收拾烂摊子？！"
王天豪低下头，不敢说话。
```

## 四、场景二：谈判+收购完成（1400-1750字）【核心场景】

### 场景定位
萧烬霸气砍价，完成收购。

### 场景类型
商业/谈判场景

### 五层展开

#### 【第1层：事件】
萧烬砍价 → 王建业同意 → 签约 → 收购完成

#### 【第2层：感官细节】

**视觉**
```
1. 萧烬谈判时：
   - 气定神闲
   - 居高临下
   - 每一句话都像在宣判

2. 王建业：
   - 脸色难看
   - 但最终点头
   - 签字时手在抖

3. 王天豪：
   - 彻底崩溃
   - "不可能！"
   - 几乎疯狂
```

**听觉**
```
1. 萧烬砍价时淡然的声音
2. 王天豪的崩溃嘶吼
3. 签字笔在纸上划过的声音
```

#### 【第3层：人物反应】

**萧烬**
```
- 砍价：毫不留情
- "40亿？当初我出50亿你们不卖。现在35亿。"
- 霸道，不容置疑
```

**王建业**
```
- 被砍价：脸色铁青
- 但不得不同意
- 签字时：满脸苦涩
```

**王天豪**
```
- 听到35亿：崩溃
- "不！这不可能！"
- 几乎疯狂
```

#### 【第4层：内心活动】

**萧烬的掌控感**
```
40亿？
萧烬心里冷笑。
当初他开价50亿，王家不卖。
还想联合其他势力搞他。
现在倒好，主动送上门来了。
但40亿？
太贵了。
商场上，主动权在他手里。
他没必要给王家面子。
35亿，已经是他的底线了。
爱卖不卖。
```

### 具体内容

```
【萧烬砍价】
萧烬听完王建业的报价，沉默了几秒。
然后，他开口了。
"40亿？"
他的语气带着一丝嘲讽。
"王董事长，你是不是忘了什么？"
王建业愣了一下。
萧烬淡淡道："当初我开价50亿，你们不卖。"
"还想联合其他势力来搞我。"
"现在撑不住了，想40亿卖给我？"
他嘴角上扬。
"你觉得，可能吗？"
王建业的脸色变了。
"萧先生……您的意思是？"
萧烬伸出三根手指。
"35亿。"
"建业集团所有资产，35亿。"
"这是我的底线。"
王建业的脸色铁青。
35亿？
建业集团的资产，评估价值至少50亿！
35亿收购，等于是打了七折！
"萧先生，这……这太少了……"
"爱卖不卖。"萧烬打断他，"不卖的话，等建业集团破产，我一分钱不花也能拿下。"
王建业的身体一僵。
他知道萧烬说的是真的。
以建业集团现在的情况，最多再撑一个月。
到时候破产清算，他们什么都得不到。
35亿……至少还能保住一些。
"好……"他艰难地点头，"35亿就35亿。"

【王天豪崩溃】
"不！"
王天豪终于忍不住了。
他冲上前，指着萧烬吼道：
"不可能！建业集团是我们王家的！你凭什么？！"
"凭什么！"
他的眼睛充血，几乎疯狂。
萧烬淡淡看了他一眼。
"凭什么？"
"凭你们惹不起我。"
简单的一句话，却让王天豪浑身冰冷。
王建业一把拉住儿子，低声呵斥：
"闭嘴！你想害死我们吗？！"
王天豪挣扎了几下，最终颓然瘫坐在地上。
"完了……全完了……"
他喃喃自语，眼神空洞。
曾经的富二代，现在就像一条丧家之犬。

【签约】
萧烬让张明远拿来合同。
"签吧。"
他把合同递给王建业。
王建业接过合同，手在微微发抖。
他看了一眼合同内容，然后咬牙签上了自己的名字。
从这一刻起，建业集团正式易主。
"萧先生。"王建业把合同递回去，声音沙哑，"希望您能……放过我们。"
萧烬接过合同，淡淡道：
"只要你们以后不惹我，我不会找你们麻烦。"
王建业如释重负，拉起地上的王天豪。
"谢谢萧先生。我们告辞了。"
他带着儿子，灰溜溜地离开了诊所。
从进门到出门，不到半个小时。
曾经叱咤江南的建业集团，就这样换了主人。
```

## 五、场景三：天机集团成立（1200-1500字）【核心场景】

### 场景定位
萧烬宣布成立天机集团，商业帝国正式起步。

### 场景类型

### 五层展开

```
1. 会议室：
   - 萧烬坐在主位

   - 气氛郑重

2. 萧烬宣布时：
   - 气场强大
   - 每一句话都掷地有声
   - 展望未来的眼神
```

**听觉**
```
1. 萧烬的宣布声
2. 掌声
3. 众人的表态
```

#### 【第3层：人物反应】

**萧烬**
```
- 宣布时：霸气
- 规划时：自信
- "目标：世界500强。"
```

**众人**
```
- 李建国：震惊又兴奋
- 苏震天：佩服
- 林小满：骄傲
- 张明远：敬佩
```

#### 【第4层：内心活动】

**萧烬的野心**
```
天机集团。
萧烬看着眼前的核心团队，心里满意。
这只是开始。
从今天起，他的商业帝国正式起步。
诊所只是起点。
医药、地产、金融……
他要建立一个横跨多个领域的商业巨头。
天机集团，将成为华夏商界的一颗新星。
然后，冲出国门，走向世界。
五年内，市值100亿。
十年内，世界500强。
这是他给自己定的目标。
他前世是弑天魔尊，纵横修仙界。
这一世，他要纵横商界。
让天机这个名字，响彻全球！
```

### 具体内容

```
【召集核心成员】
王家父子离开后，萧烬召集了核心成员开会。
会议室里，李建国、苏震天、林小满、张明远等人齐聚。
他们都知道发生了什么。
萧烬收购了建业集团。
这意味着，萧烬的商业版图再次扩大。
"各位。"萧烬开口了，"今天叫大家来，是有重要的事宣布。"
众人正襟危坐，认真听着。

【宣布成立】
萧烬站起身，走到窗前。
窗外，是江南市繁华的街景。
"从今天起，天机诊所正式升级为——天机集团。"
他转身，看着众人。
"天机集团，将是一个综合性的商业集团。"
"旗下包括：天机医馆（医疗）、天机地产（原建业集团）、天机投资（金融）。"
"三大板块，协同发展。"
众人震惊。
李建国忍不住问："萧先生，您的计划是？"
萧烬淡淡道："五年内，市值100亿。"
"十年内，进入世界500强。"
全场哗然。
世界500强？！
这个目标，太疯狂了！
但看着萧烬自信的眼神，没有人觉得他是在吹牛。
这个年轻人，已经创造了太多奇迹。
谁知道，他还能创造什么？

【职位安排】
"接下来，是职位安排。"萧烬继续说。
"李建国，天机集团副董事长，负责对外投资和人脉拓展。"
李建国站起身，恭敬道："多谢萧先生信任！"
"苏震天，天机集团顾问，负责安保和特殊事务。"
苏震天点头："义不容辞。"
"张明远，天机医馆馆长，负责医疗板块。"
张明远激动道："先生，我一定不负所托！"
"林小满——"
萧烬看向林小满，嘴角带着一丝笑意。
"天机集团副总裁，负责日常管理。"
林小满愣了一下，然后脸红了。
"萧烬哥哥，我……我可以吗？"
"可以。"萧烬说，"我相信你。"
林小满用力点头，眼眶有些湿润。
"我一定会努力的！"

【高光时刻】
安排完毕后，萧烬再次看向众人。
"各位，从今天起，我们就是一个团队。"
"天机集团的未来，需要大家共同努力。"
"我承诺，只要跟着我，不会亏待任何人。"
他的语气坚定，气场强大。
众人纷纷表态。
"愿为萧先生效力！"
"天机集团，必将辉煌！"
萧烬点点头。
"好。散会。"
众人陆续离开。
林小满走到萧烬身边，小声说：
"萧烬哥哥，谢谢你。"
萧烬揉了揉她的头。
"谢什么。你是我的人，我当然要让你站在最高的位置。"
林小满的脸更红了。
"我会努力的……绝对不会让你失望。"
萧烬笑了笑。
"我知道。"
他看向窗外。
天机集团，正式起航。
商业帝国，从今天开始！
```

## 六、场景四：伏笔+收尾（400-500字）

### 收尾设计

```
【新的关注】
天机集团成立的消息，很快传遍了江南市商界。
一时间，议论纷纷。
"萧烬收购建业集团了？"
"听说只花了35亿，打了七折！"
"这小子太狠了……"
"天机集团？又是诊所又是地产，他想干什么？"
"不管干什么，这个人以后不能得罪。"
萧烬的名字，再次成为热门话题。
与此同时，一些暗中的势力，也开始关注他。

【神秘来电】
傍晚，萧烬独自在办公室处理文件。
手机响了。
一个陌生的号码。
萧烬接起电话。
"萧先生？"
对方的声音低沉，带着一丝威压。
"我是华康集团的赵天华。"
"不知道萧先生有没有兴趣，和我见一面？"
华康集团。
萧烬眯起眼睛。
这是江南省最大的医药集团，市值超过200亿。
他们为什么会联系自己？
"有什么事？"萧烬问。
赵天华笑了笑。
"萧先生最近在医药界动作频频，我们华康很感兴趣。"
"想和萧先生谈一谈……合作的可能性。"
他的语气虽然客气，但萧烬听出了背后的意思。
这不是谈合作。
这是在试探，甚至是在警告。
萧烬的嘴角微扬。
"好啊。"
"明天下午，我等你。"
他挂断电话，眼神深邃。
华康集团……
看来，有人坐不住了。
不过，来得好。
他正愁找不到下一个目标呢。
天机集团要发展，就需要更多的资源。
华康集团……
也许是一个不错的目标。

【悬念】
萧烬站在窗前，看着夜幕下的江南市。
天机集团成立，建业集团收购。
这只是开始。
接下来，还有更大的挑战在等着他。
但他不怕。
他前世是弑天魔尊，什么大风大浪没见过？
区区商战，不过是小游戏。
他会让所有人知道——
萧烬这个名字，代表着不可阻挡的力量！
```
