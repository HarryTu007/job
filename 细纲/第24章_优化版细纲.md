## 三、场景一：萧烬规划扩张+与林小满讨论（800-1000字）

### 场景定位
萧烬和林小满讨论诊所扩张计划。目的是：
1. 展现萧烬的商业规划
2. 林小满的参与和学习
3. 为后续商业线铺垫

### 五层展开

#### 【第1层：事件】
萧烬提出扩张计划 → 与林小满讨论 → 决定保健丹药量产 → 等待李建国

#### 【第2层：感官细节】

**视觉**
```
1. 诊所办公室：
   - 萧烬坐在桌前，面前摊着几张纸
   - 纸上画着简单的规划图

2. 林小满的样子：
   - 认真地看着萧烬
   - 手里拿着笔记本，准备记录
   - 眼神专注，偶尔点头
```

**听觉**
```
1. 萧烬讲解时的声音，平稳有力
2. 林小满翻笔记本的沙沙声
3. 偶尔的提问和回答
```

#### 【第3层：人物反应】

**林小满**
```
- 听萧烬讲解时：认真，专注
- "萧烬哥哥，什么是保健丹药？"
- 理解后：眼睛发亮，"这个主意太棒了！"
```

**萧烬**
```
- 讲解时：耐心，详细
- 看林小满认真的样子：嘴角带着笑
- 被夸奖时：淡然接受
```

#### 【第4层：内心活动】

**萧烬的商业思考**
```
天机诊所现在的模式，有问题。
萧烬一边画规划图，一边思考。
一对一的治疗，效率太低了。
他一天最多看几十个病人。
但如果能把丹药量产……
他可以同时"治疗"成千上万的人。
当然，量产的丹药效果会差一些。
但对普通人来说，保健够用了。
而且，这会带来巨大的利润。
有了利润，才能做更多的事。
修炼，需要资源。
资源，需要钱来买。
这是一个闭环。
萧烬的眼神里，闪着精明的光。
```

### 具体内容

```
【萧烬提出规划】
突破后的第二天。
萧烬坐在诊所的办公室里，面前摊着几张纸。
林小满坐在他对面，手里拿着笔记本，准备记录。
"萧烬哥哥，你要给我讲什么？"
"诊所的扩张计划。"萧烬说，"以后你要帮我管理诊所，这些你需要知道。"
林小满的表情变得认真。
"我听着。"

【讲解保健丹药】
萧烬指着纸上的规划图。
"天机诊所现在的模式，效率太低。"
"我一天最多看几十个病人，这样下去，很难做大。"
"所以，我打算研发一种可以量产的保健丹药。"
林小满疑惑："保健丹药？"
"简单说，就是把丹药的效果稀释，做成普通人也能吃的保健品。"
"效果虽然弱一些，但可以大规模生产，卖给普通人。"
林小满的眼睛一亮。
"这个主意太棒了！"
"这样的话，很多人都能受益！"
萧烬点头。
"没错。而且，这会带来巨大的利润。"
"有了利润，我们才能做更多的事。"

【林小满的理解】
林小满认真地记着笔记。
"所以……诊所要升级成医馆？"
"对。"萧烬说，"天机诊所会变成天机医馆。"
"诊所继续做高端治疗，医馆负责卖保健丹药。"
"两条线同时发展。"
林小满想了想，问道：
"可是……量产丹药，需要很多钱吧？"
"需要。"萧烬说，"所以，我需要一个投资人。"
"谁？"
"他马上就来了。"
话音刚落，门口传来敲门声。
张明远的声音响起：
"先生，李建国先生到了。"
```

## 四、场景二：李建国来访+商业谈判（1800-2250字）【核心场景】

### 场景定位
本章核心场景，李建国与萧烬的商业谈判。要写出：
1. 李建国的精明
2. 萧烬的商业头脑
3. 谈判的过程
4. 李婉儿病情的伏笔

### 场景类型
对话/谈判场景

### 五层展开

#### 【第1层：事件】
李建国来访 → 萧烬提出保健丹药计划 → 谈判投资比例 → 达成协议

#### 【第2层：感官细节】

**视觉**
```
1. 李建国的形象：
   - 五十多岁，西装革履
   - 表情精明，目光锐利
   - 但看萧烬时，带着尊敬

2. 谈判场景：
   - 三人坐在会客室里
   - 茶几上放着茶具和规划书
   - 气氛轻松但专业
```

**听觉**
```
1. 李建国浑厚的声音
2. 翻阅规划书的声音
3. 茶杯碰撞的轻响
```

#### 【第3层：人物反应】

**李建国**
```
- 听萧烬讲计划时：眼睛越来越亮
- 看到市场预估时：深吸一口气
- 被萧烬拒绝40%时：并不意外
- 最终同意20%时：爽快
```

**萧烬**
```
- 讲解时：自信，从容
- 谈判时：有原则，不让步
- 听到李婉儿的事时：点头
```

**林小满**
```
- 在旁边观察学习：专注
- 听到数字时：震惊
- 谈判结束后：对萧烬佩服不已
```

#### 【第4层：内心活动】

**李建国的震惊**
```
这个年轻人……
李建国看着萧烬的规划书，心里震撼。
他做了三十年生意，见过无数商业计划。
但萧烬这份计划，让他眼前一亮。
保健丹药量产……
这是一个全新的市场！
如果成功，市值绝对不止百亿！
这个年轻人，不只是神医。
他还是一个天才的商人。
```

**萧烬的底线**
```
40%太多了。
萧烬听到李建国的报价，心里冷笑。
他需要投资，但不需要出让控制权。
天机医馆是他的，必须由他来掌控。
20%是他能接受的最高比例。
再多，免谈。
```

### 具体内容

```
【李建国到来】
门开了，李建国走了进来。
他五十多岁，西装革履，精神矍铄。
身后跟着一个助理，手里拿着公文包。
"萧先生，又见面了。"李建国笑着和萧烬握手。
"李先生，请坐。"
三人在会客室里坐下。
林小满给大家倒茶，然后安静地坐在一旁。
李建国看了她一眼，笑道：
"这位是林小姐吧？听说萧先生对她很好。"
萧烬淡淡道："她是我的人。"
李建国点头，没有多问。

【萧烬展示计划】
寒暄过后，萧烬拿出规划书。
"李先生，今天请你来，是想谈一笔生意。"
李建国接过规划书，翻开看了起来。
"保健丹药量产计划……"
他一边看，一边皱眉。
"萧先生，这个计划……"
"有问题？"
"没有。"李建国抬起头，眼睛闪着光，"太完美了。"
他指着规划书上的一个数字。
"你预计第一年销售额能达到10亿？"
"保守估计。"萧烬说，"如果市场反应好，可能更高。"
李建国深吸一口气。
10亿销售额……
如果利润率能达到30%，那就是3亿净利润。
这还只是第一年。
"萧先生的商业眼光，让我佩服。"李建国由衷地说。

【谈判投资比例】
"李先生，我需要启动资金5000万。"萧烬开门见山。
"没问题。"李建国干脆地说，"5000万，我出。"
"但我要40%的股份。"
萧烬摇头。
"太多了。"
李建国挑眉："萧先生觉得多少合适？"
"20%。"
"这……"李建国有些为难，"5000万只换20%，是不是太少了？"
"不少。"萧烬说，"这个项目的核心技术在我手里。"
"没有我的丹方，这个项目什么都不是。"
"李先生投资的，是我的技术，不是普通的创业公司。"
李建国沉默了。
他知道萧烬说得对。
保健丹药的核心，是丹方。
而丹方在萧烬脑子里。
没有萧烬，这个项目根本不存在。
"好。"李建国最终点头，"20%就20%。"
他伸出手。
"合作愉快，萧先生。"
萧烬和他握手。
"合作愉快。"

【李婉儿的事】
谈判结束后，李建国似乎还有话说。
他犹豫了一下，开口道：
"萧先生，我还有一个私人请求。"
"说。"
"是我女儿的事。"李建国说，"婉儿的脑瘤，您之前虽然治好了，但她身上那个印记……"
他的表情有些担忧。
"那个印记，最近好像有变化。"
萧烬点头。
"我知道。那个印记不是普通的东西，需要进一步处理。"
"古武大会结束后，我会帮她彻底清除。"
李建国大喜。
"萧先生大恩，李某没齿难忘！"
萧烬摆摆手。
"不用客气。我们是合作伙伴，帮你就是帮我自己。"
李建国感激地点头，然后起身告辞。
"那我就不打扰了。合同的事，我让律师尽快拟定。"
"好。"
李建国走后，林小满凑过来，眼睛亮亮的。
"萧烬哥哥，你太厉害了！"
"5000万！20%股份！这就成了？！"
萧烬笑了笑。
"商业谈判，最重要的是知道自己的底牌。"
"李建国需要我的技术，比我需要他的钱更多。"
"所以，主动权在我手里。"
林小满崇拜地看着他。
"萧烬哥哥，你是不是什么都会？"
"差不多吧。"
萧烬云淡风轻地说。
```

## 五、场景三：林小满学习管理+温馨日常（1000-1250字）【核心场景】

### 场景定位
本章情感线，林小满学习管理诊所。要写出：
1. 林小满的成长
2. 她的认真和努力
3. 温馨的日常互动
4. 萧烬的欣慰

### 具体内容

```
【林小满学习】
下午，萧烬开始教林小满管理诊所的基本知识。
"诊所的账目，要每天核对。"
"病人的资料，要分类存档。"
"药材的库存，要定期盘点。"
林小满一边听，一边认真记笔记。
她的字迹娟秀工整，笔记本写得满满当当。
萧烬看着她认真的样子，心里有些欣慰。
这丫头，比他想象的还要聪明。
只要用心教，她很快就能上手。

【实践操作】
讲完理论，萧烬让林小满实际操作。
"来，把今天的账目整理一下。"
林小满接过账本，开始仔细核对。
她的动作有些生疏，但态度很认真。
遇到不懂的地方，就抬头问萧烬。
萧烬耐心地一一解答。
一个小时后，林小满终于整理完了。
"萧烬哥哥，你看对不对？"
萧烬接过账本，翻了翻。
"不错，没有错误。"
林小满的脸上露出开心的笑容。
"真的？我做对了？"
"做对了。"萧烬揉了揉她的头，"你很聪明。"
林小满的脸红了，但眼睛亮晶晶的。
"那我以后是不是可以帮萧烬哥哥管理诊所了？"
"可以。"萧烬点头，"但你还要继续学习。"
"管理一个企业，不是简单的事。"
林小满用力点头。
"我会努力的！"

【温馨晚餐】
傍晚，萧烬和林小满一起做晚饭。
确切地说，是萧烬做，林小满打下手。
"萧烬哥哥，盐放多少？"
"一小勺就够了。"
"这个菜要炒多久？"
"看它变色就行。"
厨房里叮叮当当，烟火气十足。
最后，两人端着菜走到餐桌前。
四菜一汤，虽然简单，但色香味俱全。
林小满夹了一块红烧肉，放进嘴里。
"好吃！"她眯起眼睛，"萧烬哥哥的手艺越来越好了！"
萧烬笑着给她又夹了一块。
"多吃点。"
"你也吃。"林小满把一块排骨放到萧烬碗里。
两人相视而笑。
窗外，夕阳西下，余晖洒进来，照在两人身上。
这一刻，温馨而美好。

【林小满的心思】
吃完饭，林小满主动去洗碗。
萧烬坐在沙发上，看着她忙碌的背影。
林小满一边洗碗，一边哼着歌。
她的动作轻快，脸上带着笑。
"小满。"萧烬忽然开口。
"嗯？"
"以后，你就是天机医馆的副总经理。"
林小满愣了一下，转过身来。
"什么？"
"副总经理。"萧烬重复道，"我来当总经理，你来当副总。"
林小满的眼睛瞪大了。
"我……我可以吗？我什么都不会……"
"你会学的。"萧烬说，"我相信你。"
林小满的眼眶有些湿润。
"萧烬哥哥……"
她放下碗，跑过来，紧紧抱住萧烬。
"谢谢你……谢谢你相信我……"
萧烬轻轻拍着她的背。
"不用谢。你是我的人，我当然相信你。"
林小满把脸埋在他怀里，用力点头。
"我一定会努力的！绝对不会让萧烬哥哥失望！"
```

"古武大会……"
"也许，是时候出山了。"
暗流涌动。
风暴，即将来临。
