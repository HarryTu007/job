# 第17章：一日三绝症，神医名动全城（优化版细纲）

**类型**：过渡章节 | **建议字数**：4000-5000字（以写透为准，不硬性限制）

---

## 一、核心事件

天机诊所名声大噪，每天求诊者络绎不绝。萧烬开始筛选患者，只接疑难杂症。这一天，连续治好三个被西医判死刑的绝症患者，神医之名彻底传开。张明远作为学徒帮忙打理，诊所初具规模。同时，萧烬感觉修为即将突破，开始准备突破到炼气期五层。

## 三、场景一：诊所火爆+筛选患者（800-1000字）

### 场景定位
展现天机诊所的火爆场面，萧烬制定筛选规则。目的是：
1. 展现诊所的发展
2. 萧烬的商业头脑
3. 张明远和林小满的配合

### 五层展开

#### 【第1层：事件】
清晨诊所门口排长队 → 萧烬制定规则 → 张明远筛选 → 林小满整理

#### 【第2层：感官细节】

**视觉**
```
1. 诊所门口：
   - 长队从门口排到街角，少说有一百多人
   - 有人带着小板凳，显然是连夜排的
   - 有人举着病历本，脸上带着焦急和期待

2. 诊所内部：
   - 干净整洁，古色古香的装潢
   - 药柜里摆满了各种药材
   - 张明远在前台登记，林小满在旁边帮忙

3. 萧烬的状态：
   - 白大褂，气质从容
   - 眼神平静，带着一丝疲惫
```

**听觉**
```
1. 门外的嘈杂声，人群议论纷纷
2. 张明远喊号的声音
3. 林小满翻病历的沙沙声
4. 偶尔有人激动地喊"萧神医"
```

#### 【第3层：人物反应】

**萧烬**
```
- 看着门外的长队，皱了皱眉
- 对张明远说："今天开始，普通感冒发烧不接，只看疑难杂症"
- 语气平淡但不容置疑
```

**张明远**
```
- 恭敬地记下萧烬的要求
- 开始筛选病人，态度认真负责
- 偶尔抬头看萧烬，眼中满是敬佩
```

**林小满**
```
- 帮忙整理病历，动作娴熟
- 偶尔抬头看萧烬，眼里带着心疼
- "萧烬哥哥，你昨晚又没睡好吧？"
```

#### 【第4层：内心活动】

**萧烬的内心**
```
萧烬看着门外的长队，心里有些无奈。
他开这个诊所，本意是为了赚钱和积累人脉。
但没想到，名气传得这么快。
每天都有上百人来看病，其中大部分都是普通的头疼脑热。
这些病，普通医院就能治。
他的时间，应该花在更有价值的地方。
比如——那些被西医判死刑的绝症患者。
```

#### 【第5层：闲笔】

**闲笔**（约50字）
```
位置：萧烬看向窗外时
内容：门口有个老太太，带着个七八岁的小女孩。小女孩手里拿着一朵野花，递给老太太。"奶奶，等萧爷爷看好你的病，我们就去公园玩！"老太太笑了，眼里有泪光。
```

### 具体内容

```
【清晨的诊所】
早上七点。
天机诊所门口，已经排起了长队。
萧烬站在窗前，看着外面的人群，皱了皱眉。
"又是这么多人。"
身后传来张明远的声音："先生，今天挂号的已经有一百三十多人了。"
萧烬转过身，看着张明远手里的登记本。
"都是什么病？"
"感冒的有三十多个，发烧的有二十多个，还有一些是慢性病……"张明远翻了翻，"真正的疑难杂症，不到十个。"
萧烬沉默了几秒。

【制定规则】
"从今天开始。"萧烬开口，"普通感冒发烧不接。"
张明远愣了一下："先生，这……"
"那些病，普通医院就能治。"萧烬说，"我的时间，要花在更有价值的地方。"
他顿了顿："只接疑难杂症。被三家以上医院判定无法治愈的，优先。"
张明远恭敬地点头："是，先生。"
他转身走向前台，开始重新筛选病人。

【林小满的关心】
林小满从后面走过来，手里端着一杯茶。
"萧烬哥哥，喝点茶吧。"
萧烬接过茶杯，抿了一口。
林小满看着他，眼里带着心疼。
"你昨晚又没睡好吧？"
"在修炼。"萧烬说，"快突破了。"
林小满点点头，没有多问。
她知道萧烬的厉害，但也知道他很辛苦。
"那今天……尽量早点休息吧。"
萧烬看了她一眼，嘴角微扬。
"好。"
```

## 四、场景二：治疗三个绝症（1800-2250字）【核心场景】

### 场景定位
本章核心场景，要写出：
1. 三个绝症患者的不同情况
2. 萧烬的医术展示
3. 患者和家属的震惊与感激
4. 层层递进的爽感

### 场景类型
医疗/治疗场景（参考指南-场景类型八）

### 三个绝症设计

| 顺序 | 病症 | 难度 | 治疗方式 | 爽点 |
|------|------|------|---------|------|
| 第一个 | 晚期肝癌 | 中 | 针灸+丹药 | 十分钟见效 |
| 第二个 | 渐冻症 | 高 | 独特针法 | 当场能动 |
| 第三个 | 脑瘫儿童 | 极高 | 特殊手法 | 开口说话 |

### 治疗一：晚期肝癌患者（约600字）

#### 五层展开

**【第1层：事件】**
患者进门 → 萧烬诊断 → 针灸治疗 → 十分钟见效

**【第2层：感官细节】**
```
视觉：
- 患者是个五十多岁的男人，脸色蜡黄，瘦得皮包骨
- 他的儿子搀扶着他，眼眶通红
- 萧烬的针，又细又长，在灯光下闪着寒光

听觉：
- 患者的呻吟声，断断续续
- 针刺入穴位的轻微声响
- 治疗后，患者的一声长叹

触觉：
- 萧烬的手指在患者腹部按压，感受肝脏的状态
- 针刺入穴位时的阻力
```

**【第3层：人物反应】**
```
患者：
- 进门时：绝望，等死的状态
- 治疗中：感觉到一股暖流在体内流动
- 治疗后：震惊，不敢相信

家属（儿子）：
- 进门时：眼眶通红，强忍着泪
- 治疗中：紧张地看着
- 治疗后：扑通跪下，痛哭流涕
```

**【第4层：内心活动】**
```
萧烬诊断时的内心：
晚期肝癌。
按照这个世界的医学水平，已经没救了。
但对他来说……
小问题。
肝脏的病变，无非是气血淤滞，邪毒入侵。
用针灸疏通经络，再配合一颗护肝丹，三个月就能痊愈。
```

**【第5层：闲笔】**
```
位置：治疗结束后
内容：门外有人在偷听，听到里面的动静，倒吸一口凉气。"真的治好了？晚期肝癌？"
```

### 具体内容（治疗一）

```
【患者进门】
第一个患者，是个五十多岁的男人。
他的儿子搀扶着他，小心翼翼地走进诊室。
男人脸色蜡黄，瘦得皮包骨，眼神空洞，像是在等死。
"萧……萧神医……"儿子的声音在发抖，"我爸是晚期肝癌，医院都说……都说没救了……"
他说着，眼眶就红了。
"求求您……救救我爸……"

【诊断】
萧烬示意他们坐下，然后伸出手，搭在男人的手腕上。
片刻后，他收回手。
"晚期肝癌，肝脏已经开始萎缩。"
儿子的脸更白了。
"还……还有救吗？"
萧烬看了他一眼。
"能救。"
儿子整个人都愣住了。
"真……真的？"
"但需要配合治疗，三个月为一个疗程。"萧烬说，"今天先做第一次，之后每周来一次。"

【治疗】
萧烬取出银针。
针很细，很长，在灯光下闪着寒光。
他让男人躺下，然后开始施针。
一针，刺入期门穴。
两针，刺入章门穴。
三针，刺入日月穴。
每一针下去，男人都感觉到一股暖流在体内流动。
那种感觉很奇怪，像是有什么东西在疏通他的经络。
十分钟后。
萧烬收针。
"感觉怎么样？"
男人愣了一下，然后——
他的眼睛一点点亮了起来。
"我……我感觉……好多了……"
他的声音在发抖，但不是因为虚弱，而是因为激动。
"肚子不疼了……那种憋闷的感觉……也没了……"
儿子整个人都傻了。
然后，他扑通一声跪在地上。
"萧神医！谢谢您！谢谢您！"
```

### 治疗二：渐冻症患者（约600字）

```
【患者进门】
第二个患者，是个三十多岁的女人。
她坐在轮椅上，全身僵硬，只有眼睛能动。
她的丈夫推着轮椅，脸上写满了疲惫和绝望。
"萧神医，我老婆是渐冻症……"他的声音沙哑，"医生说，最多还能活两年……"
渐冻症。
萧烬看了女人一眼。
这种病，在这个世界被称为"绝症"。
患者的神经系统逐渐退化，最终全身瘫痪，直到死亡。
但对他来说……
只是经络堵塞罢了。

【诊断与治疗】
"躺下。"
萧烬让丈夫把女人从轮椅上抱起来，放在诊疗床上。
然后，他取出一套不同的银针。
这套针更细，更长，是专门用来疏通细微经络的。
他开始施针。
这一次，他的动作更慢，更谨慎。
因为渐冻症患者的经络已经开始萎缩，稍有不慎就会造成永久损伤。
一针，两针，三针……
二十分钟后。
萧烬收针。
"试试动一下手指。"
女人的眼睛里满是不可置信。
她试着动了动——
她的手指……动了。
"啊——！"丈夫整个人都傻了，"动了！真的动了！"
女人的眼泪夺眶而出。
她张了张嘴，艰难地发出声音：
"谢……谢……"
这是她三年来，第一次开口说话。
丈夫跪在地上，泣不成声。
"萧神医……萧神医……您是神仙啊……"
```

### 治疗三：脑瘫儿童（约600字）

```
【患者进门】
第三个患者，是个七八岁的男孩。
他的母亲抱着他，眼睛哭得通红。
男孩的眼神空洞，嘴角流着口水，四肢软绵绵的。
"萧神医，我儿子是先天性脑瘫……"母亲的声音在发抖，"医生说，他这辈子都不可能正常……"
她抱着孩子，跪在萧烬面前。
"求求您……救救我儿子……只要您能救他，我做牛做马都愿意……"
萧烬看着那个男孩。
先天性脑瘫。
这种病，比渐冻症还难治。
因为不是经络的问题，而是大脑的问题。
但……
萧烬的眼神微微眯了一下。
也不是完全没有办法。

【诊断与治疗】
"把孩子放下。"
萧烬让母亲把男孩放在诊疗床上。
然后，他的手指开始在男孩的头部按压。
他在找穴位。
普通的针灸，对脑瘫没有效果。
但有一种古老的针法——
醒神三十六针。
这是他前世从一位医道大能那里学来的，专门用来治疗大脑损伤。
萧烬取出一套特殊的银针。
这套针极细，细得像头发丝。
他开始施针。
一针，刺入百会穴。
男孩的身体微微颤抖。
两针，刺入神庭穴。
男孩的眼神开始聚焦。
三针，四针，五针……
三十六针全部刺入后，萧烬闭上眼睛，开始输入灵气。
这是这个世界的人做不到的。
因为他们没有灵气。
半小时后。
萧烬收针，睁开眼睛。
"孩子，叫妈妈。"
男孩愣了一下，然后——
"妈……妈……"
他开口了。
虽然发音还不清晰，但确确实实是"妈妈"两个字。
母亲整个人都僵住了。
然后，她抱着孩子，嚎啕大哭。
"我的儿子！我的儿子会说话了！"
门外，所有等待的病人都听到了。
整个诊所，一片哗然。
```

## 五、场景三：神医之名传开（1000-1250字）【核心场景】

### 场景定位
本章爽点爆发，要写出：
1. 围观群众的震惊
2. 消息传播的速度
3. 各方反应
4. 萧烬的从容

### 五层展开

#### 【第1层：事件】
三个治疗结束 → 消息传开 → 各方反应 → 萧烬收工

#### 【第2层：感官细节】

**视觉**
```
1. 诊所门口：
   - 人群更多了，把街道都堵了
   - 有人在拍照、录像
   - 有记者扛着摄像机往里挤

2. 三个患者家属：
   - 全都跪在门口，感谢萧神医
   - 有人在发锦旗
   - 有人在散钱，说是"随喜"
```

**听觉**
```
1. 人群的议论声，此起彼伏
2. "萧神医真是神仙啊！"
3. "晚期肝癌都能治好！"
4. "渐冻症！脑瘫！都治好了！"
5. 记者的提问声
```

#### 【第3层：人物反应】

**围观群众**
```
- 震惊、不可置信
- 有人跪下磕头
- 有人在打电话，声音激动
```

**张明远**
```
- 站在门口维持秩序
- 脸上满是骄傲
- "先生今天不再接诊了！明天请早！"
```

**林小满**
```
- 站在萧烬身边，脸上带着骄傲的笑
- "萧烬哥哥好厉害！"
- 眼睛亮亮的
```

**萧烬**
```
- 面无表情，像是做了一件微不足道的事
- "今天到此为止。"
- 转身回诊室
```

#### 【第4层：内心活动】

**萧烬的内心**
```
萧烬看着门外的人群，心里有些无奈。
他只是治了三个病人而已。
在前世，这种程度的病，他闭着眼睛都能治。
但在这个世界……
这就是"神迹"了。
算了。
名气大点也好。
以后的布局，会更方便。
```

### 具体内容

```
【消息传开】
三个治疗结束后，消息像长了翅膀一样，传遍了整个城市。
"天机诊所的萧神医，一天治好了三个绝症！"
"晚期肝癌！渐冻症！脑瘫！全都治好了！"
"真的假的？"
"千真万确！我亲眼看到的！"
到下午的时候，诊所门口已经挤满了人。
有病人，有家属，有记者，还有很多看热闹的。
人群把整条街都堵了。

【三个家属】
三个患者的家属，全都跪在诊所门口。
"萧神医是神仙下凡啊！"
"救命恩人！大恩大德！"
那个脑瘫孩子的母亲，手里捧着一面锦旗，上面写着"妙手回春，再世华佗"。
她跪在门口，磕头如捣蒜。
"萧神医！您救了我儿子！您是我们全家的恩人！"
男孩站在她身边，虽然走路还有些不稳，但已经能自己站立了。
他看着诊所的门，嘴里念叨着："谢……谢……萧……爷爷……"
围观的人群，都红了眼眶。

【记者蜂拥】
有记者扛着摄像机往里挤。
"萧神医！请问您是怎么做到的？"
"萧神医！您愿意接受采访吗？"
"萧神医！——"
张明远站在门口，把记者拦在外面。
"先生今天不接受采访！各位请回！"
"那明天呢？明天可以吗？"
"先生的行程，需要提前预约。"张明远的态度很坚定，"各位请回！"

【萧烬收工】
诊室里。
萧烬坐在椅子上，闭着眼睛休息。
林小满端着茶走进来。
"萧烬哥哥，外面好多人。"
"不理他们。"萧烬睁开眼睛，接过茶杯，"今天就到这里。"
林小满点点头，但眼睛亮亮的。
"萧烬哥哥，你好厉害。"
萧烬看了她一眼，嘴角微扬。
```
