**类型**：高潮章节 | **建议字数**：4000-5000字（以写透为准，不硬性限制）

## 一、核心事件

王天豪找黑哥带20个混混报复，萧烬轻松解决。债主苏震天带20个打手上门催债，萧烬制服所有人。遇见青梅竹马林小满，她是苏震天的女儿，被父亲逼迫来催债，流着泪对萧烬说"对不起"。

## 六、场景一：黑哥报复（1200-1500字）【核心场景】

### 场景定位
承接第2章结尾，王天豪找黑哥报复。目的是：
1. 展现萧烬的实力碾压（炼气期三层 vs 普通混混）
2. 制造第一个爽点
3. 快速推进，不要拖沓

### 场景类型
战斗/打斗场景-A型碾压秒杀（参考场景深度写作指南-类型六）

### 场景拆分

**小节A：黑哥带人包围（约300字）**
**小节B：萧烬下楼——对峙（约200字）**
**小节C：战斗过程——秒杀（约600字）**
**小节D：黑哥求饶——离开（约200字）**

---

### 小节A：黑哥带人包围（约300字）

**环境描写**（3+1法则）：

```
【3个具体细节】
1. 楼下停着三辆面包车，车门大开，里面空荡荡的
2. 二十个混混围成一圈，手里拿着钢管、棒球棍，有的还叼着烟
3. 黑哥站在最前面，是个光头大汉，脖子上有纹身，穿着背心，露出结实的肌肉

【1个动态元素】
楼上的住户有人开窗看了一眼，又赶紧关上。没人敢管闲事。
```

**黑哥的形象**（不要脸谱化）：

```
黑哥不是纯小丑，他在这片混了十几年，手底下有几十号人。
他见过不少硬茬子，但最后都服软了。
今天王天豪给了他十万，让他"废了"一个叫萧烬的小子。
黑哥觉得这钱赚得轻松。
一个欠债的穷小子，能有多厉害？
他带了二十个人，足够把对方吓得跪地求饶了。
```

**萧烬的感知**（从楼上观察）：

```
萧烬正在屋里研究系统，忽然听到楼下传来一阵嘈杂声。
他走到窗边，往下看了一眼。
二十个混混，围在楼下。
领头的是个光头，应该就是王天豪说的"黑哥"。
萧烬挑了挑眉。
就这？
他活了十万年，什么场面没见过。
二十个凡人，还不够他热身。
```

### 小节B：萧烬下楼——对峙（约200字）

**下楼过程**（要有压迫感）：

```
萧烬推开门，走下楼。
他走得很慢，一步一步，不慌不忙。
楼下的混混看到他，都愣了一下。
他们以为会看到一个吓得发抖的年轻人。
但萧烬的表情太平静了。
平静得让人有点不安。
```

**黑哥开口**（嚣张但要有层次）：

```
黑哥上下打量了萧烬一眼，冷笑一声："你就是萧烬？"
萧烬没说话，只是看着他。
"小子，敢动王少，你胆子不小啊。"黑哥往前走了一步，"今天我给你两个选择。第一，跪下来给我磕三个头，然后自断一只手，这事就算了。第二……"
他顿了顿，眼神变得凶狠："我让兄弟们帮你断。"
萧烬终于有了反应。
他笑了。
那笑容很淡，带着点说不清道不明的意味。
"就这？"
```

**关键点**：
- 萧烬的平静要有压迫感
- 黑哥不是纯小丑，要有一定的气势
- 对话要简洁，不要拖沓

### 小节C：战斗过程——秒杀（约600字）

**战斗类型**：A型碾压秒杀

**战斗前奏**（约100字）：

```
黑哥被萧烬的态度激怒了。
"给我上！"他大吼一声。
二十个混混同时冲了上来。
钢管、棒球棍，全都往萧烬身上招呼。
萧烬站在原地，没动。
```

**战斗过程**（约400字）——重点写速度感和力量感：

```
【第一波攻击】
第一个混混冲到面前，钢管高高举起。
萧烬侧身，避开。
同时，他的右手快如闪电，在混混的手腕上一拍。
"咔嚓"一声。
不是骨折，但手腕已经脱臼。
混混惨叫一声，钢管掉在地上。
萧烬没有停，左脚一踢，正中混混的膝盖。
混混整个人飞出去，撞倒后面两个人。

【第二波攻击】
又有三个混混同时冲上来。
萧烬不退反进，主动迎上去。
他的动作太快了，快到只能看到残影。
一拳，打在第一个混混的胸口。
混混倒飞出去，撞在面包车上，车门都凹进去了。
一脚，踢在第二个混混的腹部。
混混捂着肚子，跪在地上，吐出一口酸水。
第三拳，打在第三个混混的下巴。
混混整个人飞起来，在空中转了一圈，重重摔在地上。

【第三波攻击】
剩下的混混都愣住了。
他们从来没见过这么能打的人。
但黑哥在后面吼："都给我上！谁退谁死！"
混混们咬咬牙，又冲了上来。
这次，萧烬没有留手。
他的身影在人群中穿梭，每一次出手，都有人倒下。
不到十秒。
二十个混混，全部躺在地上。
有的在惨叫，有的已经昏过去了。
```

**黑哥的反应**（约100字）：

```
黑哥整个人都傻了。
他见过能打的，但没见过这么能打的。
二十个人，十秒不到，全倒了？
这他妈还是人吗？
他往后退了一步，手在发抖。
"你……你到底是什么人？"
萧烬看着他，眼神平静得吓人。
"滚。"
```

**关键点**：
- 战斗要快，不要拖沓
- 重点写萧烬的速度和力量，而不是招式细节
- 混混的反应要有层次（震惊→恐惧→求饶）
- 萧烬的状态：平静、冷漠、像在做一件微不足道的事

黑哥看着躺了一地的兄弟，腿都软了。
"大哥……我错了……我这就走……"
他一边说，一边往后退。
萧烬没理他，转身往楼上走。
黑哥如蒙大赦，赶紧招呼还能动的兄弟，把躺在地上的抬上车。

```

**萧烬的反应**（闲笔）：

```
萧烬走到楼梯口，忽然停下脚步。
他回头看了一眼。
地上还有几根钢管，几根棒球棍。
还有一摊血。
不知道是哪个混混的。
萧烬皱了皱眉。
他前世杀过的人，能绕修仙界三圈。
但在这个世界，他不想杀人。
至少现在不想。
他收回目光，继续上楼。

### 小节A：苏震天带人上门（约400字）

**时间交代**：

```
黑哥刚走，不到十分钟。
萧烬刚回到屋里，还没坐下，又听到楼下传来一阵脚步声。
这次的声音更整齐，更有纪律。
不是混混。
萧烬走到窗边，往下看了一眼。
五辆黑色轿车，停在楼下。
每辆车里下来四个人，一共二十个人。
都穿着黑色西装，戴着墨镜。
标准的打手打扮。
领头的是一个中年男人，五十岁左右，身材魁梧，眼神锐利。
苏震天。

**苏震天的形象**（不要纯反派）：

```
苏震天不是普通的债主。
他在这座城市混了三十年，黑白两道都有人脉。
他放贷，但从不逼死人。
