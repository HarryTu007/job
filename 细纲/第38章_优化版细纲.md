## 三、场景一：到达昆仑+进入门派（800-1000字）

### 场景定位
萧烬到达昆仑山脉，进入昆仑派。目的是：
1. 环境描写
2. 展现昆仑派的底蕴
3. 为会面铺垫

### 五层展开

#### 【第1层：事件】
到达昆仑山脉 → 看到昆仑派山门 → 玄冥子迎接 → 进入门派

#### 【第2层：感官细节】

**视觉**
```
1. 昆仑山脉：
   - 巍峨雄伟，云雾缭绕
   - 灵气充沛，仙气飘飘
   - 雪峰连绵，壮观无比

2. 昆仑派山门：
   - 古朴庄严的牌坊
   - "昆仑"二字金光闪烁
   - 弟子往来，秩序井然
```

**听觉**
```
1. 山风呼啸
2. 鹤鸣声声
3. 弟子练功的声音
```

#### 【第3层：人物反应】

**萧烬**
```
- 看到昆仑派：淡然
- "底蕴不错，但也就这样。"
- 不卑不亢
```

**玄冥子**
```
- 迎接时：恭敬
- "萧先生，请。"
- 态度比之前好很多
```

### 具体内容

```
【到达昆仑山脉】
飞行一天一夜后，萧烬到达了昆仑山脉。
这是华夏最神秘的山脉之一。
巍峨的雪峰直插云霄，云雾在山腰间缭绕。
灵气比外界浓郁了数十倍，让人神清气爽。
萧烬在半空中停下，俯瞰下方。
"昆仑山脉……"
他前世听说过这个地方。
据说是上古大能的道场，蕴含着无数秘密。
昆仑派占据此地，已有数千年历史。
难怪能成为修仙界的大派。
占着这么一块风水宝地，想不强都难。

【昆仑派山门】
萧烬降落在山门前。
一座古朴的牌坊矗立在眼前，上面刻着"昆仑"二字。
金色的字体闪烁着光芒，蕴含着强大的力量。
这两个字，至少是元婴期高手所书。
山门前，有数十个弟子在守卫。
看到萧烬降落，他们立刻警觉起来。
"来者何人？"
"报上名来！"
萧烬淡淡道："萧烬。你们掌门请我来的。"
守卫弟子愣了一下。
"萧……萧烬？！"
这个名字，他们最近听过太多次了。
灭掉暗影据点、让玄冥子长老亲自邀请的那个年轻人！
"快……快去通报！"

【玄冥子迎接】
很快，玄冥子从山门内走了出来。
"萧先生，您来了！"
他的态度比上次好了很多，甚至带着几分热情。
"掌门早就在等您了。"
"请跟我来。"
萧烬点点头，跟着玄冥子走进山门。
一路上，他看到无数昆仑派弟子在修炼、巡逻。
气息最低的也是炼气期，还有不少筑基期和金丹期。
"昆仑派有多少弟子？"萧烬随口问道。
"回萧先生，我派弟子约有三千人。"玄冥子说。
"其中金丹期以上，有一百二十三人。"
"元婴期，有三人。"
萧烬嘴角微扬。
三个元婴期。
这个底蕴，确实不错。
难怪敢称为"大派"。
不过……
也就这样了。
前世他是弑天魔尊，麾下强者无数。
三个元婴期？
连给他提鞋都不配。
```

## 四、场景二：与玄机真人会面+展现实力（1400-1750字）【核心场景】

### 场景定位
与掌门玄机真人会面，萧烬展现实力赢得尊重。

### 场景类型
展示/博弈场景

### 五层展开

#### 【第1层：事件】
进入议事大殿 → 见到玄机真人 → 试探 → 萧烬展现实力

#### 【第2层：感官细节】

**视觉**
```
1. 议事大殿：
   - 古朴庄严
   - 仙气缭绕
   - 两侧站着长老

2. 玄机真人：
   - 白发白须，仙风道骨
   - 眼神深邃
   - 气势惊人（元婴初期）
```

**听觉**
```
1. 脚步声回响
2. 灵气涌动声
3. 短暂的交锋声
```

#### 【第3层：人物反应】

**玄机真人**
```
- 见到萧烬：打量
- 试探后：震惊
- "萧道友实力高深，老夫佩服！"
```

**萧烬**
```
- 进入大殿：从容
- 被试探：轻松化解
- "掌门客气了。"
```

### 具体内容

```
【进入议事大殿】
玄冥子带着萧烬来到议事大殿。
大殿宏伟壮观，两侧站着十几个长老，气息各异。
最强的几个，是金丹期巅峰。
而正中央的主座上，坐着一个白发老者。
他的气息深不可测，如同一片汪洋。
元婴期初期！
这就是昆仑派掌门——玄机真人。
萧烬走进大殿，目光与玄机真人对视。
两人的气息无声碰撞，空气中泛起阵阵涟漪。
长老们纷纷变色。
仅仅是气息碰撞，就让他们感到压力。
这个年轻人，到底是什么来头？！

【玄机真人试探】
玄机真人站起身，眼神锐利。
"萧先生，久闻大名。"
他的声音平静，但带着一股无形的威压。
"今日一见，果然名不虚传。"
萧烬淡淡道："过奖。"
玄机真人忽然抬手，一道灵力激射而出。
"得罪了。"
这一招来得又快又急，普通筑基期根本反应不过来。
但萧烬只是微微侧身，轻松躲开。
然后，他反手一弹。
一道气劲射向玄机真人。
玄机真人的瞳孔骤然收缩。
他抬手挡住，但整个人后退了三步。
"好强的力量！"
他看向萧烬，眼神大变。
这一击……至少有金丹期巅峰的威力！
不对！
如果算上那种诡异的速度和角度……
这个年轻人的战力，恐怕不在他之下！

【赢得尊重】
"萧道友实力高深，老夫佩服！"
玄机真人的态度立刻变了。
他走下主座，亲自来到萧烬面前。
"请上座。"
萧烬也不客气，在上首坐下。
两侧的长老们面面相觑。
这个年轻人……居然和掌门平起平坐？！
"萧道友，老夫刚才出手试探，还望见谅。"玄机真人说。
"不试探一下，不知道萧道友的深浅。"
萧烬点点头。
"可以理解。"
"不过……"
他的眼神锐利。
"下次再试探，就不是后退三步那么简单了。"
玄机真人的脸色微变，但随即笑了。
"萧道友说笑了。"
"老夫知道分寸。"
他挥手让长老们退下，只留下几个核心人物。
"现在，我们可以好好谈谈了。"
```

## 五、场景三：真相揭露+谈判合作（1400-1750字）【核心场景】

### 场景定位
玄机真人揭露暗影组织真相，萧烬与昆仑派谈判合作。

### 具体内容

```
【真相揭露】
"萧道友，关于暗影组织的事，老夫欠你一个解释。"
玄机真人开门见山。
萧烬端起茶杯，示意他继续。
"暗影组织确实是我昆仑派的分支。"玄机真人说。
"但那是五百年前的事了。"
"当时，我派为了在暗中行事，创建了暗影组织。"
"但后来，暗影组织的首领……叛变了。"
萧烬挑眉。
"叛变？"
"是的。"玄机真人叹气。
"他名叫暗影真人，修为已达元婴期初期。"
"五百年前，他发现了我派先祖遗留的秘密，想要独吞。"
"被我派发现后，他率领暗影组织叛离，成为了我们的敌人。"
萧烬若有所思。
"先祖遗留的秘密？"
玄机真人点头。
"这就是我请萧道友来的真正原因。"
他站起身，走到大殿深处。
挥手间，一道禁制解除，露出一幅古老的地图。
"萧道友请看。"

【先祖被封印】
地图上画着昆仑山脉的深处，标注着一个位置。
"这里，是我派先祖的封印之地。"玄机真人说。
"先祖当年修为通天，差点飞升仙界。"
"但在最后关头，他被人暗算，重伤垂死。"
"为了保存一线生机，他将自己封印在这里。"
"只要找到解封的钥匙，就能救出先祖。"
萧烬的眼神闪了闪。
"钥匙……就是那三件古玉？"
"正是！"玄机真人说。
"那三件古玉，是先祖亲手炼制的解封钥匙。"
"暗影真人得知此事后，就想夺取钥匙，独占先祖的遗产。"
"但他只找到了三块，另外三块在我派手中。"
"所以，他一直无法解封。"
萧烬明白了。
"但现在，三块钥匙在我手里。"
"你们昆仑派和暗影组织，都想要。"
玄机真人点头。
"萧道友明鉴。"

【谈判】
"所以，你想让我把钥匙给你？"萧烬问。
玄机真人叹气。
"不瞒萧道友，我派确实需要那三件钥匙。"
"如果能救出先祖，我派实力将大增。"
"到时候，暗影组织不足为惧。"
萧烬沉默了一会儿。
"那我有什么好处？"
玄机真人愣了一下。
他没想到萧烬会这么直接。
"萧道友想要什么？"
萧烬嘴角上扬。
"我可以帮你们解封先祖。"
"但作为报酬——"
"先祖的遗产，我要一半。"
玄机真人的脸色变了。
"一半？这……"
"嫌多？"萧烬淡淡道。
"那我就把钥匙卖给暗影组织。"
"他们应该很乐意出高价。"
玄机真人急了。
"萧道友，不可！"
"暗影组织是叛徒，绝不能让他们得逞！"
萧烬摊手。
"那就看你们的诚意了。"

【达成协议】
玄机真人沉默良久。
最后，他咬牙道：
"好！一半就一半！"
"只要萧道友帮我们解封先祖，遗产对半分！"
萧烬满意地点头。
"成交。"
他站起身，走向那幅地图。
"这个封印之地，现在能去吗？"
"可以。"玄机真人说，"但要小心，暗影组织可能在附近埋伏。"
萧烬笑了笑。
"那正好。"
"一次性解决。"
他的眼神锐利。
"先去看看封印的情况。"
"如果没问题，今天就动手解封。"
玄机真人大喜。
"萧道友爽快！"
"老夫这就带您去！"
```

## 六、场景四：达成协议+伏笔（400-500字）

### 收尾设计

```
【前往禁地】
萧烬和玄机真人离开议事大殿，向昆仑山脉深处飞去。
一路上，玄机真人对萧烬更加敬重。
"萧道友，你的实力……"
"到底是什么境界？"
萧烬笑而不语。
玄机真人也不再追问。
高人嘛，都有秘密。
强行追问，反而不礼貌。

【暗影组织的行动】
与此同时，暗影组织总部。
暗影真人收到了情报。
"萧烬已经进入昆仑派？"
"他们要去封印之地？"
他的眼神阴冷。
"好！"
"正好一网打尽！"
"传令下去，全体出动！"
"今天，就是昆仑派覆灭之日！"
黑影涌动，杀气腾腾。

【伏笔】
禁地入口。
萧烬和玄机真人站在一道巨大的石门前。
石门上刻满了古老的符文，散发着神秘的气息。
"这就是封印之地。"玄机真人说。
"先祖就被封印在里面。"
萧烬打量着石门，眼神闪烁。
这道封印……
确实是万年前的手笔。
但以他现在的实力，应该能打开。
"萧道友，需要准备什么吗？"
萧烬摇头。
"不用。现在就——"
忽然，他的表情变了。
"有敌人。"
他看向远处。
一道道黑影正在接近。
杀气，铺天盖地而来。
"是暗影组织！"玄机真人脸色大变。
"他们怎么来得这么快？！"
萧烬嘴角上扬。
"来得正好。"
"省得我去找他们。"
他的气势开始攀升。
决战，一触即发。
```
