## 一、核心事件

苏震天约萧烬到他的地盘茶馆见面，试探萧烬实力和来历。萧烬展现部分实力，苏震天态度大变，从债主变成想要结交的对象。同时，李建国的调查结果也出来，发现萧烬父亲当年的死可能另有隐情。本章核心是"试探+态度转变"。

## 三、场景一：茶馆见面+氛围（640-760字）

### 五层展开

#### 【第1层：事件】
萧烬收到苏震天邀请 → 到达茶馆 → 观察环境 → 暗流涌动

#### 【第2层：感官细节】

**视觉**

```
1. 茶馆外观：
   - 位于老城区一条僻静的巷子里
   - 外表看起来是普通的老式茶馆
   - 但门口站着两个壮汉，一看就不好惹

2. 内部：
   - 古色古香，摆着红木桌椅
   - 但萧烬注意到，角落里坐着十几个人
   - 那些人看似喝茶，但眼神警惕，随时准备动手

3. 苏震天：
   - 坐在包厢正中央，身材魁梧，虎背熊腰
   - 五十多岁，头发花白，但精神矍铄
   - 眼神锐利，一看就是见过大风大浪的人
```

**听觉**

```
1. 茶馆里很安静，只有茶水倒入杯中的声音
2. 萧烬走进来时，所有人的呼吸都变得紧张
3. 苏震天的声音低沉有力："萧小子，来了？坐。"
```

#### 【第3层：对话铺垫】

```
萧烬走进包厢，在苏震天对面坐下。
桌上摆着一套茶具，茶香袅袅。
"苏叔叔。"萧烬开口，语气平淡。
苏震天打量他几秒，然后笑了。
"萧小子，这几天可真是风生水起啊。"
他给萧烬倒了一杯茶。
"天机诊所开业，张明远拜师，李建国女儿的病也治好了……"
他顿了顿。
"你小子，藏得挺深。"
萧烬接过茶杯，没有喝。
"苏叔叔找我来，不是为了聊这些吧？"
苏震天的笑容不变。
"直接。我喜欢。"
他放下茶杯，身体往前倾。
"那我也直说了。630万，什么时候还？"
```

#### 【第4层：萧烬的观察】

```
【快速判断】
萧烬扫了一眼包厢外面。
十几个人，都是练家子。
其中有三个，气息比较特殊。
古武者。
暗劲期。
苏震天果然有准备。
【内心】
不过，这种程度的埋伏……
萧烬嘴角微微上扬。
在他眼里，和摆设没什么区别。
```

## 四、场景二：试探+展现实力（1440-1710字）【核心场景】

### 五层展开

#### 【第1层：事件】
苏震天试探 → 手下动手 → 萧烬轻松制服 → 释放气势

#### 【第2层：苏震天试探】

```
"630万，我可以还。"萧烬说，"但苏叔叔今天叫我来，恐怕不只是为了要钱。"
苏震天愣了一下，然后大笑。
"果然聪明！"
他收起笑容，眼神变得锐利。
"萧烬，我混江湖三十年，什么人没见过。"
"但你这种人……我还是第一次遇到。"
"三天前还是个负债累累的废物，三天后就能秒杀暗劲期高手。"
他盯着萧烬。
"你到底是什么人？"
萧烬看着他，没有说话。
苏震天等了几秒，没等到回答。
他叹了口气。
"看来，不试试是不行了。"
他挥了挥手。
包厢门被推开，三个人走了进来。
正是萧烬之前注意到的那三个古武者。
```

#### 【第3层：手下动手】

```
三个古武者围住萧烬。
为首的是个光头男人，浑身肌肉虬结。
"萧烬是吧？"他冷笑，"我是苏家的护卫长，暗劲巅峰。"
"老大让我试试你的深浅。"
萧烬看了他一眼。
"试吧。"
光头男人眼神一凝，直接出手。
拳风呼啸，带着暗劲的波动。
这一拳，能打穿一堵墙。
但——
萧烬只是抬起一根手指。
轻轻一点。
光头男人的拳头僵在半空。
他感觉自己的手臂像是被一座大山压住，动弹不得。
"怎……怎么可能……"
萧烬收回手指。
光头男人踉跄后退，脸色惨白。
其他两个古武者对视一眼，同时出手！
一个从左边攻来，一个从右边包抄。
配合默契，几乎没有破绽。
但萧烬只是站在原地。
他伸出双手，分别抓住两人的手腕。
"咔嚓！"
"咔嚓！"
两声骨裂。
两个古武者惨叫着倒在地上。
从出手到结束，不到三秒。
```

#### 【第4层：释放气势】

```
苏震天的脸色变了。
他站起身，瞳孔收缩。
三个暗劲期古武者，在萧烬手下连三秒都撑不住？
这种实力……
"你……"
他刚要说话，忽然感觉一股巨大的压力笼罩而来。
萧烬只是看了他一眼。
仅仅是一个眼神。
苏震天感觉自己像是被一头远古凶兽盯上了。
他的腿开始发软。
冷汗瞬间浸透了后背。
这种感觉……他只在面对真正的大人物时才有过。
但萧烬才二十多岁！
"苏叔叔。"
萧烬的声音很平静。
"你想知道我是什么人，我可以告诉你。"
他站起身，居高临下地看着苏震天。
"我是谁不重要。"
"重要的是——"
"你想做朋友，还是敌人？"
那一刻，苏震天忽然明白了一件事。
眼前这个年轻人，绝对不是他能招惹的存在。
```

## 五、场景三：苏震天态度转变（800-950字）【核心场景】

### 五层展开

#### 【第1层：态度转变】

```
苏震天沉默了几秒。
然后，他做出了一个让所有人都没想到的举动。
他弯腰，深深鞠了一躬。
"萧先生，是我有眼无珠。"
他的声音带着真诚的歉意。
"之前的事，多有得罪，还望见谅。"
地上的三个古武者傻眼了。
他们的老大——天海市地下势力的扛把子，竟然给一个年轻人鞠躬道歉？
萧烬看着苏震天，嘴角微微上扬。
"苏叔叔，不必如此。"
他示意苏震天坐下。
"那630万的事……"苏震天小心翼翼地问。
"会还的。"萧烬说，"但不是今天。"
"明白明白！"苏震天连连点头，"萧先生什么时候方便，什么时候还！"
他的态度和之前完全不一样了。
从债主变成了……恭敬？
```

#### 【第2层：试探结束】

```
"苏叔叔，坐下聊。"萧烬说。
苏震天小心翼翼地坐下，像是个做错事的学生。
萧烬给他倒了一杯茶。
"苏叔叔是古武者？"
苏震天愣了一下，然后点头。
"暗劲巅峰，卡了十年了。"
"难怪。"萧烬说，"你的气息有些特殊，我之前就注意到了。"
苏震天的眼睛亮了。
"萧先生也懂古武？"
"略知一二。"
苏震天激动起来。
"萧先生，我练武三十年，一直卡在暗劲巅峰，不知道能不能……"
"以后再说。"萧烬打断他，"今天先聊别的。"
他看着苏震天。
"林小满，是你女儿？"
苏震天的脸色变了。
"萧先生……您和小满……"
"她对我很好。"萧烬说，"我不会让她受委屈。"
苏震天的嘴角抽了抽。
这是……在给他下马威？
但他能说什么呢？
面对这种深不可测的存在，他只能点头。
"明白……明白……"
```

#### 【第3层：关系确定】

```
萧烬站起身。
"今天就到这里。"
他从口袋里掏出一张银行卡。
"这是100万。算是定金。剩下的，我会尽快还清。"
苏震天连忙接过。
"萧先生太客气了……"
萧烬往外走。
走到门口时，他忽然停下。
"对了，苏叔叔。"
"萧先生请说！"
"林小满的事，我会考虑。"
他的声音很轻。
"如果有一天，我决定接受她……"
"希望苏叔叔不要反对。"
苏震天愣住了。
等他反应过来，萧烬已经走远了。
他站在原地，脸上的表情十分复杂。
这是……来提亲的？
```

## 六、场景四：李建国调查线（320-380字）

### 伏笔推进

```
同一时间。
李建国的办公室。
他看着手里的调查报告，眉头紧皱。
"你确定？"
"确定。"调查员说，"萧烬的父亲萧正国，五年前死于车祸。"
"但当天有目击者称，看到一个穿道袍的老者出现在事发现场。"
李建国的脸色变了。
道袍老者？
在现代社会，还有人穿道袍？
"继续查。"他说，"查清楚那个道袍老者是谁。"
"明白。"
调查员离开后，李建国靠进椅背。
萧烬的父亲死得不简单。
而萧烬本人……
他治好婉儿的那些手段，绝不是普通医术。
更像是……传说中的仙术。
"有意思。"
李建国喃喃自语。
"萧烬啊萧烬，你到底藏着多少秘密？"
【章末钩子】
电话响了。
是林小满打来的。
"李叔叔，萧烬哥哥在您那边吗？"
李建国愣了一下。
"没有啊，他不是去见苏震天了吗？"
"什么？"林小满的声音紧张起来，"他去见我爸了？"
```
