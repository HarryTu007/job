# 第20章：李雅琴身份揭晓，隐世家族（优化版细纲）

**类型**：高潮章节（身份反转） | **建议字数**：4000-5000字（以写透为准，不硬性限制）

## 一、核心事件

李雅琴主动找萧烬，揭示自己的真实身份：她是南方隐世家族"李家"的外嫁女，李家是古武世家，有筑基期高手坐镇。李雅琴希望萧烬能在古武大会上帮李家说话，作为交换，李家会全力支持萧烬的商业发展。萧烬提出自己的条件。

## 三、场景一：李雅琴约见+神秘氛围（800-1000字）

### 场景定位
李雅琴主动约见萧烬，要告诉他一个秘密。目的是：
1. 制造悬念
2. 铺垫李雅琴的不简单
3. 展现神秘氛围

### 五层展开

#### 【第1层：事件】
收到李雅琴邀请 → 来到李家别墅 → 感受到异常 → 进入密室

#### 【第2层：感官细节】

**视觉**
```
1. 李家别墅：
   - 低调奢华，占地极大
   - 围墙上有一些古老的纹路，像是阵法
   - 院子里有假山流水，布局暗合风水

2. 密室环境：
   - 在别墅地下
   - 墙壁上刻着古老的符文
   - 中央有一张圆桌，上面摆着一些古物

3. 李雅琴的状态：
   - 不再是平日里的贵妇打扮
   - 穿着一身素雅的旗袍，气质变得沉稳
   - 眼神里带着一丝凝重
```

**听觉**
```
1. 进入别墅后，一切都很安静
2. 密室里有低沉的嗡嗡声，像是阵法在运转
3. 李雅琴说话时，声音压得很低
```

**嗅觉**
```
1. 密室里有一股淡淡的檀香味
2. 还有一种说不清的气息——灵气？
```

#### 【第3层：人物反应】

**萧烬**
```
- 收到邀请时：有些疑惑
- 进入别墅后：察觉到阵法的存在
- 进入密室后：确认李雅琴的不简单
- 内心：果然如此
```

**李雅琴**
```
- 邀请时：凝重，神秘
- 见到萧烬时：恭敬中带着期待
- 即将揭示身份时：深吸一口气，像是下定决心
```

#### 【第4层：内心活动】

**萧烬的内心**
```
【进入别墅时】
萧烬一进门，就察觉到了异常。
这座别墅……有阵法。
虽然很弱，但确实是阵法。
聚灵阵？不，是护宅阵。
这种阵法，普通人布置不出来。
看来，李雅琴的身份，比他想象的要复杂。

【进入密室时】
密室的门一开，一股淡淡的灵气扑面而来。
萧烬的眼神微微一动。
这个密室，有聚灵阵。
虽然很简陋，但确实能汇聚灵气。
李雅琴……到底是什么人？
```

#### 【第5层：闲笔】

**闲笔**（约40字）
```
位置：进入密室时
内容：密室角落有一盆兰花，在这种几乎没有阳光的地方，居然长得很好。萧烬看了一眼——是灵气在滋养它。
```

### 具体内容

```
【收到邀请】
这天傍晚。
萧烬收到了李雅琴的电话。
"萧先生，您方便来我家一趟吗？我有一件重要的事想和您谈。"
她的语气很凝重，不像平日里的热情。
萧烬沉默了几秒。
"好。"

【来到李家别墅】
李家别墅在城市的郊区，占地极大。
萧烬一进门，就察觉到了异常。
围墙上有一些古老的纹路，普通人看不出来，但萧烬一眼就认出——那是阵法。
护宅阵。
虽然很弱，但确实是阵法。
萧烬的眼神微微一动。
有意思。
院子里的假山流水，布局也暗合风水。
萧烬甚至能感觉到，这座别墅里的灵气浓度，比外面高了一些。
虽然对他来说微不足道，但在这个灵气稀薄的世界，已经很不容易了。
李雅琴……到底是什么人？

【进入密室】
李雅琴亲自出来迎接。
她今天的打扮和平日不同——不再是贵妇的华丽，而是一身素雅的旗袍，气质变得沉稳。
"萧先生，请跟我来。"
她带着萧烬，穿过客厅，来到一扇隐蔽的门前。
门打开，是一条向下的楼梯。
密室在地下。
萧烬跟着她走下去。
楼梯两旁的墙壁上，刻着一些古老的符文，隐隐发着微光。
阵法。
又是阵法。
密室的门打开，一股淡淡的灵气扑面而来。
萧烬的眼神闪了闪。
密室不大，但布置得很古朴。
墙壁上刻着符文，中央有一张圆桌，上面摆着一些古物。
角落里有一盆兰花，在这种几乎没有阳光的地方，居然长得很好。
萧烬看了一眼——是灵气在滋养它。
"萧先生，请坐。"李雅琴示意他坐下。
萧烬在圆桌旁坐下，看着李雅琴。
"说吧。"他的语气平静，"你想告诉我什么？"
```

### 具体内容

**小节A：李雅琴揭示身份（约600字）**

```
【开口】
李雅琴深吸一口气。
"萧先生，我今天请您来，是想告诉您一个秘密。"
她顿了顿，像是在斟酌措辞。
"一个关于我身份的秘密。"
萧烬没有说话，只是静静地看着她。
李雅琴被他的眼神看得有些紧张，但还是继续说了下去。
"萧先生，我的真实身份……"
她从怀里取出一块玉牌，放在桌上。
玉牌很古朴，上面刻着一个"李"字，有淡淡的灵光流转。
"我是南方隐世家族'李家'的外嫁女。"
她说完，看着萧烬，等待他的反应。

【萧烬的反应】
萧烬看了一眼那块玉牌，然后淡淡道：
"我知道。"
李雅琴整个人都愣住了。
"您……您知道？"
"你身上的气息，普通人不会有。"萧烬说，"从第一次见面，我就知道你不简单。"
李雅琴的脸色变了又变。
她自问隐藏得很好，连李建国都不知道她的真实身份。
没想到，萧烬第一次见面就看穿了。
这个人……到底有多可怕？

【萧烬的追问】
"隐世家族。"萧烬说，"说说看，是什么来头？"
李雅琴定了定神，开始解释。
"隐世家族，是古武界之外的存在。"她说，"不同于古武协会和古武联盟，隐世家族不参与古武界的纷争，只专注于自身的传承和发展。"
"全国有大大小小几十个隐世家族，我们李家是南方最大的家族之一。"
"李家传承三百年，曾经辉煌一时。鼎盛时期，有三位筑基期高手坐镇。"
她顿了顿，眼神暗淡了下来。
"但如今……李家式微了。"
```

**小节B：李家的现状（约500字）**

```
【李家的困境】
"李家现在只剩下一位筑基期高手——我的爷爷。"李雅琴说，"而且，爷爷已经一百二十岁了，寿元将近。"
"除了爷爷之外，家族最强的几个长老，都只是化劲巅峰。"
"而且……"她的声音变得更低，"古武联盟，一直在觊觎我们李家。"
萧烬挑了挑眉："哦？"
"三个月后的古武大会，联盟很可能会对李家下手。"李雅琴说，"他们想吞并李家，获得李家的传承和资源。"
"如果没有外援，李家很可能会在这次大会上……覆灭。"
她说完，看着萧烬，眼神里带着恳求。
"萧先生，我今天来找您，就是想请您帮忙。"

【萧烬的态度】
萧烬沉默了几秒。
"帮忙？"他说，"你想让我做什么？"
"三个月后的古武大会，请您为李家说话。"李雅琴说，"只要您表态支持李家，联盟就不敢轻举妄动。"
她的眼神里带着期待。
"作为交换，李家会全力支持您的商业发展。"
"无论是资金、人脉还是其他资源，李家都会倾力相助。"
萧烬看着她，嘴角微扬。
"你觉得，我会为了这些东西，卷入古武界的纷争？"
李雅琴的脸色变了。
"萧先生，我……"
"别急。"萧烬打断她，"我没说不帮。"
他的眼神深邃。
"只是，你开出的条件……不够。"
```

**小节C：萧烬的震惊（约400字）**

## 五、场景三：合作谈判（1200-1500字）【核心场景】

### 场景定位
本章爽点，萧烬提出条件。要写出：
1. 萧烬的条件
2. 李雅琴的震惊
3. 双方达成协议
4. 萧烬的真正目的

### 五层展开

#### 【第1层：事件】
萧烬提条件 → 李雅琴震惊 → 讨价还价 → 达成协议

#### 【第2层：人物反应】

**萧烬**
```
- 提条件时：从容，不容置疑
- 看到李雅琴震惊时：淡然
- 达成协议时：满意点头
```

**李雅琴**
```
- 听到条件时：震惊，不敢相信
- 确认后：如释重负
- 达成协议时：感激涕零
```

### 具体内容

```
【萧烬的条件】
"李家有什么我想要的东西？"
李雅琴愣了一下。
她以为萧烬会要钱，要资源，要人脉。
没想到，他的问题这么……直接。
"萧先生想要什么？"她小心翼翼地问。
萧烬沉默了几秒，眼神深邃。
"我听说，李家有一份古地图。"
李雅琴的瞳孔猛然收缩。
"您……您怎么知道？！"
那份古地图，是李家最大的秘密！
除了家族核心成员，没有人知道它的存在！
萧烬是怎么知道的？
萧烬没有解释，只是淡淡道：
"那份地图，我要看看。"

【李雅琴的震惊】
李雅琴的脸色变了又变。
古地图是李家传承三百年的宝物，指向一个神秘的上古遗迹。
李家几代人都在研究那份地图，但始终没有找到遗迹的具体位置。
如果萧烬能帮忙破解地图……
她的心跳加速了。
但同时，她也有些警惕。
萧烬是怎么知道古地图的存在的？
他对李家，了解到什么程度？
"萧先生……"她斟酌着措辞，"那份地图是李家的至宝，轻易不能示人……"
"我不是想要那份地图。"萧烬说，"我只是想看看。"
他的眼神平静，像是在说一件微不足道的事。
"如果我能帮你们找到那个遗迹，我要参与其中。"
李雅琴愣住了。
萧烬能找到遗迹？
那个李家研究了三百年都没找到的遗迹？
"萧先生，您……您有把握？"
萧烬淡淡一笑。
"没有把握，我不会提。"

【达成协议】
李雅琴沉默了很久。
古地图是李家的秘密，但如果萧烬真的能找到遗迹……
那对李家来说，是翻天覆地的机遇。
而且，萧烬只是想"看看"和"参与"，并没有要独占的意思。
这个条件……可以接受。
"好。"她最终下定决心，"我答应您。"
"三个月后的古武大会，您帮李家说话。作为交换，李家会让您看那份古地图，如果您能找到遗迹的位置，我们一起探索。"
萧烬点点头。
"还有一个条件。"
李雅琴心里一紧："什么条件？"
"如果遗迹里有什么我想要的东西，归我。"
李雅琴愣了一下，然后点头："好。"
反正如果没有萧烬，李家根本找不到遗迹。
即使让萧烬拿走一部分东西，也比什么都得不到强。
"那就这么说定了。"萧烬站起身，"三个月后，古武大会见。"
李雅琴也站起来，深深鞠了一躬。
"萧先生，李家感激不尽！"
萧烬淡淡道："不用感谢。这是交易，各取所需。"
他转身往外走。
走到门口时，他忽然停下。
"对了，那份古地图上的阵纹，我见过。"
李雅琴一愣："您见过？"
萧烬没有回头。
"那种阵纹，至少万年以上。"
"你们李家传承三百年，太短了。"
说完，他推门出去。
李雅琴愣在原地，久久回不过神。
万年？
那份地图……有万年的历史？
萧先生……到底知道多少？
```

他的脑海里，回想着刚才看到的那块玉牌。
李家的传承玉牌。
上面的纹路，确实很古老。
但更让他在意的，是李雅琴提到的"古地图"。
指向上古遗迹的地图。
他前世见过类似的东西。
在修仙界，这种地图往往指向某个仙人洞府或者古修士遗迹。
里面可能藏着大量的修炼资源，甚至是功法传承。
如果这个世界也有类似的遗迹……
萧烬的眼神深邃。
也许，那里会有他想要的东西。
灵石？丹药？还是……
更重要的线索？

【林小满的等待】
回到诊所，林小满正坐在门口等他。
"萧烬哥哥，你回来了！"她跑上来，"去哪里了？我找你好久。"
萧烬看着她担心的表情，嘴角微扬。
"去见了个人。"
"什么人？"
"一个……想和我合作的人。"
林小满歪着头，不太明白。
但她没有多问，只是乖巧地说："那萧烬哥哥饿不饿？我给你热了饭菜。"
萧烬点点头："好。"
林小满开心地拉着他的手，往里走。
萧烬跟着她，脚步轻松了很多。
不管前路如何，至少现在，有人在等他回家。
这种感觉……很好。

【埋设伏笔】
吃饭的时候，萧烬的脑海里闪过一个念头。
李家的古地图，指向上古遗迹。
古武联盟想在古武大会上吞并各大势力。
隐世家族的存在，比他想象的要复杂。
这个世界的水，越来越深了。
但萧烬的嘴角，微微上扬。
越深，越有意思。
三个月后的古武大会——
一定很精彩。
