# 第25章：古武大会前夕，各方云集（优化版细纲）

**类型**：铺垫章节 | **建议字数**：4000-5000字（以写透为准，不硬性限制）

---

## 一、核心事件

古武大会前夕，各方势力云集江南市。萧烬带着林小满参加古武协会举办的欢迎宴会，遇到多位古武界高手。苏震天作为陪同，向萧烬介绍各方势力。古武联盟的人再次出现，态度依然傲慢。萧烬与林小满成为全场焦点。

## 三、场景一：萧烬与林小满准备参加宴会（600-750字）

### 场景定位
萧烬和林小满准备参加欢迎宴会。目的是：
1. 温馨的日常互动
2. 林小满的美丽登场
3. 为宴会场景铺垫

### 五层展开

#### 【第1层：事件】
林小满换晚礼服 → 萧烬的反应 → 温馨互动 → 出发

#### 【第2层：感官细节】

**视觉**
```
1. 林小满的晚礼服：
   - 淡蓝色的长裙，衬托她的气质
   - 精致的刺绣，低调奢华
   - 简单的妆容，突出她的清纯

2. 萧烬的装扮：
   - 黑色西装，剪裁合身
   - 没有太多装饰，但气场强大
   - 冷峻的面容，让人不敢直视
```

**听觉**
```
1. 林小满整理裙摆的窸窣声
2. 高跟鞋敲击地面的轻响
3. 萧烬简单的评价
```

#### 【第3层：人物反应】

**林小满**
```
- 换好礼服后：有些紧张，不确定好不好看
- 被萧烬夸奖后：脸红，开心
- 出门时：挽着萧烬的手臂，有些紧张又有些期待
```

**萧烬**
```
- 看到林小满：眼神微动
- 评价：简洁，但真诚
- 出门时：保护性地搂着她
```

#### 【第4层：内心活动】

**萧烬的心思**
```
林小满换好礼服从房间里走出来的时候，萧烬的眼神微微一动。
淡蓝色的长裙衬托着她白皙的皮肤，简单的妆容让她更加动人。
这丫头……出落得越来越好看了。
萧烬的嘴角微微上扬。
前世的他，一心扑在修炼上，从来没有关注过女人。
这一世，似乎……有些不一样了。
```

**林小满的紧张**
```
"萧烬哥哥，我穿这样合适吗……"
林小满有些忐忑地看着萧烬。
这是她第一次参加这么正式的场合。
她怕自己表现不好，给萧烬丢脸。
```

### 具体内容

```
【林小满换礼服】
傍晚。
林小满在房间里换晚礼服。
萧烬在客厅等她。
十分钟后，房门打开。
林小满穿着一袭淡蓝色的长裙，走了出来。
裙子的材质很好，衬托着她的身材。
她化了淡妆，显得清纯动人。
脚上是一双白色的高跟鞋，让她显得更加高挑。
"萧烬哥哥……"她有些紧张，"我穿这样合适吗？"

【萧烬的反应】
萧烬看着她，眼神微动。
这丫头……
比他想象的还要好看。
"很美。"他说。
简单的两个字，却让林小满的脸一下子红了。
"真……真的吗？"
"真的。"萧烬站起身，走到她面前。
他伸手，帮她整理了一下耳边的碎发。
"今晚，你会是最美的。"
林小满的心跳得很快。
萧烬哥哥……好温柔。

【出发】
萧烬伸出手臂。
"走吧。"
林小满乖巧地挽住他的手臂。
两人一起走出诊所。
门外，一辆黑色的轿车已经在等着了。
那是苏震天派来接他们的。
林小满上了车，有些紧张地看向窗外。
"萧烬哥哥，宴会上会有很多人吗？"
"会。"萧烬说，"但你不用紧张。有我在。"
林小满点点头，握紧了萧烬的手。
有萧烬哥哥在，她什么都不怕。
```

## 四、场景二：宴会场景+势力介绍（1600-2000字）【核心场景】

### 场景定位
本章核心场景之一，宴会上的各方势力登场。要写出：
1. 宴会的盛大
2. 各方势力的介绍
3. 暗流涌动的氛围
4. 萧烬和林小满成为焦点

### 场景类型
社交/宴会场景

### 五层展开

#### 【第1层：事件】
到达宴会厅 → 苏震天介绍各方势力 → 各方反应 → 成为焦点

#### 【第2层：感官细节】

**视觉**
```
1. 宴会厅：
   - 江南大酒店最大的宴会厅
   - 水晶吊灯，金碧辉煌
   - 上百位来宾，衣着华丽

2. 各方势力代表：
   - 古武协会：陈长老，慈祥的老者
   - 古武联盟：周护法，面色阴沉
   - 修仙者联盟：玄元子，仙风道骨
   - 各地高手：形形色色

3. 林小满的惊艳：
   - 她进场时，很多人的目光都被吸引
   - 有人交头接耳，询问她是谁
```

**听觉**
```
1. 嘈杂的人声
2. 音乐在轻轻播放
3. 酒杯碰撞的声音
4. 苏震天低声的介绍
```

**嗅觉**
```
1. 美食的香气
2. 酒香
3. 女士们的香水味
```

#### 【第3层：人物反应】

**苏震天**
```
- 介绍时：压低声音，有选择性地说
- 提到古武联盟时：表情凝重
- 看萧烬的表情：带着期待
```

**各方势力**
```
- 古武协会的人：对萧烬友善
- 古武联盟的人：带着敌意
- 修仙者联盟的人：好奇，审视
- 其他高手：震惊于林小满的美貌，也好奇萧烬的身份
```

**林小满**
```
- 进场时：紧张，紧紧抓着萧烬
- 被人注视：有些不自在
- 被萧烬安慰后：渐渐放松
```

#### 【第4层：内心活动】

**萧烬的观察**
```
萧烬扫视全场，心里有数。
古武协会、古武联盟、修仙者联盟……
三方势力，泾渭分明。
古武协会的人聚在一起，表情轻松。
古武联盟的人在另一边，神色傲慢。
修仙者联盟的人则在角落里，若有所思地观察着一切。
暗流涌动。
这场大会，恐怕不会太平。
```

### 具体内容

```
【到达宴会厅】
江南大酒店，最大的宴会厅。
萧烬和林小满走进去的时候，全场的目光都被吸引了过来。
倒不是因为萧烬。
而是因为他身边的林小满。
淡蓝色的长裙，清纯的面容，让她在一众衣着华丽的贵妇名媛中格外显眼。
"那个女孩是谁？"
"好漂亮啊……"
"她旁边那个男的是谁？"
议论声此起彼伏。
林小满有些不自在，握紧了萧烬的手。
萧烬低声说："不用紧张。他们看的是你，不是在嘲笑你。"
林小满点点头，努力让自己放松。

【苏震天出现】
"萧先生！"
苏震天快步走过来，脸上带着笑。
"你们来了！快，跟我来。"
他带着萧烬和林小满，穿过人群。
一边走，一边低声介绍：
"那边穿白袍的，是古武协会的陈长老。他是协会的元老，说话很有分量。"
"旁边那个黑袍的，是古武联盟的周护法。你之前见过，就是被你震慑的那个。"
"角落里那个灰袍老者，是修仙者联盟的玄元子。他是来观察的，不会轻易表态。"
萧烬点点头，表示记下了。

【势力介绍】
苏震天继续介绍。
"今晚来的，大概有上百位古武界的高手。"
"有化劲后期的，有化劲巅峰的，还有几个暗劲境界的。"
"当然，最强的还是那几位金丹期的老怪物。"
他指了指角落里的几个老者。
"那些人轻易不出手，但实力深不可测。"
萧烬扫了一眼那些人。
金丹期……
确实有几个气息比较强的。
但对他来说，还不算什么威胁。

【林小满惊艳全场】
就在这时，一个中年人走过来。
他穿着华丽的西装，一看就是有钱人。
"苏先生，这位是？"他的目光落在林小满身上，眼里闪着惊艳。
苏震天笑道："这位是萧烬萧先生，还有他的女朋友林小满林小姐。"
中年人眼神一变。
"萧烬？就是那个神医萧烬？"
"正是。"
中年人连忙伸出手："萧先生大名，如雷贯耳！在下王有财，做点小生意。"
萧烬淡淡地和他握了握手。
王有财又看向林小满，语气热情：
"林小姐真是天生丽质，萧先生好福气啊！"
林小满有些害羞，小声说了句"谢谢"。
萧烬轻轻搂过她的肩膀，语气平淡：
"她是我的人。"
简单一句话，却让王有财脸色微变。
他识相地点点头，没有再多说什么。
这一幕，被不少人看在眼里。
"那个年轻人是萧烬？"
"就是那个神医？"
"他身边的女孩好漂亮……"
"他刚才说'她是我的人'，好霸气……"
萧烬和林小满，成为了全场的焦点。
```

## 五、场景三：古武联盟挑衅+萧烬震慑（1400-1750字）【核心场景】

### 场景定位
本章爽点，古武联盟挑衅萧烬，被萧烬气势震慑。要写出：
1. 古武联盟的傲慢
2. 萧烬的霸气
3. 全场的震惊
4. 林小满的骄傲

### 场景类型
冲突/对峙场景

### 五层展开

#### 【第1层：事件】
周护法出现 → 言语挑衅 → 萧烬眼神震慑 → 全场哗然

#### 【第2层：感官细节】

**视觉**
```
1. 周护法的形象：
   - 四十多岁，面色阴沉
   - 黑色长袍，气势威压
   - 眼神阴鸷，带着敌意

2. 萧烬的眼神变化：
   - 平静 → 微眯 → 一凛
   - 那一瞬间，周围的空气似乎都凝固了

3. 周护法的变化：
   - 傲慢 → 僵硬 → 后退
   - 额头冒出冷汗
```

**听觉**
```
1. 原本的嘈杂声，突然安静下来
2. 周护法的挑衅声
3. 萧烬简短的回应
4. 众人倒吸凉气的声音
```

#### 【第3层：人物反应】

**周护法**
```
- 挑衅时：傲慢，不可一世
- 被萧烬眼神锁定：身体僵硬
- 退后时：满头冷汗，表情惊恐
```

**萧烬**
```
- 面对挑衅：平静
- 反问时：带着一丝玩味
- 眼神一凛时：霸气侧漏
```

**林小满**
```
- 被挑衅时：有些害怕
- 看萧烬震慑对方：眼睛发亮
- 之后：紧紧抱着萧烬的手臂，满脸骄傲
```

**全场**
```
- 原本在看热闹
- 被萧烬的气势震慑：倒吸凉气
- 之后：议论纷纷，重新评估萧烬
```

#### 【第4层：内心活动】

**周护法的恐惧**
```
这……这是什么气势？！
周护法的身体在发抖。
他是古武联盟的护法，化劲巅峰的高手。
在古武界，他也算是顶尖的存在。
但此刻，面对萧烬的眼神——
他感觉自己像是被一头远古凶兽盯上的猎物。
无法动弹。
无法抵抗。
只有恐惧。
这个年轻人……到底是什么怪物？！
```

**萧烬的不屑**
```
萧烬看着周护法退后的样子，心里不以为意。
化劲巅峰？
在他眼里，不过是蝼蚁。
他只是释放了一点点气势。
如果是前世全盛时期的气势……
这个周护法，恐怕会当场吓死。
不过，现在还不是全面暴露实力的时候。
吓退他，就够了。
```

### 具体内容

```
【周护法出现】
正当萧烬和林小满成为焦点的时候，一个阴沉的声音响起。
"萧烬？就是那个不识抬举的小子？"
人群分开，一个黑袍中年人走了过来。
他四十多岁，面色阴沉，眼神阴鸷。
气势威压，让周围的人都不自觉地后退。
苏震天的表情变了。
"周护法……"
周护法看都不看他，目光直直地盯着萧烬。
"听说你之前把我们联盟的人赶走了？"
他的语气带着嘲讽。
"一个小小的炼气期，也敢跟我们古武联盟叫板？"

【言语挑衅】
周围的人都停下了交谈，看向这边。
好戏来了！
萧烬之前拒绝古武联盟的事，不少人都听说了。
现在周护法亲自出面，肯定有好戏看。
林小满有些害怕，紧紧抓着萧烬的手臂。
萧烬轻轻拍了拍她的手，示意她不用紧张。
然后，他看向周护法，淡淡道：
"有意见？"
周护法冷笑。
"意见？我意见大了去了。"
"你一个无名小卒，也敢拒绝我们联盟的招揽？"
"知不知道得罪我们联盟是什么后果？"
他的气势压了过来，周围的空气都变得沉重。
"识相的，明天的大会上主动认输，然后加入我们联盟。"
"否则……"
他阴森森地笑了。
"后果自负。"

【萧烬反击】
全场鸦雀无声。
所有人都在看萧烬的反应。
萧烬看着周护法，嘴角微微上扬。
"否则什么？"
他的声音很平静，但周护法的表情却变了。
因为萧烬的眼神——
变了。
原本平静如水的眼神，突然变得锐利无比。
那一瞬间，周护法感觉自己被什么东西盯住了。
一股强大到令人窒息的气势，从萧烬身上爆发出来。
那气势——
像是一头远古凶兽在俯视猎物。
像是神明在审判凡人。
周护法的身体一僵，瞳孔猛然收缩。
"这……这是……"
他想后退，但身体不听使唤。
腿在发软。
额头在冒汗。
他的内心充满了恐惧。
这个年轻人……到底是什么怪物？！

【全场震惊】
萧烬没有动手，只是看着他。
"后果自负？"
他的声音淡淡的，但在周护法耳中，却像是雷鸣。
"你是在威胁我？"
周护法的嘴唇在颤抖。
他想说话，但一个字都说不出来。
那股气势太强了。
强到他连呼吸都困难。
"我……我……"
啪！
周护法双膝一软，竟然跪了下去！
全场哗然！
古武联盟的周护法，化劲巅峰的高手——
竟然被萧烬吓得跪下了？！
"这……这怎么可能？！"
"周护法那可是化劲巅峰！"
"萧烬没出手啊，只是一个眼神……"
"太可怕了……"
议论声此起彼伏。
所有人都震惊地看着这一幕。

【萧烬收势】
萧烬收回气势，周护法大口大口地喘气。
他撑着地面想站起来，但腿还在发软。
太丢人了！
他堂堂古武联盟的护法，居然被一个年轻人吓跪了！
"你……你……"他的声音沙哑，满是怨毒。
萧烬低头看着他，眼神平静。
"回去告诉你们联盟的人。"
"我萧烬，不是他们能招惹的。"
"明天的大会上，如果还有人敢挑衅我……"
他的嘴角微微上扬，带着一丝冷意。
"我不介意，让古武联盟在江南市消失。"
说完，他搂着林小满，转身离开。
留下周护法跪在原地，脸色铁青。
全场的人看着萧烬的背影，心中只有一个念头：
这个年轻人……深不可测！
```

## 六、场景四：陈长老提醒+伏笔（400-500字）

### 收尾设计

```
【陈长老的提醒】
萧烬带着林小满走到一个角落，陈长老悄悄凑了过来。
"萧先生，刚才那一幕，老夫看到了。"
萧烬看向他。
陈长老压低声音："萧先生的实力，让老夫佩服。"
"但……"
他的表情变得凝重。
"明天的大会，可能有变故。"
萧烬挑眉："什么变故？"
"古武联盟最近在暗中联络各方势力，似乎在策划什么。"
陈长老叹了口气。
"具体是什么，老夫也不清楚。"
"但萧先生小心无大错。"
萧烬点点头。
"多谢陈长老提醒。"
陈长老拍了拍他的肩膀。
"萧先生是个人才，老夫不希望你出事。"
说完，他转身离开。
萧烬看着他的背影，眼神深邃。
古武联盟在策划什么？
明天的大会，会出什么变故？
他不知道。
但不管是什么，他都不怕。

【林小满的骄傲】
"萧烬哥哥，你刚才好厉害！"
林小满眼睛亮亮的，紧紧抱着萧烬的手臂。
"那个坏人被你吓跪了！"
萧烬笑了笑。
"那种人，不值一提。"
"可是……"林小满有些担心，"他们会不会报复？"
"让他们来。"萧烬说，"我不怕。"
林小满看着他自信的侧脸，心里充满了崇拜。
萧烬哥哥……太帅了！

【各方反应】
与此同时，宴会厅的各个角落里，各方势力都在议论。
古武联盟的人聚在一起，脸色阴沉。
"这个萧烬，必须除掉！"
古武协会的人则是震惊。
"这年轻人的实力，恐怕不止炼气六层……"
修仙者联盟的玄元子眯着眼睛。
"有意思……明天的大会，会很精彩。"
而在远处的黑暗中，有一双眼睛在注视着这一切。
"萧烬……"
那人喃喃自语。
"你果然没让我失望。"
"明天，就让我看看，你到底有多强。"
风云将起。
大会，即将开幕。
```
