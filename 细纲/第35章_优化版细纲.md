# 第35章：拍卖会后续，暗影现身（优化版细纲）

**类型**：高潮章节 | **建议字数**：4000-5000字（以写透为准，不硬性限制）

---

## 一、核心事件

萧烬主动调查暗影组织，发现他们在江南市有据点。单枪匹马杀入据点，遭遇金丹期中期的暗影长老青冥子。激战后萧烬获胜，获取重要情报：暗影组织与昆仑派有关。

## 三、场景一：前往据点+突入（800-1000字）

### 场景定位
萧烬主动出击，杀入暗影据点。目的是：
1. 展现萧烬的主动性
2. 霸气侧漏的登场
3. 为战斗铺垫

### 五层展开

#### 【第1层：事件】
前往城郊 → 找到废弃工厂 → 直接闯入 → 秒杀门卫

#### 【第2层：感官细节】

**视觉**
```
1. 废弃工厂：
   - 城郊的一片荒废厂房
   - 外表破败，杂草丛生
   - 但有隐约的禁制波动

2. 萧烬的出场：
   - 大摇大摆走进去
   - 面对警卫毫不留情
   - 一掌一个，干净利落
```

**听觉**
```
1. 风声
2. 门卫的惊呼
3. 倒地的闷响
```

#### 【第3层：人物反应】

**萧烬**
```
- 走进据点：气定神闲
- 面对阻拦：不屑
- "挡路者，死。"
```

**门卫**
```
- 看到萧烬：震惊
- 想阻拦：被秒杀
- 来不及发出警报
```

#### 【第4层：内心活动】

**萧烬的杀意**
```
废弃工厂……
萧烬站在工厂门口，眼神冰冷。
这里就是暗影组织在江南的据点。
昨晚他们敢来伏击他，今天他就要让他们知道——
惹萧烬，是要付出代价的。
他迈步走了进去。
前世他是弑天魔尊，习惯了以攻代守。
坐以待毙？
不存在的。
```

### 具体内容

```
【前往城郊】
上午十点。
萧烬独自驾车来到城郊。
林小满还在休息，他没有带她。
今天的事，太危险了。
不适合她参与。
车子停在一片荒废的工业区外。
萧烬下车，看向前方。
一座破败的工厂，杂草丛生，看起来已经荒废多年。
但萧烬能感觉到，里面有禁制的波动。
还有……不少修仙者的气息。
最强的那个，是金丹期中期。
应该就是青冥子了。
萧烬的嘴角微扬。
"找到你了。"

【直接闯入】
他没有隐藏行踪，大摇大摆地走向工厂大门。
刚走到门口，两个黑衣人从阴影中现身。
"站住！这里是……"
话没说完，就被萧烬一掌拍飞。
砰！
两人砸在墙上，当场昏迷。
萧烬连看都没看他们一眼，继续往里走。
走廊里又冲出几个人，都是筑基期的修士。
"有敌袭！"
"快报告长老！"
萧烬懒得废话。
他抬起手，一道气劲激射而出。
噗噗噗——
几人全部倒地。
"挡路者，死。"
萧烬冷声道，继续前进。

【深入据点】
萧烬一路横推，没有任何人能挡住他。
工厂内部比外面看起来大得多。
又是空间扩展阵。
暗影组织的实力，确实不弱。
但在萧烬眼里，这些人都是蝼蚁。
很快，他来到了工厂最深处的一个大厅。
大厅里，一个黑袍老者正坐在主位上。
他的眼神阴沉，气息深不可测。
金丹期中期。
青冥子。
```

## 四、场景二：与青冥子对战（1800-2250字）【核心场景】

### 场景定位
本章核心爽点，萧烬碾压金丹期中期。

### 场景类型
战斗/碾压场景

### 五层展开

#### 【第1层：事件】
对峙 → 青冥子出手 → 激战 → 萧烬碾压

#### 【第2层：感官细节】

**视觉**
```
1. 青冥子：
   - 五十多岁的模样
   - 黑袍加身，气势阴森
   - 眼神如毒蛇

2. 战斗场景：
   - 青冥子使出各种阴毒招式
   - 萧烬见招拆招，游刃有余
   - 最后一击，青冥子被打飞
```

**听觉**
```
1. 灵气碰撞的爆鸣
2. 青冥子的怒吼
3. 萧烬淡然的话语
4. 青冥子被打飞的闷响
```

#### 【第3层：人物反应】

**青冥子**
```
- 最初：傲慢，自信
- 战斗中：震惊
- 被碾压后：恐惧
```

**萧烬**
```
- 战斗中：从容
- 碾压时：不屑
- "金丹期中期，也不过如此。"
```

#### 【第4层：内心活动】

**萧烬的评估**
```
金丹期中期……
萧烬和青冥子交手，心里在评估。
这老家伙的实力，在金丹期中期里算是上乘。
招式阴毒，经验丰富。
如果换成普通的筑基期来，肯定不是对手。
但萧烬不是普通的筑基期。
他前世是弑天魔尊，战斗经验远超这个老家伙。
青冥子的招式虽然阴毒，但在他眼里，破绽百出。
时间差不多了。
结束吧。
```

### 具体内容

```
【对峙】
萧烬走进大厅，与青冥子对视。
"你就是萧烬？"
青冥子的声音阴沉。
"好大的胆子，敢单枪匹马闯我暗影据点。"
萧烬淡淡道：
"你们敢来杀我，我就敢来灭你们。"
青冥子眯起眼睛。
"嚣张。"
"不过，我喜欢。"
他站起身，气势爆发。
金丹期中期的威压，席卷全场。
"让本座看看，你有什么本事！"

【激战】
青冥子出手了。
他的身形如鬼魅般闪动，出现在萧烬面前。
一爪抓向萧烬的心脏。
"阴蚀爪！"
这一招，他用过无数次，从来没有失手。
然而——
萧烬侧身一闪，轻松躲开。
然后反手一掌，拍向青冥子胸口。
青冥子大惊，急忙后退。
但萧烬的掌风还是擦到了他，将他逼退十几步。
"好快的速度！"
青冥子的脸色变了。
这个年轻人，只是筑基期吗？
怎么可能这么强？！
他不再试探，使出了全力。
"暗影千杀！"
无数道黑色的气劲从他身上激射而出，铺天盖地向萧烬袭去。
这一招，能同时攻击方圆十米内的所有目标。
就算是金丹期初期的高手，也难以全身而退。

【萧烬反击】
萧烬看着漫天的黑色气劲，嘴角微扬。
"雕虫小技。"
他一步踏出，整个人消失在原地。
下一秒，他出现在青冥子面前。
"怎么可能？！"青冥子惊骇欲绝。
他的暗影千杀居然没有击中萧烬？
萧烬抬起手，一掌拍下。
"太弱了。"
轰！！！
青冥子被这一掌直接拍飞出去，砸穿了身后的墙壁。
"咳……"
他吐出一口鲜血，挣扎着想起身，但发现全身的骨头都碎了。
萧烬走到他面前，居高临下。
"金丹期中期，也不过如此。"
青冥子的眼里满是恐惧。
这个年轻人……到底是什么怪物？！
他是金丹期中期！
在修仙界已经算是高手了！
怎么会被一个筑基期碾压？！
"你……你到底是谁……"
他颤声问道。
萧烬淡淡道：
"一个你惹不起的人。"
"现在，告诉我你们暗影组织的情报。"
"说了，我让你死得痛快。"
"不说……"
他的手指点在青冥子胸口。
"我有的是办法让你生不如死。"
```

## 五、场景三：获取情报+揭露真相（1000-1250字）【核心场景】

### 场景定位
萧烬审问青冥子，获取重要情报。

### 具体内容

```
【审问】
萧烬的手指按在青冥子的丹田上。
只要稍微用力，就能废掉他的修为。
对修仙者来说，废掉修为比死还难受。
"说吧。"萧烬说，"暗影组织是什么来头？"
青冥子的身体在颤抖。
他能感觉到萧烬手指上的力量。
只要萧烬愿意，他现在就是一个废人。
"我……我说……"
他再也没有之前的傲慢，只剩下恐惧。
"暗影组织……是昆仑派的分支……"
萧烬眯起眼睛。
"昆仑派？"
"是……"青冥子说，"昆仑派是修仙界的大派，势力庞大……"
"暗影组织是昆仑派的暗部，专门负责一些……见不得光的事。"
"刺杀、情报、暗中交易……都是我们在做。"
萧烬点点头。
"那三件古玉，你们为什么想抢？"
青冥子犹豫了一下。
"说！"萧烬加大了手上的力量。
"啊——"青冥子惨叫。
"我说！我说！"
"那三件古玉……是上古仙府的钥匙！"
"昆仑派的祖师爷发现了仙府的位置，但需要钥匙才能打开……"
"我们在各处寻找钥匙碎片，已经找到了三块……"
"加上你手里的三块，就凑齐六块了！"
萧烬的眼神闪了闪。
果然是仙府。
看来这个遗迹的价值，比他想象的还要大。

【更多情报】
"仙府在哪？"萧烬问。
"昆仑山脉深处……具体位置我不知道……"青冥子说。
"只有昆仑派的掌门和几个长老知道。"
萧烬继续问：
"你们暗影组织的总部在哪？"
"昆仑山脉……暗影峰……"
"还有什么我应该知道的？"
青冥子想了想，说：
"昆仑派……很强。"
"掌门是元婴期后期的高手，几个长老也都是元婴期。"
"你惹了我们暗影组织，昆仑派不会放过你的……"
萧烬嘴角微扬。
"元婴期？"
"那正好。"
"我正愁找不到对手练手呢。"
青冥子愣住了。
这个年轻人……是疯了吗？
元婴期啊！
他居然说……想找元婴期练手？！

【处理】
萧烬站起身。
"该知道的，我都知道了。"
"按照约定，我让你死得痛快。"
他抬起手。
青冥子闭上眼睛，脸上满是不甘。
他活了两百多年，没想到会死在一个年轻人手里。
"等等！"他忽然睁开眼睛，"我可以告诉你一个秘密！"
"你饶我一命，我把昆仑派的最大秘密告诉你！"
萧烬挑眉。
"什么秘密？"
"昆仑派的祖师爷……其实是一个魔修！"
萧烬的眼神微动。
"魔修？"
"是……"青冥子说，"昆仑派表面上是正道，其实骨子里是魔道！"
"他们修炼的功法，是上古魔门的功法！"
"仙府里的东西，也是魔门的遗产！"
萧烬沉默了一会儿。
"有意思。"
他收回手。
"这个情报，确实有价值。"
"我改变主意了。"
"你不用死。"
青冥子大喜。
"谢谢……谢谢萧先生……"
萧烬淡淡道：
"不过，你的修为，我要废掉。"
"不——"
话音未落，萧烬的手掌已经按在他的丹田上。
轰！
青冥子惨叫一声，昏死过去。
他的修为，被萧烬废掉了。
萧烬看着他，眼神冷漠。
"留你一命，是因为你还有用。"
"以后，你就是我的眼线。"
"昆仑派的一举一动，我要第一时间知道。"
```

## 六、场景四：萧烬决定+伏笔（400-500字）

### 收尾设计

```
【销毁据点】
萧烬离开之前，一把火烧了整个据点。
熊熊大火中，暗影组织在江南的势力，彻底覆灭。
萧烬站在火光中，眼神深邃。
昆仑派……魔门……仙府……
这个世界的水，比他想象的还要深。
但他不怕。
他前世就是魔门的弑天魔尊。
魔门的遗产，本来就应该属于他。
昆仑派想抢？
那就看看谁的拳头更硬。

【回到诊所】
下午，萧烬回到诊所。
林小满已经醒了，正在练习管理知识。
看到萧烬回来，她眼睛一亮。
"萧烬哥哥，你回来了！"
"嗯。"萧烬点头。
"去哪了？"
"处理了一些事。"萧烬说，"以后，应该没人敢来招惹我们了。"
林小满乖巧地点头，没有多问。
她知道萧烬有很多事不能告诉她。
但她相信萧烬。
不管做什么，萧烬哥哥一定是对的。

【伏笔】
就在萧烬回到诊所的同时，昆仑山脉深处。
暗影峰。
一个黑袍人收到了消息。
"青冥子的据点……被人灭了？"
他的声音冰冷。
"是谁干的？"
"回禀大人……是一个叫萧烬的年轻人……"
黑袍人沉默了一会儿。
"萧烬……"
他念着这个名字，眼神闪烁。
"有意思。"
"去查查他的底细。"
"如果他真的拿到了三块钥匙碎片……"
"那就派人去江南，把东西抢回来。"
"是！"
暗影涌动。
更大的风暴，即将来临。
```

## 十、本章预期效果

**读者读完第35章，应该：**

1. **爽**：碾压金丹期中期！
2. **惊讶**：昆仑派是魔门？
3. **期待**：仙府探索
4. **紧张**：昆仑派要来报复了
5. **佩服**：萧烬收了青冥子当眼线

**读者不应该觉得：**
- 战斗太简单
- 情报太多
- 敌人太弱
- 缺少悬念
