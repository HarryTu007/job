**类型**：铺垫章节 | **建议字数**：4000-5000字（以写透为准，不硬性限制）

## 一、核心事件

萧烬与李雅琴深入交谈，了解李家的秘密计划——寻找上古遗迹。李雅琴透露，李家手中有一份残缺的古地图，指向终南山深处的某个神秘位置。萧烬一眼看出古地图的玄机，震惊李雅琴。双方达成协议，萧烬同意帮助，但要分享遗迹中的收获。

## 三、场景一：李家密室+展示古地图（1000-1250字）

### 场景定位
承接第20章，李雅琴带萧烬进入更深处的密室，展示古地图。目的是：
1. 展现古地图的神秘
2. 李家三百年的执念
3. 为萧烬的分析做铺垫

### 五层展开

#### 【第1层：事件】
进入更深密室 → 展示古地图 → 李雅琴介绍来历 → 萧烬观察

#### 【第2层：感官细节】

**视觉**
```
1. 更深的密室：
   - 比之前的密室更古朴，更神秘
   - 墙壁上的符文更加复杂，隐隐发光
   - 中央是一个石台，上面放着一个玉匣

2. 古地图：
   - 材质不是普通纸张，像是某种兽皮
   - 泛黄，有破损的边角
   - 上面画着复杂的线条和符号
   - 某些地方有淡淡的光芒流转

3. 李雅琴的表情：
   - 凝重，带着期待
   - 小心翼翼地打开玉匣
   - 看向萧烬时，眼里有希望
```

**听觉**
```
1. 密室里非常安静，能听到心跳
2. 打开玉匣时的轻响
3. 展开古地图时，有轻微的沙沙声
```

**嗅觉**
```
1. 密室里有一股古老的气息
2. 古地图上有淡淡的檀香味，像是保存用的
```

**触觉**
```
1. 萧烬触摸古地图时，感受到材质的特殊
2. 有微弱的灵气波动
```

#### 【第3层：人物反应】

**李雅琴**
```
- 打开玉匣时：小心翼翼，像捧着稀世珍宝
- 展示古地图时：凝重地介绍
- 看萧烬反应时：紧张又期待
```

**萧烬**
```
- 进入密室时：扫视四周，眼神锐利
- 看到古地图时：眼神微动
- 触摸古地图时：神情若有所思
```

#### 【第4层：内心活动】

**萧烬的内心**
```
【看到古地图时】
这材质……
萧烬的眼神微微一动。
不是普通的兽皮，是蛟龙皮。
蛟龙是修仙界的低阶妖兽，皮革坚韧，能保存万年不腐。
用蛟龙皮制作的地图……
这东西的来历，绝对不简单。

【触摸古地图时】
萧烬的手指轻轻触碰地图表面。
有灵气波动。
虽然很微弱，但确实是灵气。
这说明……这张地图上，刻有阵纹。
而且是万年以上的古老阵纹。
李家说传承三百年？
太短了。
这张地图的源头，至少万年以上。
```

#### 【第5层：闲笔】

**闲笔**（约40字）
```
位置：打开玉匣时
内容：玉匣里铺着一层绒布，绒布已经发黄了，但还能看出曾经是鲜红色的。三百年的岁月，把一切都褪成了沧桑。
```

### 具体内容

```
【进入更深密室】
李雅琴带着萧烬，来到密室深处的一扇石门前。
她从怀里取出一块玉牌，贴在石门上。
石门上的纹路亮了一下，然后缓缓打开。
"萧先生，请。"
萧烬跟着她走了进去。
这个密室比外面那个更小，但更加古朴。
墙壁上刻着密密麻麻的符文，比外面的更加复杂，隐隐发着微光。
萧烬扫了一眼那些符文，心里有些惊讶。
这是……封印阵？
李家在这里封印着什么？

【展示古地图】
密室中央是一个石台，上面放着一个古朴的玉匣。
李雅琴走到石台前，深吸一口气，然后小心翼翼地打开玉匣。
玉匣里铺着一层绒布，绒布已经发黄了，但还能看出曾经是鲜红色的。
绒布上，放着一卷泛黄的卷轴。
李雅琴轻轻取出卷轴，放在石台上展开。
"萧先生，这就是李家传承三百年的秘密——上古遗迹地图。"
萧烬看向那张地图。
材质不是普通的纸张，像是某种兽皮。
泛黄，边角有些破损。
上面画着复杂的线条和符号，有些地方还有淡淡的光芒流转。

【李雅琴介绍】
"这张地图，是三百年前李家先祖在终南山深处发现的。"李雅琴说，"先祖偶然闯入一处山洞，发现了这张地图和一些其他东西。"
"从那以后，李家历代家主都在研究这张地图，想要找到地图上标注的位置。"
"但三百年过去了，我们始终没有成功。"
她看着萧烬，眼里带着期待。
"萧先生，您见多识广……能看出什么吗？"
```

## 四、场景二：萧烬分析古地图（1600-2000字）【核心场景】

### 场景定位
本章核心场景，萧烬展现前世见识，分析古地图。要写出：
1. 萧烬的博学
2. 古地图的秘密
3. 李雅琴的震惊
4. 前世记忆的闪回

### 场景类型
展示/分析场景（参考指南-场景类型八）

### 五层展开

#### 【第1层：事件】
萧烬仔细观察 → 指出地图来历 → 分析阵纹含义 → 推测遗迹位置

#### 【第2层：感官细节】

**视觉**
```
1. 萧烬分析时的动作：
   - 手指沿着地图上的线条移动
   - 眼神专注，像在回忆什么
   - 偶尔停顿，若有所思

2. 古地图的细节：
   - 被萧烬指出后，某些符号开始微微发光
   - 线条之间有隐藏的连接
   - 中心位置有一个特殊的标记
```

#### 【第3层：人物反应】

**萧烬**
```
- 分析时：专注，从容
- 说出结论时：淡然，像在说一件平常事
- 看到李雅琴震惊时：不以为意
```

**李雅琴**
```
- 听萧烬分析时：从疑惑到震惊
- 听到"万年以上"时：瞪大眼睛
- 听到萧烬见过类似阵纹时：彻底懵了
```

#### 【第4层：内心活动】

**萧烬的内心**（核心）
```
【分析阵纹时】
这些阵纹……
萧烬的眼神微微眯起。
太熟悉了。
这是上古时期的"定位阵纹"，专门用来标记某个特定位置。
他前世在一位老友的洞府里见过类似的阵纹。
那位老友说，这种阵纹是上古大能们用来标记自己洞府的。
如果这张地图上有这种阵纹……
那么，地图指向的那个遗迹，很可能是一位上古大能的洞府。

【回忆前世】
萧烬的脑海里，闪过一个画面。
那是他前世走访修仙界时，在某个秘境里看到的一幅壁画。
壁画上画着一座巍峨的山峰，山峰上有一座宫殿。
宫殿门口，刻着的阵纹……
和眼前这张地图上的，一模一样。
萧烬的心里，泛起一丝波澜。
难道……那位大能的洞府，就在这个世界？
```

### 具体内容

```
【萧烬开始分析】
萧烬走到石台前，俯身仔细观察那张地图。
他的手指轻轻触碰地图表面。
蛟龙皮。
和他猜的一样。
他的手指沿着地图上的线条移动，眼神专注。
良久，他开口了。
"这张地图的材质，是蛟龙皮。"
李雅琴一愣："蛟龙皮？"
"一种妖兽的皮革。"萧烬淡淡道，"坚韧耐腐，能保存万年不坏。"
李雅琴的瞳孔猛然收缩。
万年？！

【分析阵纹】
萧烬的手指停在地图的某个位置。
"这里，这里，还有这里。"他指了三个点，"你看到了吗？"
李雅琴凑过去看，只看到几个复杂的符号。
"我……我看不出什么……"
"这是定位阵纹。"萧烬说，"上古时期的大能们用来标记位置的。"
他的手指在三个点之间画了一个三角形。
"这三个点，构成一个三角阵。当三个点同时激活时，就能确定中心位置。"
他指向三角形的中心。
那里，有一个特殊的符号，像是某种文字，但又不是。
"这里，就是地图标注的遗迹位置。"
李雅琴整个人都愣住了。
三百年。
李家研究了三百年，都没看出来。
萧烬只看了几分钟，就分析得这么透彻。
这个人……到底是什么来历？

【萧烬的结论】
"三百年？"萧烬摇了摇头，"太短了。"
"这张地图的源头，至少万年以上。"
"你们李家只是偶然得到了它，并不是它的创造者。"
李雅琴张了张嘴，说不出话。
万年……
她以为三百年的传承已经够久了。
没想到，这张地图的历史，比李家长了无数倍。
"萧先生……"她艰难地开口，"您怎么会知道这些？"
萧烬看了她一眼，淡淡道：
"因为这种阵纹，我见过。"

【前世记忆闪回】
萧烬的脑海里，闪过一个画面。
那是他前世游历修仙界时，在某个秘境里看到的壁画。
壁画上画着一座巍峨的山峰。
山峰上有一座宫殿，庄严肃穆。
宫殿门口刻着的阵纹，和眼前这张地图上的，一模一样。
他记得，那位秘境的主人，是一位上古大能。
金丹期巅峰的强者，距离元婴只有一步之遥。
那位大能在渡劫时陨落了，但留下了大量的修炼资源和功法传承。
如果这张地图指向的，也是那位大能的遗迹……
萧烬的心里，泛起一丝期待。
也许，那里会有他需要的东西。
```

## 五、场景三：合作条件谈判（1000-1250字）【核心场景】

### 场景定位
双方谈判合作条件。要写出：
1. 萧烬的条件
2. 李雅琴的权衡
3. 达成协议
4. 各取所需

### 具体内容

```
【萧烬提出条件】
"萧先生，您愿意帮我们找到遗迹吗？"李雅琴问，语气里带着期待。
萧烬看着她，没有立刻回答。
他在权衡。
帮李家找到遗迹，对他有什么好处？
李家给的商业支持？
那点东西，他不在乎。
但遗迹里的东西……
如果真是那位上古大能的洞府，里面的修炼资源，对他来说非常重要。
"可以帮忙。"萧烬开口了。
李雅琴脸上一喜。
"但我有条件。"
李雅琴的表情变得凝重："萧先生请说。"

【条件一】
"第一。"萧烬说，"遗迹里的东西，我要优先选择权。"
"你们李家可以得到大部分，但我要先挑。"
李雅琴沉默了几秒。
优先选择权……
这意味着最好的东西，可能会被萧烬拿走。
但如果没有萧烬，他们根本找不到遗迹。
什么都得不到。
"好。"她点头。

【条件二】
"第二。"萧烬继续说，"探索遗迹的时候，我要亲自参与。"
"而且，我要带人一起去。"
"带人？"李雅琴有些疑惑，"带谁？"
"林小满。"
李雅琴愣了一下，然后点头。
林小满……那是萧烬的女人。
带她一起去，也能理解。
"没问题。"

【条件三】
"第三。"萧烬的眼神变得锐利，"如果在遗迹里发现什么……与我有关的东西。"
"那东西，无条件归我。"
李雅琴皱眉："与您有关的东西？"
"你不用管是什么。"萧烬淡淡道，"只要答应就行。"
李雅琴沉默了很久。
她不知道萧烬说的"与他有关的东西"是什么。
但看萧烬的态度，似乎非常重要。
"好。"她最终点头，"我答应您。"

【达成协议】
萧烬站起身。
"那就这么说定了。"
"古武大会结束后，我们就去终南山探索遗迹。"
李雅琴也站起来，深深鞠了一躬。
"萧先生，李家感激不尽。"
萧烬淡淡道："不用感谢。各取所需。"
他转身往外走。
走到门口时，忽然停下。
"对了，那张地图上的中心符号……"
他回头，看着李雅琴。
"不是普通的文字，是上古时期的'封印符'。"
"遗迹的入口，需要特殊的方法才能打开。"
"到时候，我来处理。"
说完，他推门出去。
李雅琴愣在原地。
封印符……
萧烬连这个都知道？
他到底……是什么人？
```

## 六、场景四：伏笔+收尾（400-500字）

### 收尾设计

```
【萧烬的思考】
离开李家，萧烬走在夜色中。
他的脑海里，还在回想那张古地图。
定位阵纹，封印符……
都是上古大能的手笔。
那位大能，会是他前世认识的人吗？
萧烬想起了一些名字。
前世修仙界有很多大能，其中有些和他有过交集。
有朋友，也有敌人。
如果那个遗迹的主人，是他认识的人……
事情可能会变得有趣。
萧烬的嘴角微微上扬。
古武大会，上古遗迹……
这个世界，越来越有意思了。

【回到诊所】
回到诊所，已经很晚了。
林小满还在等他。
"萧烬哥哥，你回来了！"她迎上来，"怎么去了这么久？"
"有点事。"萧烬看着她担心的表情，嘴角微扬，"不用担心。"
"什么事？"
"以后再告诉你。"萧烬揉了揉她的头，"先睡觉。"
林小满虽然好奇，但没有多问。
她相信萧烬，不管是什么事，他都能处理好。

【悬念埋设】
就在萧烬准备休息的时候，他忽然感觉到一道目光。
从很远的地方投来。
那目光……带着审视，带着好奇，还有一丝……危险。
萧烬的眼神微眯。
有人在监视他。
而且，那个人的修为……很高。
至少金丹期。
萧烬没有声张，只是淡淡一笑。
"有意思。"
他关上窗户，躺到床上。
不管是谁，想要对付他，都要掂量掂量自己的分量。
而现在，他需要好好休息。
明天，还有很多事要做。
```

## 十、本章预期效果

**读者读完第21章，应该：**

1. **惊叹萧烬见识**：万年前的阵纹都认识
2. **好奇遗迹**：里面有什么？
3. **期待探索**：古武大会后就去
4. **好奇监视者**：金丹期是谁？
5. **感受前世联系**：萧烬和遗迹有关系？

**读者不应该觉得：**
- 设定太复杂
- 分析太长
- 缺少悬念
- 节奏太慢
