# 第19章：古武联盟来人，两方拉拢（优化版细纲）

**类型**：铺垫章节 | **建议字数**：4000-5000字（以写透为准，不硬性限制）

---

## 一、核心事件

古武联盟果然派人来拉拢萧烬，来者是一名年轻高手周刚（化劲巅峰），态度傲慢。萧烬不卑不亢，一个眼神让周刚腿软。最终萧烬表示会参加古武大会，但不会提前选边站。两方势力都不满意，但也无可奈何。苏震天透露古武联盟的阴谋。

---

## 三、场景一：周刚登门+傲慢挑衅（800-1000字）

### 场景定位
承接第18章末尾，古武联盟派人来了。目的是：
1. 展现周刚的傲慢
2. 形成与陈长老的对比
3. 为后续冲突做铺垫

### 五层展开

#### 【第1层：事件】
周刚带人到访 → 傲慢开场 → 提出条件 → 萧烬冷淡回应

#### 【第2层：感官细节】

**视觉**
```
1. 周刚的形象：
   - 二十七八岁，身材高大，穿着黑色唐装
   - 脸上带着倨傲的神情，眼神锐利
   - 走路的姿势很嚣张，像是谁都不放在眼里

2. 随从：
   - 两个黑衣人跟在身后
   - 同样是古武者，大约明劲境界
   - 态度恭敬地跟着周刚

3. 诊所内：
   - 萧烬坐在诊室里，平静地看着来人
   - 林小满站在旁边，有些紧张
   - 张明远在前台，皱着眉
```

**听觉**
```
1. 周刚的脚步声，很重，像是在示威
2. 他说话的声音，带着居高临下的意味
3. 林小满小声的惊呼
```

#### 【第3层：人物反应】

**周刚**
```
- 进门时：傲慢，不把任何人放在眼里
- 看到萧烬时：打量，带着轻蔑
- 提出条件时：理所当然，觉得萧烬应该感恩
```

**萧烬**
```
- 看到周刚时：平静，没有任何波动
- 被轻视时：淡淡一笑，不以为意
- 听到条件时：挑眉，带着玩味
```

**林小满**
```
- 看到周刚时：有些紧张
- 感受到周刚的敌意时：往萧烬身边靠
- 萧烬安抚后：稍微放松
```

#### 【第4层：内心活动】

**萧烬的内心**
```
萧烬看着周刚，心里有些好笑。
化劲巅峰。
在这个世界，算是不错的境界了。
但这副傲慢的样子……
像极了前世那些井底之蛙。
觉得自己是天才，觉得别人都应该跪着。
直到被打脸，才知道天外有天。
萧烬的嘴角微微上扬。
那就让他见识见识，什么叫真正的强者。
```

#### 【第5层：闲笔】

**闲笔**（约40字）
```
位置：周刚进门时
内容：门口的盆栽被周刚身上的气势压得叶子都垂了下去。林小满心疼地看了一眼。
```

### 具体内容

```
【周刚登门】
第二天上午。
天机诊所刚开门，就有人来了。
三个人，走在最前面的是个年轻男人。
他二十七八岁，身材高大，穿着黑色唐装，脸上带着倨傲的神情。
他走路的姿势很嚣张，像是这个世界都归他管。
门口的盆栽被他身上的气势压得叶子都垂了下去。
林小满心疼地看了一眼那盆花。
张明远迎了上去："请问几位……"
"萧烬在哪？"年轻男人打断他，语气傲慢。
张明远皱眉："请问您是……"
"我是古武联盟的人。"年轻男人冷冷道，"周刚。"
他说这话的时候，声音很大，像是要让所有人都听到。
古武联盟？
张明远愣了一下。
他知道古武联盟——苏震天之前提过，那是和古武协会齐名的大势力。
"请稍等，我去通报一下。"
"不用通报了。"周刚往里走，"我自己去。"

【傲慢开场】
诊室里。
萧烬正坐在椅子上，闭目养神。
周刚推门而入，打量着萧烬。
"你就是萧烬？"
萧烬睁开眼睛，看了他一眼。
"你是？"
"古武联盟，周刚。"周刚的下巴微微抬起，"我奉盟主之命，来给你一个机会。"
"机会？"萧烬挑了挑眉，"什么机会？"
"我们联盟主，愿意给你一个护法的位置。"周刚说，语气里带着施舍的意味，"你应该知道这意味着什么。护法，在联盟里是仅次于盟主和长老的存在。以你的年纪，能得到这个位置，应该感恩戴德才对。"
他说完，看着萧烬，等着他激动的反应。
但萧烬——
只是淡淡地笑了笑。
"护法？"
他的语气很平静，像是在说一件微不足道的事。
"你们盟主配吗？"
```

## 四、场景二：对峙+气势压制（1600-2000字）【核心场景】

### 场景定位
本章核心场景，要写出：
1. 周刚被气势压制
2. 萧烬的强势
3. 两个随从的震惊
4. 场面的张力

### 场景类型
对话/交流场景 + 气势对决（参考指南-场景类型七）

### 五层展开

#### 【第1层：事件】
周刚震怒 → 释放气势 → 被萧烬反压 → 腿软跪地 → 彻底服软

#### 【第2层：感官细节】

**视觉**
```
1. 周刚释放气势时：
   - 身上的衣服无风自动
   - 眼神变得凌厉
   - 气势外放，形成可见的涟漪

2. 萧烬反压时：
   - 眼神微冷
   - 只是淡淡看了一眼
   - 一股无形的压力向周刚压去

3. 周刚被压制后：
   - 脸色惨白
   - 额头冷汗直流
   - 双腿发软，跪倒在地
```

**听觉**
```
1. 周刚释放气势时的呼啸声
2. 萧烬释放气势时的死寂
3. 周刚跪地的声音
4. 两个随从的惊呼
```

**触觉**
```
1. 林小满感受到的压力，像有什么东西压在胸口
2. 萧烬气势释放时的窒息感
3. 周刚跪地时膝盖撞击地面的疼痛
```

#### 【第3层：人物反应】

**周刚**
```
- 被激怒时：震怒，释放气势
- 被反压时：震惊→恐惧→挣扎
- 跪地后：颤抖，说不出话
- 气势收回后：惊魂未定，满头冷汗
```

**两个随从**
```
- 看到周刚释放气势时：得意
- 看到萧烬反压时：震惊
- 周刚跪地时：吓傻了
- 最后：瑟瑟发抖，不敢动
```

**林小满**
```
- 周刚释放气势时：害怕，往萧烬身边靠
- 萧烬反压时：震惊，心跳加速
- 周刚跪地时：瞪大眼睛
- 最后：崇拜地看着萧烬
```

#### 【第4层：内心活动】

**萧烬的内心**（简短有力）
```
【被激怒时】
这小子……还挺冲。
萧烬看着周刚释放的气势，心里有些好笑。
化劲巅峰的气势，在他面前……
像蚂蚁在冲大象示威。
也罢，给他一个教训。

【释放气势时】
萧烬的眼神微冷。
他没有释放全部气势，只是放出了十分之一。
对付一个化劲巅峰的小子，十分之一足够了。

【周刚跪地后】
萧烬收回气势，端起茶杯。
这种程度的货色，也配来找他的麻烦？
古武联盟……也不过如此。
```

**周刚的内心**
```
【释放气势时】
这小子敢侮辱盟主？
找死！
我让他知道，什么叫古武联盟的威严！

【被反压时】
这……这是什么气势？！
我……我动不了……
太强了……比盟主还强……不……比盟主强得多……
这……这不可能……

【跪地后】
完了……
我得罪了一个恐怖的存在……
盟主……盟主救我……
```

#### 【第5层：闲笔】

**闲笔1**（约30字）
```
位置：气势对撞时
内容：诊室角落的药柜玻璃发出轻微的颤抖声，像在经历一场无声的地震。
```

**闲笔2**（约40字）
```
位置：周刚跪地后
内容：门外有个病人刚要进来，看到这一幕，吓得转身就跑。他不知道发生了什么，但直觉告诉他，快跑。
```

### 具体内容

**小节A：周刚震怒（约400字）**

```
【震怒】
周刚整个人都愣住了。
他……他说什么？
你们盟主配吗？
这是他听过的最嚣张的话。
盟主是什么人？
筑基期中期的强者！
整个古武界，除了协会的那几个老怪物，没有人是盟主的对手！
一个名不见经传的小子，敢说盟主"不配"？
"你找死！"
周刚怒吼一声，身上的气势猛然爆发。
化劲巅峰！
他修炼了二十多年，才达到这个境界。
在同龄人中，已经是顶尖的天才。
他的气势像一阵狂风，席卷整个诊室。
桌上的纸张被吹得四散，茶杯滑向桌边。
林小满脸色一白，下意识往萧烬身边靠。
两个随从得意地看着萧烬，等着他跪地求饶。

【对峙】
但萧烬——
只是平静地看着周刚。
他甚至没有站起来。
"就这？"
他的声音很轻，但在周刚耳中，却像是惊雷。
"化劲巅峰的气势……"萧烬摇了摇头，"还不够。"
他的眼神，微微一冷。
周刚感觉到了不对。
他的气势……被什么东西压住了？
不对——
是被吞噬了！
```

**小节B：气势反压（约500字）**

```
【萧烬出手】
萧烬没有站起来。
他只是淡淡地看了周刚一眼。
就这一眼——
轰！
一股恐怖的气势，从萧烬身上爆发出来。
那气势像是山崩海啸，瞬间淹没了周刚的气势。
周刚的脸色瞬间变得惨白。
他感觉自己像是站在一座活火山的喷发口。
那种压迫感，那种窒息感，让他连呼吸都困难。
"我……"
他想说话，但嗓子像是被什么东西卡住，一个字都发不出。
他想动，但身体像是被冻住了，一丝一毫都动不了。
他只能瞪大眼睛，看着萧烬。
那双眼睛……太可怕了。
像是一片深渊，能把人吞噬。
"扑通！"
周刚的双腿一软，直接跪在了地上。
他的膝盖重重地砸在地板上，发出一声闷响。
但他感觉不到疼痛。
因为他的全部注意力，都被萧烬的气势占据了。

【随从的反应】
两个随从整个人都傻了。
周少……跪下了？
化劲巅峰的周少，被一个眼神压跪了？
他们想冲上去帮忙，但身体根本动不了。
那股气势同样压在他们身上，让他们连抬手都做不到。
"我……我们……"
其中一个随从的声音在发抖。
他们见过很多强者，但从来没见过这么恐怖的。
这个人……到底是什么怪物？

【林小满的反应】
林小满瞪大了眼睛。
她虽然感受到了萧烬的气势，但那股压力没有落在她身上。
萧烬在保护她。
她看着跪在地上的周刚，又看看坐在椅子上喝茶的萧烬。
萧烬哥哥……好厉害……
```

## 五、场景三：萧烬霸气表态（1000-1250字）【核心场景】

### 场景定位
本章爽点，要写出：
1. 萧烬不选边站的态度
2. 对两方势力的态度
3. 霸气宣言
4. 林小满的崇拜

### 五层展开

#### 【第1层：事件】
陈长老再次来访 → 询问态度 → 萧烬表态 → 两边都不选

#### 【第2层：人物反应】

**陈玄清（再次来访）**
```
- 来时：满怀期待
- 听到萧烬态度后：有些失望
- 但又释然：这种人，确实不该站队
```

**萧烬**
```
- 面对询问：从容
- 表态时：霸气，不容置疑
- "我只站我自己"
```

### 具体内容

```
【陈长老再次来访】
周刚走后不久，陈玄清又来了。
"萧先生。"他一进门就问，"联盟的人来过了？"
"来过了。"萧烬淡淡道。
"他们说了什么？"
"给我一个护法的位置。"
陈玄清的眉头皱了起来。
护法？
联盟出手倒是大方。
但他知道，以萧烬的实力，护法这个位置根本不够。
"萧先生怎么回答的？"
"我让他回去告诉盟主，想让我加入，让他亲自来谈。"
陈玄清愣了一下，然后笑了。
"好！说得好！"
他的眼神里带着欣赏。
这个年轻人，确实有傲气的资本。

【陈玄清的请求】
"那……萧先生对协会是什么态度？"陈玄清小心翼翼地问。
他知道萧烬的实力深不可测，不敢太过逼迫。
萧烬看着他，沉默了几秒。
"陈长老，我直说了吧。"
他的语气很平静，但带着一种不容置疑的威严。
"古武协会也好，古武联盟也好，我都不会加入。"
陈玄清的脸色变了。
"萧先生……"
"三个月后的古武大会，我会去。"萧烬打断他，"但只是去看看，不会提前选边站。"
他站起身，走到窗边，望着窗外。
"这个世界的古武界，在我眼里只是一群玩泥巴的孩子。"
他回头，看着陈玄清，眼神深邃。
"不管是协会还是联盟，都不值得我投靠。"
"我只站……我自己。"

【陈玄清的反应】
陈玄清沉默了。
萧烬的话虽然狂，但他说不出反驳的话。
因为萧烬有狂的资本。
一个眼神就能压跪化劲巅峰的高手……
这种实力，别说在年轻一辈，就是整个古武界，能找出几个？
"萧先生的意思，老夫明白了。"他最终叹了口气，"不管怎样，三个月后，终南山见。"
他拱手告辞，离开了诊所。
走出门的时候，他忽然想起一句话——
真龙不屑与群蛇为伍。
萧烬这种人……
也许注定不属于任何势力。
他只属于他自己。

【林小满的崇拜】
陈玄清走后，林小满从后面走出来。
"萧烬哥哥……"她的眼睛亮亮的，"你好厉害！"
"什么？"
"刚才你说的话！"林小满学着萧烬的样子，"我只站我自己！"
她的眼睛里满是星星。
"太帅了！"
萧烬看着她崇拜的表情，嘴角微扬。
"去给我倒杯茶。"
"好！"林小满开心地跑去倒茶。
```
