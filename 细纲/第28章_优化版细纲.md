# 第28章：盟主出手，震慑全场（优化版细纲）

**类型**：高潮章节 | **建议字数**：4000-5000字（以写透为准，不硬性限制）

---

## 一、核心事件

龙天行（元婴期初期）亲自下场试探萧烬。萧烬感受到巨大压力，但依然从容应对。龙天行释放部分修为压制，萧烬硬扛三招不败！龙天行震惊之余收手，对萧烬态度大变，主动邀请萧烬加入古武联盟担任客卿。萧烬霸气拒绝。

## 三、场景一：对峙+气氛紧张（600-750字）

### 场景定位
萧烬与龙天行对峙，全场气氛凝重。目的是：
1. 展现元婴期的压迫感
2. 制造紧张感
3. 突出萧烬的勇气

### 五层展开

#### 【第1层：事件】
两人对峙 → 龙天行释放气势 → 全场压力 → 萧烬不为所动

#### 【第2层：感官细节】

**视觉**
```
1. 龙天行：
   - 五十多岁，但精神矍铄
   - 气势惊人，像一座高山
   - 俯视萧烬的眼神

2. 萧烬：
   - 与龙天行对视
   - 神情平静，没有任何惧色
   - 气势虽弱，但稳如磐石

3. 全场：
   - 很多人被气势压得喘不过气
   - 林小满脸色苍白
   - 陈长老等人神色紧张
```

**听觉**
```
1. 龙天行威压下的嗡鸣
2. 有人跪倒的声音
3. 全场压抑的呼吸声
```

#### 【第3层：人物反应】

**龙天行**
```
- 释放气势，试探萧烬
- 发现萧烬不为所动：微微惊讶
- "你的定力，不错。"
```

**萧烬**
```
- 感受到压力，但不动如山
- 内心："元婴期……有点意思。"
```

### 具体内容

```
【对峙】
萧烬跃上擂台，与龙天行相距十米。
两人对视。
元婴期初期vs炼气期七层。
境界差距，天壤之别。
龙天行的嘴角微微上扬。
"年轻人，你的胆子，很大。"
"知道和我对战意味着什么吗？"
萧烬淡淡道："请赐教。"
龙天行眯起眼睛。
"好。那本盟主就让你见识一下——"
"什么叫元婴期的力量！"
他的气势骤然爆发！

【气势压制】
恐怖的压力席卷全场。
这是元婴期的威压！
擂台下，很多实力弱的人直接跪倒在地。
林小满的双腿发软，苏震天扶着她，脸色也很难看。
"这……这就是元婴期的实力？"
"太可怕了！"
"萧烬能扛住吗？"
所有人都为萧烬担心。
但萧烬——
依然站得笔直。
他的表情没有任何变化，平静如水。
龙天行的眼神闪了闪。
"你能扛住我的气势？"
萧烬淡淡道："就这？"
全场哗然。
"萧烬说'就这'？！"
"他疯了吗？那可是元婴期的威压！"
龙天行的嘴角抽了抽。
这小子……好大的口气！
```

## 四、场景二：三招对决（1800-2250字）【核心场景】

### 场景定位
萧烬硬扛龙天行三招，展现潜力。

### 场景类型
战斗场景（高压）

### 五层展开

#### 【第1层：事件】
第一招 → 萧烬扛住 → 第二招 → 勉强化解 → 第三招 → 全力抵挡

#### 【第2层：感官细节】

**视觉**
```
1. 龙天行出手：
   - 每一招都带着恐怖的压迫感
   - 空间都在震动
   - 擂台出现裂痕

2. 萧烬应对：
   - 第一招：稳稳挡住
   - 第二招：被逼退几步
   - 第三招：浑身发力，艰难抵挡
```

**听觉**
```
1. 每一招的爆炸声
2. 擂台碎裂的声音
3. 萧烬沉闷的低吼
4. 全场的惊呼
```

**触觉**
```
1. 每一招带来的巨大冲击
2. 身体承受的压力
3. 第三招后的酸痛
```

#### 【第3层：人物反应】

**龙天行**
```
- 第一招后：意外
- 第二招后：震惊
- 第三招后：难以置信
```

**萧烬**
```
- 第一招：从容
- 第二招：认真
- 第三招：全力
- 三招后：喘着气，但还站着
```

#### 【第4层：内心活动】

**萧烬的感悟**
```
元婴期初期……
萧烬承受着龙天行的攻击，心里在评估。
这老家伙的实力，确实很强。
每一招都蕴含着元婴期特有的灵魂压制。
普通的炼气期，别说三招，一招都扛不住。
但他不是普通的炼气期。
他前世是弑天魔尊，对灵魂攻击有天然的抵抗力。
再加上前世的战斗经验，他能预判龙天行的出招路线。
三招……
应该能扛住！

【第三招时】
好强的力量！
萧烬感觉自己的骨头都在发出咯吱声。
龙天行的第三招，比前两招强了不止一倍。
这老家伙，是真的要试他的底了。
但萧烬没有退缩。
他咬紧牙关，全身灵气爆发，硬扛了下来！
```

### 具体内容

```
【第一招】
"既然你这么自信，那就试试本盟主的招数。"
龙天行抬起手，轻轻一挥。
看似轻描淡写的一挥，却蕴含着恐怖的力量。
空间都在颤抖！
全场倒吸凉气。
萧烬的眼神一凝，双手抬起，迎了上去。
轰！
两股力量碰撞，发出惊天的巨响。
萧烬的脚下，擂台出现了蜘蛛网般的裂痕。
但他——站住了！
"哦？"龙天行有些意外，"你能接住我这一招？"
萧烬淡淡道："还行。"
全场再次哗然。
"他接住了！萧烬接住了元婴期的攻击！"
"太不可思议了！"
林小满紧握双手，眼眶微红。
"萧烬哥哥……"

【第二招】
龙天行的眼神变得认真了。
"看来，你确实有些本事。"
"那这第二招，你也试试。"
他这一次，没有轻轻挥手。
而是直接一拳轰出！
这一拳——
带着元婴期的全部威压！
空气都被压缩，发出尖锐的声响。
萧烬的表情变了。
这一招，比刚才强太多了！
他没有硬接，而是侧身闪避，同时双手化掌，拍向龙天行的拳头侧面。
借力打力！
轰！
萧烬被逼退了五步，但成功化解了这一招。
"好！"龙天行大喝，"借力打力，用得不错！"
"但第三招，你还能接吗？"

【第三招】
龙天行的气势再次攀升。
这一次，他没有留手。
元婴期初期的全部实力，在这一刻爆发！
"龙天行用全力了！"陈长老脸色大变，"不好！萧烬扛不住！"
玄元子也站了起来，表情凝重。
林小满的脸色苍白。
"萧烬哥哥！"
龙天行一掌拍出。
这一掌，空间都在扭曲！
萧烬的瞳孔收缩。
这一招……太强了！
但他没有退缩。
退缩，就意味着认输。
他前世是弑天魔尊，从来不知道什么叫认输！
"来吧！"
萧烬暴喝一声，体内灵气全部爆发。
炼气期七层的全部力量，凝聚在双手。
迎着龙天行的掌力，硬扛了上去！
轰！！！
惊天的巨响！
擂台直接塌了一块。
萧烬的身体剧烈颤抖，嘴角溢出一丝鲜血。
但他——
依然站着！
没有倒下！
全场死寂。
然后，是雷鸣般的惊呼！
"他……他接住了！"
"三招！萧烬扛住了龙天行三招！"
"炼气期扛住元婴期三招，这是什么怪物？！"
```

## 五、场景三：龙天行态度转变+邀请（1200-1500字）【核心场景】

### 场景定位
龙天行态度大变，主动邀请萧烬。

### 具体内容

```
【龙天行的震惊】
龙天行看着萧烬，眼神复杂。
震惊，难以置信，还有……欣赏。
"炼气期扛住我三招……"
他喃喃道。
"本盟主行走江湖几十年，还是第一次见到。"
他收回气势，负手而立。
"你叫萧烬，对吧？"
萧烬擦去嘴角的血迹，淡淡道："是。"
"你很强。"龙天行说，"你的实力，远不止炼气七层。"
"我不知道你有什么秘密，但你的潜力，让我刮目相看。"
萧烬不置可否。

【态度转变】
龙天行的表情变了。
从刚才的居高临下，变成了平等对话。
"年轻人，本盟主有个提议。"
他说。
"今天的事，就到这里。"
"之前联盟的人得罪了你，本盟主替他们道歉。"
全场哗然。
"龙天行道歉？！"
"古武联盟的盟主，向萧烬道歉？！"
这可是前所未有的事！
古武联盟的人脸色难看，但不敢吭声。
周护法和赵铁山更是面如死灰。
他们没想到，盟主会为了萧烬，向他们的敌人道歉。

【邀请】
"除了道歉，本盟主还有一个邀请。"
龙天行继续说。
"来我们古武联盟，担任客卿。"
"地位仅次于本盟主，资源随便用。"
全场再次震惊。
客卿？
这可是古武联盟最尊贵的位置之一！
很多人奋斗一辈子都得不到的荣誉！
龙天行居然主动送上门？
"盟主疯了吗？"
"萧烬刚才还把他们联盟的人打得满地找牙……"
"看来龙天行是真的看上萧烬了。"
林小满紧张地看着萧烬。
她不想萧烬加入古武联盟。
苏震天和陈长老也在等萧烬的回答。
所有人，都在看萧烬。

【萧烬的反应】
萧烬看着龙天行，嘴角微扬。
"客卿？"
他轻轻吐出两个字。
然后，又吐出两个字。
"不够格。"
全场死寂。
不够格？
萧烬说古武联盟的客卿位置……不够格？！
龙天行的眼神微变。
"你的意思是？"
萧烬淡淡道："我说了，不够格。"
"客卿这个位置，对我来说，太小了。"
"你想让我加入古武联盟，除非——"
他看着龙天行的眼睛，一字一顿。
"你把盟主的位置让给我。"
```

## 六、场景四：霸气拒绝+伏笔（400-500字）

### 收尾设计

```
【全场哗然】
萧烬的话，像一颗炸弹，在全场爆炸。
"他……他让龙天行让位？！"
"这也太狂了吧！"
"萧烬疯了！他才炼气七层，居然敢这么说话！"
古武联盟的人脸色铁青。
周护法愤怒道："大胆！你知道你在和谁说话吗？！"
但龙天行抬手制止了他。
他看着萧烬，眼神复杂。
"有意思。"
他笑了。
"你是第一个敢这么和我说话的人。"
"也好，既然你不愿意加入，那就当朋友吧。"
"以后有机会，我们再切磋。"
他转身跃下擂台，带着古武联盟的人离开。
走之前，他回头看了萧烬一眼。
"年轻人，我记住你了。"
"希望下次见面，你能更强。"
萧烬淡淡道："会的。"

【陈长老的提醒】
龙天行离开后，陈长老走过来。
"萧先生，你今天表现太出色了。"
他压低声音。
"但你也把古武联盟得罪透了。"
"以后要小心。"
萧烬点点头。
"多谢陈长老提醒。"
陈长老叹了口气。
"今天的大会，你是最大的赢家。"
"接下来的颁奖，你好好表现。"
萧烬笑了笑。
"好。"

【神秘人的注视】
人群中，那个神秘人看着萧烬离开的背影。
"有意思……硬扛元婴期三招。"
"这小子的潜力，比我想象的还大。"
他的眼神闪烁。
"魔尊的传人……不，也许不只是传人。"
"也许，他就是魔尊本人的转世。"
他转身消失在人群中。
"我要回去禀报了。"
"这个人……很重要。"
```
