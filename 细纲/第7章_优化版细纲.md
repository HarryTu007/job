# 第7章：治疗李雅琴，李建国登场（优化版细纲）

**类型**：铺垫章节 | **建议字数**：4000-5000字（以写透为准，不硬性限制）

---

## 一、核心事件

李雅琴带萧烬去她家，治疗她的暗疾（宫寒之症，导致不孕）。萧烬炼制九阳回春丹，成功治愈。李建国（市首富）登场，看到女儿被治愈，震惊于萧烬的医术，主动结交。本章核心是"人脉拓展"，同时展现萧烬的炼丹能力和医者仁心。

---

## 三、场景一：李家别墅+病情说明（800-1000字）

### 场景定位
承接上章，李雅琴带萧烬去她家。目的是：
1. 展现李家的富贵（但不俗气）
2. 说明李雅琴的病情
3. 萧烬诊断，给出方案

### 五层展开

#### 【第1层：事件】
李雅琴开车带萧烬去李家别墅 → 进入别墅 → 说明病情 → 萧烬诊断

#### 【第2层：感官细节】

**视觉（主导）**

```
1. 别墅外观：
   - 城郊的独栋别墅，占地至少五亩
   - 不是那种暴发户式的金碧辉煌，而是低调的新中式风格
   - 院子里种着几株古松，树龄至少上百年
   - 门口两座石狮子，造型古朴，萧烬扫了一眼——明代的

2. 别墅内部：
   - 装修走的是简约路线，但每一件摆设都价值不菲
   - 墙上挂着一幅字——萧烬认出是某位现代大师的真迹
   - 茶几上放着一套紫砂茶具，品相极好

3. 李雅琴的变化：
   - 回到家后，她放松了很多，脱下了高跟鞋
   - 换了一身家居服，素颜比化妆还要好看
```

**听觉**

```
1. 别墅很安静，隐约能听到院子里假山流水的声音
2. 有人在弹古琴，清越悠扬——大概是家里的音响在放
3. 管家是个六十多岁的老人，说话轻声细语
```

**嗅觉**

```
空气里弥漫着淡淡的檀香味。
萧烬注意到客厅角落有一座香炉，里面点着檀香。
这种香，有安神的作用，但对李雅琴的病没什么帮助。
```

#### 【第3层：对话设计】

**病情说明**

```
李雅琴让管家退下，只留下她和萧烬两个人。
"萧先生，有件事我没跟您说。"
她犹豫了一下。
"您给我的美容丹，效果确实很好。但其实……我还有一个毛病。"
萧烬看着她，等她继续。
"宫寒。"李雅琴的声音有些低，"从十几岁就开始了。看过无数大夫，中医、西医、偏方，都没用。"
她苦笑了一下。
"医生说，我这辈子可能都很难……怀孕。"
她没有哭，只是笑得很勉强。
"我爸为了这件事，操碎了心。找遍了全国的名医，都没办法。"
"上次见您的时候，我本来想问问您有没有办法。但又怕……"
她没说下去。
怕萧烬也没办法，怕希望再次落空。
```

**萧烬诊断**

```
萧烬听完，没有说话。
他走到李雅琴面前，伸出手。
"把手给我。"
李雅琴愣了一下，然后把手伸了过去。
萧烬的手指搭在她的手腕上，闭上眼睛。
房间里安静了下来。
一分钟后，萧烬睁开眼睛。
"宫寒确实严重。你这是先天性的，后天又受了寒气入侵，两者叠加，普通医术根本治不好。"
李雅琴的脸色暗了暗。
"但对我来说……"萧烬松开手，"小问题。"
李雅琴猛然抬头。
"什么？"
"我能治。"萧烬说，"一颗丹药的事。"
```

#### 【第4层：内心活动】

**萧烬的诊断**

```
【快速判断】
宫寒之症，在凡俗界确实是疑难杂症。
但在修仙界，这不过是最基础的病症之一。
九阳回春丹，专治寒症，对她的病手到擒来。
唯一麻烦的是，这颗丹药需要现场炼制。
他手上没有现成的。
【深度思考】
李雅琴是市首富李建国的女儿。
治好她，不仅是救人，也是一份人情。
前世他不在乎这些，因为他够强，不需要任何人的帮助。
但今世不一样。
他刚刚重生，根基未稳，需要在凡俗界站稳脚跟。
李建国的人脉和资源，会很有用。
当然，这不是他治病的主要原因。
主要原因是——他能治，为什么不治？
```

#### 【第5层：闲笔】

```
【闲笔1】门口的石狮子（约30字）
萧烬认出那是明代的东西，至少四百年历史。这种古董放在门口，李家的底蕴可见一斑。
```

## 四、场景二：炼丹+治疗（1440-1710字）【核心场景】

### 场景定位
本章的绝对重点，要写出：
1. 炼丹的仪式感和专业感
2. 萧烬的炼丹大师风范
3. 李雅琴（和管家/李建国）的震惊
4. 治疗成功的喜悦

### 炼丹分段设计

| 阶段 | 时长 | 描写重点 | 字数 |
|------|------|---------|------|
| 准备药材 | 5分钟 | 萧烬列单子，李雅琴准备 | 300字 |
| 布置阵法 | 10分钟 | 简单的聚灵阵，展现修仙手段 | 400字 |
| 炼丹过程 | 30分钟 | 重点描写，火候控制、药香弥漫 | 600字 |
| 服丹治疗 | 10分钟 | 李雅琴服丹，身体变化 | 400字 |

### 五层展开

#### 【第1层：事件】
萧烬列药材单子 → 布置聚灵阵 → 炼制九阳回春丹 → 李雅琴服丹 → 治疗成功

#### 【第2层：准备阶段】

**列药材单子**

```
"你家有药材储备吗？"萧烬问。
"有。"李雅琴说，"我爸收集了不少珍贵药材，本来是想找名医用的。"
"带我去看看。"
李雅琴带萧烬去了地下室的药材储藏室。
萧烬扫了一眼，点了点头。
人参、鹿茸、红花、当归……基本的药材都有。
有几株药材的年份还不错，至少五十年以上。
"差不多够了。"
他拿出手机，写下一份清单：
- 百年老参一株（用李家的五十年参代替，效果稍差但可行）
- 红花三两
- 当归五两
- 鹿茸粉二两
- 阳灵石一块（没有，用自己的）

最后一样，阳灵石，是修仙界的东西。
萧烬从系统仓库里取出一块，放进口袋。
这是他重生时带来的储备，剩的不多了。
但用来炼这颗丹药，值得。
```

**布置聚灵阵**

```
"我需要一个安静的房间。"萧烬说，"至少一个小时不能有人打扰。"
李雅琴把他带到一间书房。
"这里可以吗？"
"可以。"
萧烬让她出去，关上门。
然后，他开始布置阵法。
没有复杂的手势，没有念咒语。
只是用手指在空中画了几道符文。
符文闪烁了一下，然后消失。
房间里的空气忽然变得不一样了。
如果有修仙者在场，就会发现——
周围的灵气正在缓缓向这间房间汇聚。
聚灵阵。
最基础的阵法之一。
在灵气稀薄的凡俗界，这已经是萧烬能做到的极限。
但足够了。
炼制九阳回春丹，不需要太多灵气。
```

#### 【第3层：炼丹过程】（重点描写）

**炼丹开始**

```
萧烬从系统仓库里取出一个小型丹炉。
这是新手大礼包里的东西，品质一般，但炼低阶丹药足够了。
他把丹炉放在桌上，打开盖子。
然后，开始放入药材。
首先是阳灵石。
一块拇指大小的石头，通体呈暖黄色，表面有淡淡的光芒流动。
萧烬把它放进丹炉底部。
这是丹药的核心，也是凡俗界医术治不了李雅琴的原因——
她的病，需要修仙界的东西才能治。
接下来是人参。
萧烬把五十年老参切成薄片，一片一片放进去。
然后是红花、当归、鹿茸粉……
每一样药材，他都处理得极为仔细。
分量精确到毫厘，顺序不能有丝毫差错。
```

**火候控制**——展现专业

```
药材放完，萧烬盖上丹炉盖子。
他右手在丹炉下方轻轻一挥。
没有火焰出现。
但丹炉开始缓缓升温。
这是真气加热，比普通火焰更精准，更容易控制。
萧烬闭上眼睛，精神力探入丹炉内部。
他能"看"到每一种药材的变化。
阳灵石在底部缓缓融化，释放出温热的能量。
人参片开始软化，药性慢慢析出。
红花和当归在高温下相互融合，形成一种淡红色的液体。
鹿茸粉最后加入，起到中和的作用。
"升温。"
丹炉的温度提高了十度。
药材融合的速度加快。
"降温。"
温度回落五度。
融合速度放缓，给药性更多时间渗透。
"加速。"
"减速。"
"凝丹。"
每一个步骤，萧烬都控制得恰到好处。
前世十万年的炼丹经验，在这一刻体现得淋漓尽致。
```

**丹成**

```
半小时后。
丹炉忽然发出一声轻响。
萧烬睁开眼睛。
他打开盖子。
一股浓郁的药香扑面而来。
丹炉正中央，静静躺着一颗丹药。
圆润饱满，通体呈暖红色，表面有淡淡的光芒流动。
九阳回春丹。
成了。
萧烬拿起丹药，放在掌心观察了一下。
品质……还行。
受限于药材和环境，这颗丹药只能算中下品。
但治疗李雅琴的病，绰绰有余。
他站起身，走出书房。
李雅琴正在门口等着，脸上带着紧张和期待。
"好了。"萧烬把丹药递给她，"服下去，一个时辰后，你的病就会痊愈。"
```

#### 【第4层：服丹治疗】

**服丹**

```
李雅琴看着掌心那颗丹药，眼眶有些泛红。
"真的……能治好吗？"
她的声音都在发抖。
二十多年了。
从十几岁开始，她就知道自己可能永远没办法当母亲。
这些年，她看过无数医生，试过无数方法。
每一次都是失望。
渐渐的，她已经不抱希望了。
但现在……
"先别激动。"萧烬说，"服下去再说。"
李雅琴深吸一口气，把丹药放进嘴里。
丹药入口即化，一股温热的气息从腹中升起。
她感觉自己的身体在发生变化。
那些年积累的寒气，正在被一点一点驱散。
小腹处，有一团暖意在缓缓流动。
"啊……"
李雅琴忽然捂住小腹，脸色发红。
不是痛。
是一种说不出的舒适感。
像是冰封了二十多年的土地，终于等来了春天。
```

**治疗成功**

```
一个小时后。
李雅琴睁开眼睛。
她能感觉到，身体和以前不一样了。
那种常年萦绕在小腹的寒意，消失了。
取而代之的是一股暖融融的感觉。
"好了。"萧烬的声音传来，"以后注意保养，别再受寒。"
李雅琴看着他，眼泪忍不住流了下来。
"谢谢……谢谢您……"
她想跪下去，被萧烬一把扶住。
"不用跪。"萧烬说，"只是举手之劳。"
```

#### 【第5层：闲笔】

```
【闲笔2】阳灵石的来历（约40字）
萧烬把阳灵石放进丹炉时，心里默默算了一下——这是他存货里倒数第三块了。看来，得想办法弄点修仙资源了。
```

## 五、场景三：李建国登场+结交（1000-1250字）【核心场景】

### 场景定位
本章第二个核心场景，要写出：
1. 李建国的形象（市首富，有见识，有格局）
2. 他对萧烬的态度变化（怀疑→震惊→敬佩→结交）
3. 萧烬的不卑不亢

### 五层展开

#### 【第1层：事件】
李建国回家 → 得知女儿被治愈 → 震惊 → 找萧烬详谈 → 主动结交

#### 【第2层：李建国登场】

```
就在这时，门口传来声音。
"雅琴，我回来了。"
一个五十多岁的男人走进来。
身材中等，头发花白，但精神矍铄。
穿着一身休闲装，看起来很随和。
但萧烬能感觉到，这个人身上有一股气势——
那是常年位居高位的人才有的气势。
李建国。
天海市首富，身家百亿。
他一进门，就看到女儿满脸泪痕。
"怎么了？"他皱眉，"谁欺负你了？"
"爸！"李雅琴擦了擦眼泪，声音里带着压抑不住的喜悦，"我的病好了！"
李建国愣住了。
"什么？"
"我的宫寒，治好了！萧先生帮我治好的！"
李建国的脸色变了。
他看向萧烬。
目光像是在看一个怪物。
```

#### 【第3层：对话设计】

**李建国的怀疑→确认**

```
"你说什么？"李建国的声音有些发抖，"治好了？"
"是真的，爸！"李雅琴抓住父亲的手，"我能感觉到，那种寒气全都消失了！"
李建国沉默了几秒。
然后，他走到萧烬面前。
"萧先生，是吧？"
萧烬点头。
"我女儿的病，我找了全国最好的医生，都治不了。"李建国盯着他，"你是怎么治好的？"
他的语气不是质问，而是……震惊。
"一颗丹药。"萧烬说。
"丹药？"李建国愣了一下，"什么丹药？"
"九阳回春丹。专治寒症。"
李建国又沉默了。
他在商场上摸爬滚打几十年，什么人没见过。
但萧烬这种人……他还是第一次遇到。
二十出头的年轻人，面对他这个市首富，没有一丝紧张。
说起"丹药"两个字，就像在说家常便饭。
要么是疯子，要么是……真正的高人。
他选择相信后者。
```

**主动结交**

```
"萧先生。"李建国忽然深深鞠了一躬。
萧烬没有阻止。
"您救了我女儿，这份恩情，李某铭记于心。"
他直起身，眼神真诚。
"以后您有什么需要，尽管开口。只要李某能做到的，绝不推辞。"
萧烬看着他，点了点头。
"李先生客气了。"
"不是客气。"李建国认真地说，"萧先生的本事，李某一辈子没见过。能认识您，是我的荣幸。"
他从口袋里掏出一张名片。
"这是我的私人电话。任何时候，只要您打过来，我随时候命。"
萧烬接过名片，看了一眼。
李建国，天海市建国集团董事长。
"另外……"李建国犹豫了一下，"我想请萧先生吃顿饭，不知道您方不方便？"
"饭可以改天吃。"萧烬说，"我现在要回去了。"
他没有拒绝，也没有一口答应。
不卑不亢。
李建国的眼神里多了几分欣赏。
这个年轻人，不简单。
```

#### 【第4层：萧烬的内心】

```
【深度思考】
李建国。
天海市首富，身家百亿，人脉遍布全市。
这种人，对他现阶段来说，非常有价值。
但萧烬不会刻意去攀附。
前世他是魔尊，万众敬仰，从来只有别人求他。
今世虽然重生，他的骄傲不会变。
李建国主动结交，他接受。
但仅此而已。
他不会为了人脉，低三下四。
【对李建国的评价】
这个人，有眼光，有格局。
不像王天豪那种蠢货，只会炫耀和威胁。
李建国知道什么人该敬，什么人不该惹。
这种人，值得结交。
```

#### 【第5层：闲笔】

```
【闲笔3】李建国的观察（约40字）
李建国注意到，萧烬身上没有任何名牌，手腕上也没戴表。但他的气质，比任何名牌都值钱。这种人，不是暴发户。
```

## 六、场景四：埋伏笔+收尾（400-500字）

### 场景定位
本章收尾，要：
1. 萧烬离开
2. 李建国的后续安排（调查萧烬）
3. 埋下伏笔

### 收尾设计

**萧烬离开**

```
萧烬拒绝了李雅琴送他的提议，叫了一辆车离开。
在车上，他看着窗外的夜景，嘴角微微上扬。
市首富的人脉，到手了。
接下来，该做下一步计划了。
林小满的事……
他想起系统的任务——"帮助第一女主开启修炼之路"。
那丫头，现在应该还在出租屋等他吧。
```

**李建国的安排（伏笔）**

```
李家别墅。
萧烬离开后，李建国独自坐在书房里。
他点了一根雪茄，陷入沉思。
"萧烬……"
他喃喃自语。
这个年轻人，太神秘了。
他必须调查清楚。
不是为了别的，而是为了知道——这个人，究竟是什么来头。
他拿起电话，拨通了一个号码。
"帮我查一个人。萧烬，二十五岁左右，住在老城区。"
"查他的一切。越详细越好。"
挂断电话，李建国靠进椅背，眼神深邃。
他有一种直觉——
这个萧烬，会给天海市带来一场巨大的变化。
而他李建国，要抓住这个机会。
```

## 十三、本章预期效果

**读者读完第7章，应该：**

1. **对萧烬的能力有更深认识**：他不只会打架，炼丹也是高手
2. **记住李建国**：市首富，有格局，以后会是萧烬的人脉
3. **产生期待**：李建国调查萧烬会发现什么？
4. **感到温馨**：治愈李雅琴的情节有温度
5. **理解萧烬的处事方式**：不卑不亢，不主动攀附

**读者不应该觉得：**
- 炼丹过程太无聊
- 李建国太舔
- 感激戏太煽情
- 剧情太平淡
